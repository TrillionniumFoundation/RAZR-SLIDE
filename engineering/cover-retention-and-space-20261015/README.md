# 盖件保持与整机空间接续｜2026-10-15

## 真实新增问题与局部修复

前轮盖件先定位方案在夹爪移除后，现有名义CAD允许盖件沿+r完整上抬1mm；本轮对两侧各22个其余实体用完整平移区域重新验证，不只是检查端点。装得进去不能替代保持。

新候选在内/外根座各加入固定C形保持槽。先前悬空挡片及不相连立柱方案均拒绝并保留。本轮保持槽包含与原根座有正体积搭接的底脚，两侧四个根座各仍为单一有效实体，不丢弃原材料。每侧内/外根座分别新增约0.1931/0.1731mm³，不切除原根座；盖件及其余零件保持不变，不增加原研究装配的外包络。

名义上方间隙0.02mm，立壁0.13mm。上抬0.019mm仍无干涉，上抬0.05mm时两边保持槽均阻挡。这只是指定直线方向的刚体止挡，不是任意六自由度捕获、强度、预紧、公差、摩擦或疲劳资格。0.02mm是不利高度误差、装配偏差、热变形及挠度必须共同面对的预算，不能把数值零干涉当作可制造公差。

## 当前验证范围

395项/23组单元测试通过。原盖件先定位22阶段的130对检查在新根座上重算；使用来源不变的KEY/STOP/棘爪完整运动包络，全部130对运动检查重算；506对静态检查通过。新增夹爪撤出94对检查通过，但没有给真实夹爪发出松开指令，也没有取得安全松夹资格。

验证程序不导入候选或场景生成器，重新读取四份新根座STEP及四份保持槽证明STEP，核对原材料保留、完整性、搭接和边界。两份完整STOW装配的46个实体又分别逐一匹配。仍是同一CAD内核与通用算法，不称跨内核证明。保持槽证明实体不能被当作装配里的额外零件。

原564/184离散采样本轮没有重复，历史结果原样保留。当前不变运动体的完整包络被精确复用，新根座的130个运动相交全部重新计算。没有新建分支或重新克隆远端；本次追加在原PR #6。

## 空间结论必须纠正到整个组件

每侧当前静态研究组件包络为12×15.8×21.21mm（e/q/r）。计入已声明KEY完整行程后，名义运行包络为12×16.445×21.21mm；q最大值13.145mm，比盖件自身12.5mm还多0.645mm。以上不是实际手机尺寸，也不是可用内腔；没有含夹具/工具，也未加入真实工艺或电芯膨胀公差。

当前源码输入登记中的10项成品空间字段仍为空，机舱归属和装配坐标变换也未取得。本轮仓库及Library检索找到的是已有研究文件、询证草稿与未完成记录，没有把它们冒充同版本真实内腔。自研壳体CAD加实测器件包络也可作为后续输入，但不能拿研究CORE直接当空腔或随意移动研究组件直到看似不碰撞。

双舱等外形、单约7英寸OLED、无独立背屏、A大电池优先及4700mAh目标不变。新增保持槽未额外扩大研究包络，但前轮盖件的3.5mm空间代价仍未被真实手机内腔接受。
