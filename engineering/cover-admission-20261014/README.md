# 外盖先定位：装配前段准入研究｜2026-10-14

## 当前结论

当前入装候选在两侧各完成七个连续直线阶段：盖件落到支撑、压头就位、未停放棘爪从下方进入、棘爪停放、内根座侧入、STOP0侧入、STOP1侧入。每一步的所有已放入零件及有限夹具都作为障碍，失败后不得把零件写成已安装。第八步外根座闭合仍失败，整个初始装配计划以退出1保留拒绝，后续紧固和完整夹具退出未执行。

## 实质改动与代价

保留PR5的KEY通道和外盖U形绕接。新的内根座定位口窗口为e=-3.16..-2.68、q=2.98..3.22、r=-7.25..-6.43mm；每侧只移除盖件0.04416mm³，外包络不增、实体仍完整。原闭合定位孔变成侧开槽，其保持/承载边界已改变；关闭后的挡块或压板尚未设计。不得将此改动称为原孔完整不变或已获制造资格。

相同路线和夹具的原闭孔负对照，两侧只通过前四段，随后内根座侧入拒绝；开槽后该段及两个STOP阶段通过。因此不是靠换测试、删除障碍或增加离散采样得到通过。

## 夹具与碰撞检查

每侧加入两个有限CAD实体：底座/支撑柱组件及后置压头组件。初版直立压头在内根座侧入和终位有实际相交，原源文件和失败记录保留；现压头的立柱移至后方，指形横梁避开根座与螺钉包络。它们仍只是几何研究夹具；机架、驱动、夹紧力、保持稳定性、材料和真实紧固未验证，更没有制作或上电。

运动包络由完整端点实体、原生前向平面棱柱和圆柱保守载体组成。各实体单独检查，不依赖全局Boolean融合。它们可能重叠，不能把其体积相加当真实扫掠体积；任一相交实体足以拒绝，所有实体与障碍均不相交才支持所声明名义直线路径。没有把几个姿态的并集当作连续扫掠。

## 保留的实际阻塞

外根座侧向闭合在距终位0.05mm处，左右各与盖件相交约0.02723856mm³；实际双实体STEP与独立复读保留。第八阶段每侧8个相交包络单元存在重叠，不把它们相加报告碰撞总量。按整个外根座横移包络直接削盖件会剩五个实体，全部保留为拒绝候选，没有只挑最大的一块。

## 原生输入与源端限制

本轮也发现，重生成的复杂外根座在构造面棱柱时出现inner wire is not closed；改用直接原生面棱柱也未通过严格拓扑检查。没有把错误当空集。最后的入装证明采用PR5中已独立核验、逐字节绑定的完整STEP零件，不重生成、不修复或过滤其面；只有明确的盖件定位口做减量。源端重新生成对象到该装入证明的闭合仍待解决，不能凭STEP通过宣布源端问题已修好。
