## 3. 中途原失败、修复材料与允许域

## 4. 当前全 KEY 行程、真实内核反例与材料填充

每侧 KEY 的 92 个完整面含 80 个 PLANE 和 12 个 CYLINDER；每侧 528 个有向边出现均保留 seam 多次出现，完整 pcurve、3D curve 和 vertex 进入区间支撑。每侧 94 个区域包含完整起点、完整终点和全部 92 个面沿 `q∈[0,12]` 的载体。该计算覆盖完整名义直线行程，没有通过离散姿态代替连续域。

BREP 正向 producer-v6 每侧执行 47 个 Common，另有 47 个近切向精确载体体积界。两侧混合贡献为 `4.223755680489645e-13` 和 `4.2142792593527956e-13 mm³`。独立 STEP 反向 reader-v2 得到同量级结果，三个 whole-body 的六个定向材料差为零。运行分别用时约 24.17 s / 27.32 s，峰值 RSS 约 377 / 406 MB。它们仍共享 OCP 内核。

**这些混合合计不是严格交集上界。** 其中 47 个 Common 零值缺少独立误差保证，不能直接用于放行。新反例已明确展示该风险：

| 原件或判据 | 有向体积 / 上界，mm³ |
| --- | ---: |
| 拓扑有效的微薄 prism | `9.233858122569423e-16` |
| 完整 panel | `4526.78137306303` |
| 保存的 Common 结果，仍为有效拓扑 | `4526.781373063011` |
| 原 `min(operand volumes)+1e-7` 允许上界 | `1.000000009233858e-7` |

该结果违反原上界，失败实体、输入与独立原生读回均已保留。另三次失败包含负有向体积、非零极小轴分量导致精确前提拒绝，以及有效拓扑但零体积的 prism。没有使用 `abs(volume)`、舍掉微小项或放宽原门限。

当前左右 KEY 的完整边界还给出约 `12.4 mm` 的 X 支撑间隔；这项解析表示下的分离与两侧 q 无关，不依赖 Common。完整 panel 的额外填充和通道证明作为单独证据保存，不改写已经封存的原生诊断。在“完整材料边界包含于列出的序列化解析支持”这一条件下，完整 panel 的 298 面与两侧 KEY 共 482 面进入材料覆盖。每侧条件化保守体积上界从约 `3.17208` 收紧到 `1.002`，再经完整边界通道排除得到 `0.9600000000000029 mm³`，仍高于原 `1e-7` 门；这个上界不是实际碰撞体积。最后检查六个导槽面、12 个 wire、48 条 LINE：native Closed 均为 true，而精确 binary64 参数端点有 44 处连接不完全重合。没有吸附端点或推断孔填充，全部残余正贡献保留。最终范围见机器可读总账与 `panel-filling/` 交付；native-set identity 和统一编译误差仍未证明。

旧 L1 九例的改进采用紧致材料的完整边界填充：凸载体包含全边界才可推出包含材料；一般有限盒并集需要沿纤维补齐，不能把外壳盒并集当成实体。九例保留 27 个原 BREP、79 个载体、474 个完整有向面环、121 个固定纤维原子和 842 项严格比较。独立 reader 新执行 79 次 Common，并以解析分离作为另一个依据。空心壳、`2^-80` 正薄壳和单点投影端点三个几何控制均保留；七个主要篡改负控和两个来源篡改负控全部被拒绝。该成果只关闭所述解析模型的填充推理，未关闭原 016–019 的初始 q 扫掠、完整 B_SHELL 并集或 native filling 语义。

另增加一个独立命名的可移植 loadG 算法：4221 个原二进制有理数乘积精确求和，最后只进行一次 binary64 ties-to-even 舍入。24 个 dot 经独立 Fraction 和舍入格核对，与正确舍入参考一致；171 个差分边界例、120 次次序变换和四份实际篡改文件控制通过。历史 BLAS map 有十项不同，当前 BLAS map 有六项不同，最大绝对差均为 `2.220446049250313e-16`。原 whole-seed bitwise replay 仍未通过，历史失败保留；新辅助 map 不自动提供完整 portable seed、任意 RHS 逆或接触 QP 资格。

## 7. G3→G4→G5 实现修复及验证

原 G4 没有处理采样表之外的分类失效和维修/换件事件；本轮将 G4/G5 统一到保留事件的路径。失效不能被缺测覆盖，缺附件另留缺证；维修/换件使原装配连续资格失效，但不自动写成物理失效。

前置资格必须使用同一完整设计绑定和同一 SHA 校验的原装配记录；记录中的零件、材料批次、工艺、固件与装配身份必须一致。阶段时序要求前一级采集开始 < 结束 ≤ 通过审查完成 ≤ 后一级采集开始；G5 同时重查 G3→G4 内部顺序。缺原件、缺采样证据或缺审查时间为 unknown；顶层 pass 与内部失败、未决或维修相矛盾时拒绝。G4 成功的空异常表只有在采样通过且覆盖完整时才准入。

原 43 项测试先通过；新增反例在修复前确实失败。独立审查又发现并修复记录时序、判据一致性和 G4 正常空异常表被过度拒绝的问题，各版失败均保留。最后的 donor 复核又发现原始装配记录中的 donor 身份可被外层一致声明重新标记；新补丁校验原件顶层或 qualification_assembly 内的同样件 donor，缺失为 unknown、冲突拒绝。新增六项控制修复前有四项失败。最终 68 项 G4/G5、8 项当前 G3 绑定和 57 项既有 G3 合同测试，共 **133 项针对性测试通过**；原七个独立准入控制与新增 12 种 donor 配置审查分别保留；新增审查显式隔离外部输入适配器，未替代完整量测流程。这里没有新的全仓回归成绩，也没有实物 pass。

新采集前应冻结各阶段共用完整 binding 及原始 as-built 的 `qualification_assembly`；旧部分记录不靠改标签迁移为通过。工具校验记录一致性，不认证仪器或文件在现实中的真实性。详见 [合同修改说明](qualification/README.md)、[最终源码与测试身份](qualification/SOURCE_AND_TEST_READBACK_DONOR_FOLLOWON.json)、[先前独立审查](independent-review/qualification/INDEPENDENT_REVIEW.json)及[原始 donor 追加审查](independent-review/qualification-donor-followon/FOLLOWON_REVIEW.json)。
