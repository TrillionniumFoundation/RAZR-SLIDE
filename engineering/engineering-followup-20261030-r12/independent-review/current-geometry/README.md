# R12 当前 KEY / panel 连续载体：独立审查结算

本目录独立复核全材料网格、解析投影、外部通道、全部正贡献及最终 trim 未决项。它没有导入被审查的 fibre、projection 或 channel producer 模块；必要的源参数、输入哈希和计算脚本均保留。

## 结论

严格按当前已证明范围，保守上界仍未达到原 `1e-7 mm³` 门。左右各从 Z 向填充的约 **3.17208 mm³**，收紧到三向填充交集的约 **1.002 mm³**，再由完整外部通道证明排除斜面包围盒带来的约 **0.042 mm³**，留下每侧 **0.9600000000000029 mm³**。这个正上界表示当前方法不能认证通过，不证明真实材料发生碰撞。

剩余量位于 Y 导轨通道的保守填充。完整原生 wire 读回显示六个相关面共有 12 个 native Closed wire、48 条有向 LINE；独立有理数运算核实 44 个连接的保存 pcurve 端点不逐字相等，最大差为 `6.661338147750939e-16`。没有把微小端点差说成实物孔洞，也没有通过未经证明的 snapping / trim filling 假设减去剩余体积。

## 外部通道证明的精确条件

令每个 q 下的材料集合 K 为紧致闭集，并假定其完整拓扑边界确由记录的连续解析面、trim、3D 边和顶点表示。若相连的开放通道 C 与完整边界不相交，而且含有一个经完整全局支撑确定的 K 外点，则 C 整体属于 K 的外部。该结论不要求 K 单连通。

右侧本次独立通道为 `X∈(11.4,11.7), Y∈(52,64), Z∈(1.2,1.6)`，接上 `X∈(11.4,32), Y∈(52,53)`、相同 Z 的通道；左侧镜像。文件使用 source binary64 的精确有理数值，不用显示小数代替合同。通道边界之外的薄条必须保留；最终 producer 账本确实逐正贡献处理，没有按坐标近似删条。

对相关斜面，`±X+Y` 的完整解析支撑给出分离，因而没有使用 native Common 的零值作为上界。整个论证仍有明确前提：保存的解析边界与实际 native BREP 材料的 filling 身份，以及所有原生几何变换/求值器的全参数误差界，尚未全部证明。

## 对抗控制

五个账本篡改控制均被独立 checker 拒绝：漏掉正 box、漏掉边界面、用重复面替代一面、把仍为正的约 0.48 mm³ 未决 box 的上界减去 `2^-80`、以及破坏弯折通道连通性。前三个错误无法通过计数相同或总量接近来掩盖。

另外，两侧各三种故意扩大到实际 arm、tab 和 yoke 的错误通道均被边界排除检查拒绝，共六项。这些拒绝与原生材料正控分别保存：未决包围盒本身不被当作实际碰撞证明。

## 当前资格

本审查验证的是精确账本、完整边界支撑、连通外部路径及明示模型下的保守计算。最终 `1e-7` 门仍为 false；真实 native identity bridge、全 15 维 G2、物理允许域、当前 FE、OEM、电气与 G3→G4→G5 均未被本证据升级。

复跑需要相邻的 `geometry_work` 和 `panel_fill_work` 目录；外部输入身份列于 `EXTERNAL_DEPENDENCIES.json`。原生失败和所有历史版本由相应工作包保存，本目录不覆盖它们。
