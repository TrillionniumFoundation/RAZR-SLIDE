# R12：当前 K1 / K3 全 KEY 行程的连续载体与原生诊断

本目录对 **当前 `key_forward_loop_v1` 的完整左右 KEY**、**当前 `panel_key_travel_stops_v1` 的完整 panel** 进行新计算。它没有把旧 S4 的 L1 材料当作当前候选，也没有重复声称重建了一次完整 154 体 factory。

本轮完成的原生诊断覆盖每侧 `q ∈ [0,12] mm` 的完整直线行程；它采用全边界载体，**不是有限姿态抽样**。两侧 q 各自独立。原生 Common 的零值仍不被冒称为严格交集体积上界：每侧 47 个非退化载体的精确 panel 分离义务仍单独保留。完整 15 维运动、真实机构允许域、全局壁厚/最弱截面、当前 FE 和 G3–G5 均未据此放行。

## 3. 精确载体怎样补齐了原来的缺口

`complete_surface_support.py` 读取每个面全部有向边出现、完整 pcurve trim、3D 曲线及顶点。LINE 使用全参数仿射极值，CIRCLE 使用完整圆的解析支撑，平方根上界经过有理数平方比较后向外舍入。曲面参数矩形、所有边和顶点的世界坐标支撑取并集，再加入完整 q 行程。

当前 KEY 的最终材料没有 BSPLINE pcurve；工具对允许的 degree-1 情形保留明确的末段仿射延拓说明和未证的 native 语义标志，不隐藏越界参数。

全部面都参与载体构造，不依赖浮点法向点积正负来删去“非前进面”。数学依据是紧致材料的平移填充关系：内部点首次沿运动线进入材料时必经过其完整边界，故起始材料与完整边界行程可覆盖完整平移扫掠。把保存的边界表示与实际 native filling、编译后的全参数误差连接起来的义务仍未关闭。

## 4. 独立左右 KEY 的严格区间分离

`INDEPENDENT_KEY_X_SUPPORT_CERTIFICATE.json` 从上述全部解析边界支撑推导两侧 X 半空间，分别使用正向 BREP 与反向 STEP 数据。两侧严格正间隔约 **12.4 mm**，与独立的 `q_L,q_R ∈ [0,12]` 无关。

此处不用 Common 零值，也不用 `AddOptimal` 的浮点包围盒冒充精确支撑。对于紧致材料，完整边界落在一个 X 半空间意味着整个材料也落在该半空间；证明及其真实 native 材料解释前提均写入机器可读证书。因此该证书明确区分“解析表示下的半空间分离”与“完整原生 filling / 全浮点误差桥接已证”。

## 7. 通用平方根上界的下溢修复

后续 panel 载体工作触发了对平方根界实现的审查：先将一个极小的正有理数转为 binary64 再开方，可能先下溢为零；从零逐 ULP 向上走的旧写法没有可用的有限迭代预算。已另存 `complete_surface_support_v2.py` 的二进制缩放版本，以及 `complete_surface_support_v3.py` 的纯有理数 / 整数平方根版本。旧 helper 仍逐字节保留，以上 v6 / reader-v2 报告没有被重写或冒称使用了新 helper。

v3 用相对 128-bit 的 dyadic 格点和整数 `isqrt` 直接构造外向界，避免任何中间浮点转换。八个实际算术控制覆盖零、单位值、非平方数、`q=1e-600`、最小 subnormal 的平方、连平方根也低于最小 binary64 的 `q=1e-700`，以及很大的平方。所有 `upper² >= q` 的精确检查通过。

这证明旧通用算法存在下溢路径，并验证了修复；它**没有证明**另一 panel worker 的超时原因就是这一问题。该 worker 的实际失败、调用定位和续跑证据由独立 panel 工作目录保留。
