# K1: named forward U-loop KEY candidate

This isolated diagnostic applies `key_forward_loop_v1` to a newly rebuilt,
clean, immutable S4 complete factory. It leaves the S4 production source and
all go flags unchanged. The two finite witness poses retain the original
binary64 slide and total q values.

## Prerequisite and order

The exact F1a run is 40273568199, diagnostic commit
935d6adb5ceeb2995971cb32ba2a5f7694114237. Both actual engineering artifacts
must first be retrieved, reviewed and entered in `K1_F1A_BINDING.json` with
their artifact ID and exact `ENGINEERING_MANIFEST.json` SHA256. A template is
not executable approval or proof. `build_k1_workflow.py` refuses an incomplete
binding. The run downloads the frozen artifacts, verifies every manifest
member, both 11,781-pair journals, all 154 independent STEP readbacks, all
eight L1 whole-material-frame comparisons per pose, and the source/environment
projection. These are explicitly marked projections of ephemeral raw reports;
the original raw runtime is not downloaded or reconstructed.

Each job independently rechecks the current S4 source and locked 43-package
environment, rebuilds all 154 original factory bodies, and compares each body
as complete material with its F1a STEP in both subtraction directions. It
reproduces the original positive panel/KEY Common before applying the candidate.

The producer exports the original KEY, declared cutter, actual removed material,
actual added material, all three new prisms, q=0 result and actual witness KEY
as STEP and BREP. It exports all 154 candidate bodies and evaluates all 11,781
unordered pairs with the unchanged original `strict_common` and 1e-7 mm3
predicate. Positive Common solids and selected/completed journals are retained.

The independent process imports every candidate STEP, repeats all 11,781 pairs,
and independently builds the cutter and three prisms from the frozen contract.
It does not import the candidate builder. Whole-material differences, protected
old material, loss/addition/balance and q=0-to-factory correspondence must agree.
Execution completion and finite pose clearance are separate fields. A complete
run with any rejected pair remains a geometric rejection.

## Structural intent and limits

The collision source is the original KEY transverse bar crossing the fixed
panel cover-backing posts. The panel posts and their functional cover-bearing
faces remain unchanged. Each KEY removes the original bar material inside a
1.10 x 1.50 x 0.36 mm strip (0.594 mm3) and adds a forward U-shaped connection.
The material account must verify these numbers natively rather than assume them.

Each declared leg has a 0.38 x 0.36 mm cross section: 0.1368 mm2, or 25.333% of
the old transverse bar's 0.54 mm2 section. This is not a strength qualification
or a measured minimum section of the complete KEY. Loads, preload, material,
process and tolerances remain missing. Old FE results cannot qualify this change.

The three new declared prisms avoid the two source post prisms throughout
q in [0,12], the unclipped nominal slot projection, and the real halfspace
model using the original slot comparison TOL constants. The exact-rational
axis gaps are retained and their float displays are rounded downward. This statement covers only those
prisms and posts. It is not a full KEY or full-scene continuous proof. No
backlash, telescope or left/right domain is clipped; no physical stop is added.
Both finite witnesses must first clear before endpoint and full independent
domain work can support a later candidate review.

## Capacity and preservation

Factory and reader each retain the original finite 1200 s, 1536 MiB RSS,
6.8 GiB shared unreclaimable memory, 256 MiB startup and 100 MiB runtime disk
guards with 2 GiB additional startup memory. The prior D6 complete finite
factories took 457–479 s. K1 adds full baseline STEP material comparisons and
material accounting within the same bounded task; fit is a plan, not a measured
guarantee. Timeout, capacity refusal and actual failures remain evidence.

Only the engineering allowlist is uploaded: exact reviewed sources, complete
models and pair journals, original prerequisite engineering export, numerical
resources and marked report projections. Raw runtime interfaces, caller
environment and unrelated logs remain only on the ephemeral runner, with local
hash/size/category inventory. Durable raw-runtime preservation is not claimed.
