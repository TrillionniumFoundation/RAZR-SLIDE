# K3 preliminary additive travel-stop experiment

This independently named candidate leaves immutable S4 and the verified K1/K2
candidate unchanged. It adds four panel pieces, with stop planes derived from
the exact frozen K1 front crossbar. All geometry remains diagnostic.

The first remote run has two complete factories: STOW with both tabs 3 mm and
PREDOCK at slide 79.75 mm. Each saves all 154 candidate bodies, the complete
original panel and each added component before checking positive panel joins,
preservation of four original cover support faces, endpoint contact area and
opposite normals, and complete KEY/panel overtravel and inward-release controls.
An actual failed early gate prevents the 153 changed-panel pair calculations.
Neither pilot executes the full 11,781 unordered pairs or the ten-state plan.

The independent process reads every STEP, verifies original panel material
against both actual K1 engineering witnesses, rebuilds the panel from the frozen
scalar contract without importing the candidate builder, measures 18 early gates
and replays any performed panel pairs. The CAD kernel is the same locked kernel.
A diagnostic job can complete successfully while the candidate is rejected; the
scientific `actual_finite_pilot_clear` flag is explicit. Both actual pilot results
require review before any ten-state/full-matrix execution; no automatic stage is
released by this workflow.

The lower posts overlap the ROOT_INNER AABB in the actual STOW0 factory; fit is
unresolved until actual native Common. Do not thin a part or erase this risk to
obtain a pass. There is no measured global minimum wall or strength qualification.

Every original finite resource gate remains: 1200 s per worker, 1536 MiB worker
RSS, shared unreclaimable 6.8 GiB, startup ordinary disk 256 MiB, runtime disk
100 MiB and incremental startup memory 2048 MiB. Original owned lifecycle, INT/
TERM cleanup and separate hosted deadline remain. No local native execution is
allowed while the original startup capacity gate fails.

Only engineering originals and explicitly derived projections are uploaded.
Original runtime, paths, logs and caller environment are not public; omitted
files receive category, size and byte hashes, with no durable runtime claim.
All source/domain/go/physical and fabrication flags remain unchanged or false.
