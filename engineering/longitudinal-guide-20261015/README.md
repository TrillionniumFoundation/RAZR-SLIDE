## 本轮实际问题与改动

Y向从来不是完全无约束。旧肩销/盲孔座在偏离中心后会先碰到背板和上盖的开口；旧根座的前后面也存在。不能只根据此前X向面的秩为3，就称整套导向缺少所有Y约束。

本候选在每侧外根座增加两块连通的宽主体导向面，前面位于Y=18.07mm，后面位于Y=22.23mm。原PAWL主体前后面是18.15和22.15mm，因此原朝向下名义Y接触位置为±0.08mm，±0.09mm出现实际正体积阻挡。左右镜像。

同时仅在背板/导向/可拆上盖两侧颊板开固定半径0.78mm让位通道，使原0.65mm销肩/盲孔座不先承担这一路径的几何止挡。原PAWL、KEY、槽、肩销、目录紧固件和现役外盖都未改动。每侧根座新增0.342mm³；每侧上盖移除约0.100496mm³；背板共移除约0.613586mm³。所有新零件保持完整单一正实体，25份模板中18份保持原实体。

这是**接触位置和几何载荷路径的重新分配**，不是实际力学资格。它放宽了旧销肩通道对Y位移的限制，不能称为降低所有游隙。无预紧时中心位置仍存在自由间隙。

## 实际检查

20项新增几何/数值/拒绝输入测试通过。独立候选重读25份STEP，通过24项Y向接触/越程检查，并保留12项旧销肩阻挡反例。

Y运动按实际斜槽关系与Z联动：`ΔZ = -slope × ΔY`，并保留槽隙两个边界。不是把PAWL沿Y随意搬动后假定仍在槽内。对整个槽行程、X±0.05mm、Y±0.08mm，30项根座/盖件保守包络和12项销肩—背板/上盖圆柱载体包络检查通过。主体导向边界允许真实接触，不把零接触间距当加工余量。销肩保守包络最小剩余间距约0.02358mm。此前独立刚体误差框的根座/盖件余量仍为约0.02mm，但没有加入实际形位、磨损和受力变形。

从已校验的mounted/coupling/当前模板独立重建79件场景，先复现基线的全部3081对结果，再完成20个本候选场景、15735对检查；另补32个释放端耦合边界场景、9792对检查。合计52个场景、25527对，均无正干涉。此处是隔离重放，不是仓库完整单测/原生任务重跑。

绑定旧十四步装入成功报告，并证明本轮其他改动均为原件的材料子集，新增材料全部由四个固定方体覆盖；对新增材料再做56项装入、16项早期根座合拢、8项STOP完整路径和4项框架合拢比较，全部通过。这是有明确单调材料关系的增量证明，不是重新声称整套上游装配或工具转矩已合格。

对选定实际接触面的线性化不穿透不等式，五个非工作方向的优化目标均有界，Z工作轴保留。另设“秩仍为5但缺少一侧法向”的拒绝对照，避免把矩阵秩当作单向接触闭合。该模型不是有限转角的可达域、中心位同时接触或有载力封闭证明。

36个额外有限转角观测中19个无碰撞，其余有实际阻挡；无碰撞观测没有丢失原局部锁止/释放预期。没有把36个观测写成36项全通过，也没有从离散点推导连续可达路径。四个缺件/非有限证书/STEP改写/符号链接输入全部拒绝。
