# 盖件先定位的装配研究候选｜2026-10-14

## 这轮解决的范围

本轮为上轮盖件晚装阻塞提供了一个新的名义几何装配候选，而不是宣称旧结构只换顺序就通过。新流程是：盖件放到下夹爪端部 → 上夹爪闭合 → 内根座从内侧进入 → 停放棘爪从下方进入 → 两个STOP依次从外侧进入 → 外根座闭合 → 两颗根座连接螺钉进入 → 两次完整刀杆占用检查。左右共22个阶段、130个参与体配对检查。夹爪端部和刀杆占用均为实际导出的几何体，但完整执行器、夹持力、临时零件保持和螺纹预紧仍未验证。

## 明确的新接口与空间代价

当前研究源为 `integration/cover_admission.py`。闭合定位结构改成侧向导入槽，连接U筋改走q=12.2–12.5 mm远端。原近端盖件参考仍保留在 `integration/keycover_bypass.py`，不改写它的尺寸或旧验收。

新研究盖件使局部零件装配q最大值从9变为12.5 mm，增加3.5 mm占用；这是明确的新空间需求，不是证明真实手机内腔已经容纳。原盖件封闭定位孔与原定位舌不再宣称保留。一个原来在槽加工后成为孤岛的定位舌，通过预先声明的特征包围体整项删除，不按最大实体筛选或丢弃未知碎片。

以接触研究阶段的原盖件为材料基准，每侧原体积约41.274096658 mm³；新体积39.938445329 mm³；明确移除原材料3.663651329 mm³，新增2.328 mm³，其中旧定位舌特征移除0.2424 mm³。其余根座、KEY、STOP、棘爪等非盖件几何不变。相对于紧接上一版近端绕接盖件的另一组增减账目，在独立材料回执中单列，不能混用。

新侧向槽的抗脱出、耐磨、定位刚度、载荷和公差必须重新评价；本轮的几何通过不意味着功能等效或已经允许加工。

## 运动检查方法与失败保留

六个主要装配轴方向和法向退让后再横移的实际位置检查表明，现有结构并非简单换序即可。它们是有界诊断，不是证明所有旋转或多段路径都不存在。近端开槽候选产生分离实体，远端初版仍保留一个旧定位舌孤岛，原始报告均保存。

整体合并运动包络及从wire重建面的方法暴露了非正实体、端点材料丢失和无效修剪面等内核问题。失败日志原样保留。新 `translation_regions.py` 使用完整有效原生面作线性挤出，分别核验可能重叠的证明区域，不依赖把所有区域融合成一个大实体。沿运动轴的圆柱侧面法向速度为零，不加入会填满轴向孔的整圆柱载体；其余曲面仍按显式保守包络处理，未支持的面类型拒绝。区域体积之和不冒充并集体积。

源码生成器内存几何的部分扫掠仍然失败，不能称为内核问题已全部修复。当前候选固定读取仓库已有、逐文件哈希匹配的完整STEP作为STOW名义输入；旧生成路径保留。几何差异通过独立原生复读核对，不以改容差掩盖。

## 证据与复现

新的22阶段装配检查和原q=0–12 mm的130对运动检查是两组不同检查，不得混称为同一组。独立装配复验重新读完整STEP、按既定顺序重算每一步，并拒绝省略此前已安装的障碍、修改起止位置或缺少刀具参与体。独立过程中不导入候选/场景生成器，但仍使用同一CAD内核和通用运动算法，并非跨内核证明。

根座名义连接螺钉仍只是原有圆柱包络；直径3 mm、总占用长60 mm的刀杆没有证明刀头啮合、实际扭矩或整把工具手柄净空。夹爪只覆盖端部体积，不等于已制造完整夹具。

`uv sync --locked` 后用 `uv run --locked python -B tools/verify.py` 运行当前单元组。装配研究入口为 `integration/cover_order_gate.py --output NEW_EXTERNAL_DIR`，独立复验为 `integration/verify_cover_order.py --repo REPO --receipt REPORT --sha256 HASH --output NEW_FILE`。原动作/装配回归入口为 `replay_admission_sequence.py`、`replay_admission_assembly.py`，运动入口为 `admission_motion_gate.py`。

原始JSON采用可逆gzip存储，索引列出原字节与压缩字节长度和SHA256；关键退出码及未截断日志在jobs目录。新增QA材料复读脚本在qa目录，不把其执行冒充额外单元测试。

## 接下来真正的门槛

先把3.5 mm新空间需求放回同版本真实A/B机舱，决定该研究结构能否产品化，不能静默替换原尺寸基线。同时设计完整夹爪执行机构和临时保持方式，验证开口槽保持/抗脱、夹紧力、根座预紧、有限力回缩和疲劳。OPEN连续运动、真实OLED/FPC叠层与完整端接、独立双电池/USB等原门槛仍在。

本轮没有制造夹具、改动硬件、上电、采购、外发供应商消息或合并主干。candidate_go、fixture_fabrication_go和manufacturing_go均保持false。
