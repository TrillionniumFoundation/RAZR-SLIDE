# 对置棘爪侧向导向面 — 2026-10-15

本轮在完整root-clearance根座上增加四处有限平面导向带及一条外侧连接脊，不切削任何旧零件。
左右外根座各增加约3.7816mm3，21个其他模板保持原实体。缺少连接脊时，两块外侧导向块悬空、总计三实体；该方案被拒绝。

原姿态不转动且导向带仍重叠时，PAWL纯X位移±0.05mm接触，±0.06mm发生实际材料相交；旧根座同条件不相交。
八个实际平面、16个边界/越界原生试验和最坏轴向导向重叠共同支持此条件结论，不是所有六自由度/力学资格。
这些潜在接触法向的方向矩阵秩为3；新增面单独不约束Y平移、允许的Z平移或绕X转动。
中心间隙姿态不意味着所有这些面同时接触，更不意味着已实现预紧/形封闭/有载保持。

本轮有明确代价：原界面相对刚体误差框X±0.03/Y±0.05/Z±0.02mm及整段轴向运动的最小包络间距从0.05降为0.02mm。
前者是旧非承载让位面规则，后者是本轮新增有意导向面的余量。旧0.05证书不再对新根座宣称通过。
此处换取更小横向空行程；没有把误差框误称实际自由游隙，也没有供应商尺寸、形位、转角、磨损和热变形资格。

隔离环境20项新测试、23模板子集独立重读通过；不是局域网执行或完整609项重跑。
托管执行将检查完整旧79实体场景、新侧向接触边界、STOP对新增材料的完整运动、早期根座合拢及14步背板装配。
完整结果以实际CI和后续SUMMARY为准，不从配置数量推断通过。原所有测试与原生任务保留。
