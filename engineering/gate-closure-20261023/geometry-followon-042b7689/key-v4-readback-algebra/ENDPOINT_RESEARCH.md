# KEY 端点有限接触面与有界延拓研究

## 已经实际计算的结果

本目录只读固定提交 `042b768903cccbd7a0995317c8598401e0318e2a` 的原生 STEP
文本、原四个 cam profile 和输入清单。`endpoint-extension-research-report.json`
重新核对实际归档成员字节、有限平面及其完整闭合 LINE 边界，再按全部边坐标划分
正交面投影。它没有生成新的整机、调用 Common 或修改生产 profile。

原 KEY 前缘在 Y=14.75 mm；两侧 CAP_0 和当前 ROOT_INNER 的相对平面在
Y=14.73 mm。每侧存在三个有正面积的完整投影重叠面片：CAP_0 为 0.12 mm²，
ROOT_INNER 为两个各 0.08 mm²。名义平面间距由原坐标相减得到 0.02 mm。
计算包含 KEY 的凹多边形完整面，不能用四个角点都在另一面内来替代面积计算。

这个结果给出了 KEY 偏移 dq=-0.02 mm 时的对向面重合位置。它还不是全局第一
硬止挡定理，也没有证明所有其他材料在到达该位置之前都无干涉；接触力、变形、
制造公差和强度均未由这些面数据推导。

另一次、独立保存的小型 native 读取已经恢复四个旧 Common STEP 的有效性、
完整 solid 数和体积：对应结果在交付包的 `run-key-common-readback-042b7689-v2/`。
原文件体积依次约为 0.001238206264、0.001650941685、0.001238206264、
0.001650941685 mm³，全部高于原 1e-7 mm³ 阈值。这里的对向面与这些原文件的
位置和体积相符，可以支持 CAP_0/KEY 和 ROOT_INNER/KEY 的候选解释；旧试验
丢失了逐对原始报告，因此原 pair ID 仍未恢复。

## 保留完整原槽约束

令 dq 为 KEY 的端点外偏移，dx 为相应 crosshead 偏移。原名义两槽约束为：

```text
a = (0.425 - 0.4) * hypot(1, 12 / 79.75) = 0.0252814320072192 mm
b = (0.425 - 0.4) * sqrt(2)              = 0.035355339059327334 mm
h = a + b                              = 0.06063677106654654 mm
abs(dx) <= a
abs(dx - dq) <= b
```

`coupled_domain` 保留这些耦合不等式，没有把独立的 dq、dx 矩形当作可实现姿态。
STOW 全负向域 dq∈[-h,0] 分为 [-h,-0.02] 与 [-0.02,0]，两段都保留。分段用于
后续接触/拒绝分析，没有缩小原槽间隙，也没有把近端段提前标为无碰撞。OPEN
保留 dq∈[0,h] 的相同耦合域。

## 有限 floor 能支持什么延拓

原四个 KEY floor 的局部 q 范围约为 [-0.0011145618,0.3] mm。若仅将 STOW
原平台分支向负 dq 延拓，原 pin 切点相对 KEY 的 q 为 `pin_q-dq`。完整负向槽域
要求该切点覆盖 [0,h]，它确实落在原有限 floor 的 q 范围内。因此，q<0 的软件
拒绝不能直接当作已经证明的实体止挡。

`extended_contact` 是独立研究函数，在明确的耦合负向范围内返回原平台高度和
零斜率，同时拒绝越界、非有限值、错误 floor 区间及错误半径。原生产
`ContactProfile.evaluate` 仍严格拒绝 q<0 或 q>12，相关负例验证了这一点。

完整 pin 不是一个切点。原圆柱面 radius=0.1 mm；真实 STEP 顶点导出的轴向
e 端点约为 [-0.85,-0.18] mm，超过 floor 的 e 区间 [-0.6,-0.2] mm。报告显式保存
原圆柱面、所有实际顶点、轴、位置和半径，并记录候选整圆柱的保守盒：完整负向域
q 投影约为 [-0.1,0.1606367711] mm。该盒只包住所声明的候选圆柱材料；它不是
原完整 STOP 的内部判定，也不构成完整 pin/KEY 无交叠证明。原 STEP 的 BRep
有效性和完整 STOP 关系没有在这个纯代数 helper 中重新计算。

OPEN 的研究延拓只保留原 `lower_stop_height` 选定分支。它明确不声称有限 floor
持续接触、恢复力或实体下止挡得到证明。连续整场检查仍然可以利用现有名义材料
模型推进；物理恢复力和制造资格属于另外的实测/边界条件义务。
