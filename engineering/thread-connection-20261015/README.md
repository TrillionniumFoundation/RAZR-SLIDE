# 有限啮合、螺旋导程与预紧窗口研究

基线 d580094f5bb99764259aee979591c60aea6a9bca。当前主干几何仍是 SNZS-M1-3/SHNS-M1；本增量不改变任何CAD生成器、原生模板、原实际装配/载荷登记或工作流。4mm螺钉只保留为独立候选。

## 计算实际做了什么

integration/frame_thread_budget.py 区分名义实体重叠、完整牙形轴向重叠和真实线程能力。以螺钉头承压面为唯一基准，完整外牙区间为[头下不完整长度,L-牙端不完整长度]；内牙为[夹持距离+入口不完整长度,夹持距离+螺母高度-出口不完整长度]。共同基准只使用一次，不把关联误差重复相加。独立区间盒上的最小重叠精确计算；最大重叠另用对齐端点计算，测试用独立线性规划复核40组参数盒。

导程模型使用未取模的相对角度: residual=dz-pitch*(screw_angle-nut_angle)/360。它不是焊死连接，也不把光孔当作无限自由滑动。它只在假设已啮合的同一导程分支上使用，不提供真实牙面、摩擦、自锁、预紧或材料能力；完全脱开时不保持该约束。不能把轴向多走一螺距后几何相位重合误说成整段退出路径通过。

预紧窗口反算沿用现有roof_joint_budget的闭合双弹簧模型，并显式计入载荷分数范围、预紧散差、松弛/热增减及夹紧余量。框架螺钉实际载荷不能用法向线性规划得到的最小反力直接替代。扭矩窗口不默认K=0.2，不把0.02Nm目录上限当成设定值。范围可能为空，不能以平均摩擦系数掩盖。

## 目录与假设严格分开

NBK公开SNZS-M1-3与SNZS-M1-4均为M1x0.25、头径1.8/头高0.45mm，长度分别3/4mm；SHNS-M1对边2.5、高0.8mm。网页并未提供本计算要求的完整牙端、生产批次公差和预紧数据。

仅在明确的假设盒中比较：L=标称±0.05mm、夹持距离[1.96,2.04]mm、螺母高度[0.75,0.85]mm、外牙两端不完整区各[0,0.5]mm、内牙两端各[0,0.1]mm。3mm候选完整牙形轴向重叠下界0.31mm，上端完整覆盖余量-0.44mm；4mm为0.55mm和+0.56mm。这个结果不表示供应商有这些公差，也不表示3mm实际产品已失效。

4mm不会创造更多螺母材料：在无牙端损失的同一名义尺寸下，两种长度重叠都只有0.8mm；改变的是牙端余量。实际输入文件继续null，啮合和预紧均返回undetermined。有效牙数、真实配合等级、抗拔和安装扭矩未给定。
