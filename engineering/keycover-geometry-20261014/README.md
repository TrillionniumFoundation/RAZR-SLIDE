## 为什么不能继续只挖槽

从实际KEY中取三个完全包含于原实体的重叠长方体，其精确q方向0–12mm扫掠把原外盖包络分成两个空间。两块保留底板分别属于不同空间，最小间距约0.18mm。该证据不依赖保守圆柱包络，也不声称改变KEY或扩大外盖后仍然无解。

## 固定近端U形连接

保留原外盖两块底板及孔位，沿两侧上缘增加固定连接筋，在KEY行程近端跨接。外盖自身q下界从1.7变为-0.4mm，即增加2.1mm占用；当前局部23零件研究装配外包络实测不增大。这个边界不能被说成真实手机内腔已经容纳。远端绕接的3.5mm扩展预检保留但未采用。

每侧外盖只移除原KEY运动碰撞区0.048mm³，新增1.848mm³，原两片全部保留并重新连成一个有效正实体。外根座KEY槽再移除0.026mm³，来自此前新增连接片，原v9根座材料额外移除量为零。两侧共42个非修改零件全部独立比对一致。

保护区域覆盖完整旧底板和原孔位，几何未变；未宣称真实螺纹、预紧、工具通道或强度合格。连接筋截面为名义0.3×0.4mm，连接路径变化后的刚度、疲劳、公差和加工尚未验证。
