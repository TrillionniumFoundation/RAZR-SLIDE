## 接触分支与假设

原生圆销半径0.1 mm、槽底斜率2、下平台高度1.04 mm、平台拐角q=-0.0011145618 mm。STOP0原生home高度1.14 mm，下止点-0.02 mm；STOP1整体高5 mm，运动规律相同。

令销心相对KEY的位置x=-q，r=0.1，m=2，槽底拐角a=-0.0011145618、h0=1.04。斜段销心高度为h0+m(x-a)+r*sqrt(1+m²)；圆角段为h0+sqrt(r²-(x-a)²)；平台h0+r；未接触时保持下止点。三个连接位置q约为0.0011145618、0.09055728090、0.64291796067 mm。

圆销绕拐角的轨迹半径等于销半径，完整销材料包络由2r扇区和端部圆柱构成；其余直线分支由完整圆柱平移包络构成。STOP其余部分全部按三个e区间计入保守盒形运动包络，不丢弃任何材料。这些包络只用于证明/拒绝名义几何，不是额外装入的实体零件。

斜段与圆角、圆角与平台在该模型中C1；下止点开始啮合处只有C0连续，速度斜率有变化。真实恢复力、接触分支选择、摩擦、惯性冲击、弹簧/支撑刚度、夹具和疲劳未被这些公式证明。OPEN没有在本轮取得连续接触证明。
