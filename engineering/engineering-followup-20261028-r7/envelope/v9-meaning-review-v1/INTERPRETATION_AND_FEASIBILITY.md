# V9 的零上界、u=0 和整帧剩余量分别表示什么

本说明只读保存的原件与源码，不重新运行几何算法。全部精确有理数、
13 个输入身份、逐项计数和源码判据保存在
`R7E_V9_PROOF_AND_SPATIAL_CONTINUATION_READBACK_V1.json`。
下文小数仅用于显示，判断使用原始 exact 值及原 float64 `1e-7`。

## 选中的旧叶已由原空间规则排除全部正体积

V9 的 single 阶段只继续处理 case-028/frame-1 中的一个 V6 保留叶：
原 locator `[76,47]`。该叶原来因 V6 路径深度达到 24 而保留，原正向
体积约为 **0.0035074449511051124 mm³**。原记录没有宣称材料干涉。

保存的 V9 树有 81 次细分和 82 个 excluded 叶，没有 retained 叶。
82 个 excluded 叶的 exact 体积之和严格等于这个旧叶的原体积；保留
正体积和为 exact 0。新增最大深度为 19，从原 V6 根累计为 43。

最终保存的每个叶证明都使用原空间分离规则，所有码均在 `0–7` 中。
这些码逐项覆盖该通道对应材料的完整原载体集合，没有最终保存的 `u`。

| 最终叶证明种类 | 叶数 | 完整空间码数 |
| --- | ---: | ---: |
| side 0，axis 1，end 0 | 38 | 每叶 523 |
| side 1，axis 0，end 1 | 44 | 每叶 179 |
| 含原非轴支撑码 6 或 7 | 66 | 6 共 38 次；7 共 28 次 |
| 仅原坐标分离码 0–5 | 16 | 无非轴码 |
| 含新 UV 证明码 u | 0 | 0 |

全部 27,750 个最终空间码的分布为：0 有 13,209 次，1 有 12,621 次，
2 有 891 次，3 有 503 次，4 有 296 次，5 有 164 次，6 有 38 次，
7 有 28 次。空间规则采用对开放通道有效的非严格端点分离关系；所有
原闭边界和切平面作为零体积载体保留。源码和实际证书均明确
`whole_closed_cell_disjoint_claimed=false`。因此 exact 零体积上界不
等于整个闭单元没有接触点，也不能被改写为 native BRep 材料空交。

## u 门要求的是新方法留下最终证明

V9 实际调用过程中有 413 次局部 UV 分离成功，但它们发生在最终没有
完成整个材料通道证明的中间尝试中。最终 82 叶的证明不需要这些 UV
证书，所以最终保存的 `u` 数为 0。现有计数不能恢复每一个中间成功
的面身份，也不能把中间成功数当作最终独立证明数。

原 V7 与 V9 驱动器的 first-u 条件 AST 完全相同。它同时要求：

1. 新排除的开放叶正体积大于 0；
2. 该 single 选中叶满足原容差；
3. 最终 excluded 叶至少保存一个实际新 UV 证明。

前两项从已保存数学结果看为真，第三项为假。这个门是在检查新增 UV
方法有没有产生最终保留的证明，**不是物理干涉判据**。不能把 `u=0`
解释成选中叶中仍有正体积未排除。

此外，实际驱动器连这个门也没有走到：独立数学 worker 完成并与生产者
一致，但其 owned 监督器在进程退出采样中遇到缺失 `VmRSS` 的异常。
驱动器先因 `verify-single` owned 阶段失败停止。真实 owned 失败、
数学 worker 完成、以及事后可读到的 u 判据为假，是三个不同事实。
本说明不重跑、不豁免、不更改任何一个事实。

## single 的零上界不是整帧零上界

原 V6 的 case-028/frame-1 有 **3,511 个保留叶**。其保留体积和及整帧
条件上界均约为 **0.004396435272042011 mm³**。

V9 single 源码先把输入叶过滤为 `[76,47]`，然后令该阶段的
`upper = kept`。它没有把其他 3,510 个旧叶纳入 single 的新上界。
所以 single 报告中的 exact 0 只对应这一选中叶。

仅作体积账目的算术替换，其他旧叶仍剩约
**0.000888990320936899 mm³**，显著高于原 `1e-7` 容差。该算术值
不是一次新运行产生的正式整帧证书。原 V9 的全帧阶段没有执行，原
primitive/trim/native 语义限制也没有消失。

原 V6 保留原因是：313 叶因 tiny 阈值保留，3,184 叶因深度 24 保留，
14 叶因全局 split 额度保留。tiny 叶总和约 1.1870e-14 mm³；主要剩余
问题不在这些 tiny 叶，而在大量深度限制叶和少量 split 限制叶。

## node 0 的几何含义与下一有限候选

另一个已完成并独立审读源码的有限诊断证明：node 0 的 face 41/42
完整闭目标与全部原边界 cover 分离，其固定点对原 outer wire 的
绕数为 −1；face 37/39 固定点绕数为 0，但各有两个原 Circle 参数点
被有向区间严格证明进入完整目标。38 条完整原 Line 均未接触目标。
四面都没有 inner wire，原 gap/arc 的点避让同伦条件均可证。
这不能转成 native 填充语义，但足以排除“node 0 只是 cover 过宽”
这一简单解释。

81 个实际保存失败前缀中，新增 face 27 / model 6 作为首阻挡的记录
是 **0**。不存在可据此选出的“首个 face 27 失败前缀”。这也不等于
face 27 从未被测试；成功的中间前缀没有完整逐面保留。

一个可预先确定的不同候选是 **node 51**：在两个 z 方向原面均首先
受最后一个 Circle patch 63 / UV piece 205 阻挡的 40 个原节点中，
它的原 node_id 最小。它位于原树深度 8，路径和每个原切分点均保留。
node 0 的首阻挡是 patch 58，node 51 已走到原弧的最后一片，因而可
用同样有限的精确方法检查弧端点与闭合 gap 附近的载体保守性。

待检查的具体包含关系仍是：原弧包含于原角片 box 与径向 slab 的交，
而实际目标的完整 affine-plane preimage 包含于旧 inverse-box UV
矩形。两端的包含都可能严格；也可能仍有真实原弧点进入目标。下一
合同必须同时保留这两种结果，不能预设它会产生 `u` 或调换原通道顺序。

## 独立命名的原空间续分实验：可以定义，尚无全预算成功依据

原空间规则可以形成另一种独立命名的实验：继承并独立重验原 V6 完整
材料载体及 V9 保存的 82 个原空间证明，在其他旧叶上继续使用原
坐标/非轴规则、原通道次序、原切分规则和原 `1e-7` 上界要求。
这个实验的目标是整帧原模型的条件体积上界，不能称作 V9 或 UV 方法
资格通过，也不能取消原 first-u 门。原 V9 的两个真实失败继续保存。

若采用原已允许的追加 4,096 split / 每旧叶追加深度 24 / 两类各
12,000,000 的全局计数上限，并累计已经发生的 V9 single 工作，则只
剩 **4,015 split、11,828,571 piece tests、11,657,560 support tests**。
已经花在中间 UV 尝试上的测试不能从账目里删除。已有选中叶追加深度
19 也要继承；其他旧叶必须绑定各自原深度，不能把重复阶段当作免费
重置深度。追加 24 对原深度最多 24 的旧叶意味着从 V6 根最多 48。

仅从原体积分布就能看出困难。按 exact 体积由大到小排列剩余旧叶，即使
假设被处理的每个叶都完全归零，也至少要改变 **2,296 个旧叶**，才能让
未处理尾和降到原容差以下。仅去掉前 30 个大叶后，尾和仍约
3.5879e-7 mm³。3,153 个旧叶具有完全相同的 exact 体积，显示值约为
1.1087838536643396e-10 mm³；其中大量叶共享相同的原失败模式。

这 2,296 个关键旧叶都保存了完整的原空间失败前缀。对相同输入重复
相同确定性规则不能直接把它们改成成功；每个需要改变的旧叶至少要
有一次新的切分。因此剩余额度要求平均每个关键旧叶不超过约 1.75 次
追加 split。现有单个大叶的 81 次 split 不能证明这一条件。

若错误地把已处理大叶的成本等比例乘到 2,296 个叶，连同已处理叶
会需要 186,057 次 split、786,584,680 次 combined support tests，
明显超过原预算。这个数字是反对简单外推的算术场景，不是运行预测。

已有真实性能数据说明计算环境可以执行有限验证：原 V6 owned 全阶段
约 62.32 秒、183 MB 峰 RSS，执行约 8.63M 支撑测试；当前 V9 producer
数学 worker 约 5.15 秒、132.5 MB。它们不构成后续复杂有理数运算、
输出大小或收敛速度的硬保证。原 600 秒/768 MiB 和实际容量闸仍必须
逐次执行。

合理的下一容量证据是预先选定一个主类旧叶，沿原确定性 cut 做一次
split，检查两个子叶，记录完整失败/成功、实际计数和所有保留量。
其结果可以支持或否定“约一次或两次 split 足以处理主类”的假设，
但不能把代表叶的成功复制给其他叶。全帧实验仍需要独立合同、完整
原件绑定、真实监督器及独立验证；当前只读分析没有授权或启动它。
