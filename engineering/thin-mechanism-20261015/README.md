## 实际空间取舍

每侧静态e/q/r外廓由12×15.8×21.21mm变为6.6×30.6×21.21mm。
厚度减少45%，代价是q方向平面占用扩大；不声称外包络总体积或质量同时下降。
KEY、PAWL、原止挡接触核心及螺钉标称尺寸保留。簧座、支撑、下层盖螺钉和盖件边缘重新设计；
没有用整体缩放、逐个移动零件、抛弃断开实体或依赖当前姿态的实时切削来取得通过。

6.7mm深度来自上一轮显式假设的自研空壳，而非实测OEM成品。新候选总名义深度余量0.1mm，
两面各0.05mm，不是合格加工公差、变形、温升或载荷预算。两组机构暂在A研究内腔中作排布，
不是已经固定到壳体或完成KEY到B舱79.75mm滑动/8.2mm就位的物理接口。
`integration/assembly_inputs.json`保持原字节，真实器件/成品空字段仍未验证；研究体积不换算4700mAh。

## 保留的失败与证明边界

36份开发过程源码/日志/原生反例保存在 `rejected-development.tar.gz`，逐件索引为 `rejected-manifest.json`。
包含保持槽悬空、棘爪撞新支撑、根座装入撞STOP、开槽后断开、早期旁路未连接及错误盖板进入方向。
原生扫掠错误没有转成零干涉。最终根座路径使用相对障碍物运动进行同等几何检查；不声称修好了旧内核错误。
四种损坏输入（缺件、NaN边界、假体积、STEP字节变化）均以退出1拒绝，没有发布通过结果。

生成器：`integration/thin_mechanism.py`。独立读取器：`integration/verify_thin_mechanism.py`。
独立读取不导入候选生成器，但仍使用相同CAD内核与通用几何工具，不是跨内核证明。
装配顺序依赖保持/预压STOP和临时夹持；KEY安装使用耦合接触过程而非独立直线插入。
没有完成真实夹具、完整工具操作空间、紧固螺纹/预紧、加长止挡臂/盖板刚度、疲劳、卡滞或限力资格。
也没有在该内腔装入实际OLED/平面储屏、主板、端接FPC、导轨、桥体、电池或BMS。

下一步优先做壳体固定点和KEY/B舱同版本运动接口，再核算材料/公差/受力与实际器件空间；
不能以当前空壳中名义排布通过替代完整手机可用。A大电池/B储屏、等外包络双舱、单约7英寸主屏目标不变。
`candidate_go=false`、`fixture_fabrication_go=false`、`manufacturing_go=false`；无加工、上电、采购或供应商外发。
