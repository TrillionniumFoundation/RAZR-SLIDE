## Mathematical source review

The helper preserves the true trimmed Line endpoints. Each endpoint is assigned
to a uniquely nearest auxiliary rectangle corner on that segment's actual
constant-coordinate side. The oriented assignments must form one directed
four-corner cycle. The independent checker also verifies its signed area has
absolute value equal to the rectangle's area. The exact maximum endpoint
offset defines the corner radius delta, with four delta strictly smaller than
both side lengths.

Within the explicitly declared model, endpoint joining is restricted to the
four corner squares and the recorded inner wire denotes a removed hole. The
open inward-offset core cannot intersect those squares. Its winding number
is therefore unchanged by the permitted joining paths. This reasoning establishes
core exclusion only under those two model premises; it does not establish how
the native kernel treats the actual ULP endpoint gaps or inner-wire semantics.

The full old stationary face box is projected through an exact affine plane
inverse. Each admitted core lies strictly inside that conservative UV domain.
Subtracting open cores produces closed strips. The final source explicitly adds
the four complete zero-width sides of every core, including portions that may
lie inside a different core. All later subtractions preserve such carriers.
Unsupported, invalid or capacity-rejected faces retain their entire old box.

The independent checker reconstructs these facts from the original projected
face records without importing the producer or helper. It does not require the
producer's particular strip construction. Instead, it checks the complete
Cartesian arrangement of exact UV endpoint strata, including 2D open regions,
1D edges and 0D points. Every required stratum, including every complete core
boundary, must be covered by declared closed patches. This is finite interval
containment, not numerical point sampling.

Each patch is mapped through the original affine plane and intersected with
the original stationary box. Only strict empty intersections may be omitted;
zero-width intersections stay. The moving side receives the complete original
D again. Every old boundary piece has a checked replacement map, and every
original edge and vertex remains unchanged. New model pieces remain subject
to the 1,024-patch and 4,096-piece limits.

All original selected roots are retained in the certificate topology. Every
split has two positive children with exact directed volume conservation;
closed cut planes remain zero-volume carriers. Tiny, budget-limited and other
unresolved positive leaves retain their complete positive volume. Excluded
open leaves require complete independently checked boundary separation codes.
The original float64-derived 1e-7 threshold is unchanged.

## Precondition and execution binding

The workflow is restricted both by its push branch and by an exact repository
and ref condition on the job. Manual dispatch has that same job guard. Its
push path is the single registered RUN_REQUEST path. Permissions remain
`contents: read`; checkout and artifact actions use fixed commit hashes, and
checkout does not persist credentials. The checkout SHA is verified by Git.
The workflow then checks the exact literal final lock SHA before invoking the
driver. The concrete workflow differs from the reviewed template only by that
literal substitution.

The driver checks the locked sources and 19 public inputs, then runs:

1. The original real retained cell 202 of case-001/frame-1 in the new model.
2. Independent verification of that actual cell and its controls.
3. The complete 16-frame source and capacity preflight.
4. The complete original 16-frame conditional model experiment.
5. Independent verification of the full actual result.

Every stage uses the unchanged original supervisor, entry and owned-process
sources. The original 600-second, 805,306,368-byte worker RSS,
7,301,444,403-byte shared-memory ceiling, 104,857,600-byte disk floor,
41,943,040-byte output ceiling, and 4,194,304-byte metadata margin remain.
Missing or zero RSS observations are not permitted. The job's 55-minute cap
provides 300 seconds beyond the sum of five 600-second worker limits; that is
a registered capacity margin, not a runtime guarantee.

The larger phases require actual owned receipts, exact source/report/contract
and output-directory bindings, successful independent single-cell verification,
positive removed volume, an applied face and hole, and the original threshold
pass in the conditional model. The full phase also requires the actual preflight
bound to those same sources. The checker binds the exact selected case/frame,
the complete certificate frame header, all original roots, complete D, model
counts and source identities. Any stage failure stops later stages.

On successful completion, the driver rehashes all locked payloads and public
inputs. The source lock file itself is checked at workflow entry and is not a
member of that final payload list. This review's assurance concerns the bound
workflow, driver and owned-process chain together; no stronger per-component
posthash guarantee is asserted.

## Controls are reviewed source, not executed results

The checker must execute two independent synthetic analytic positive cases:
a complete six-face box exterior channel, and an exact split preserving a
positive tiny leaf. Their rejection controls comprise four channel, five split
and two leaf mutations. These synthetic controls are separate from real cases.

Real certificates supply three phase, two root and two leaf mutations. Four
actual channel mutations require an excluded leaf, and five split mutations
require an actual split; absent prerequisites produce explicit not-applicable
records. For the first actual applied trim face, four additional mutations
alter an actual core endpoint, remove UV patches, remove an original retained
edge or vertex, and alter an actual swept patch endpoint. Missing specific
targets are recorded individually. No missing real object is fabricated.

The final checker source performs these mutations on copied real certificates
and invokes the same independent reconstruction used for the actual result.
It keeps source inputs unchanged. **None of these V5 controls was executed in
this review.** Their execution, outcomes, actual object eligibility and resource
receipts must be established from a later real CI artifact.
