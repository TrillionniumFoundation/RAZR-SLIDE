# V7 静态数学审阅：完整闭 UV 外部通道

本记录审阅另一作者编写的 `planar_exterior_model_r5e_v7.py`、
`planar_exterior_refinement_r5e_v7.py` 和 `run_portable_planar_r5e_v7.py`。
审阅人同时编写了独立的新 V7 checker；checker 的设计合同属于作者说明，
不冒充对 checker 自身的跨作者审计。producer 作者另外对 checker 做了静态接口与算术交叉阅读。
最终机器审阅记录将固定双方实际源码、源锁、只读输入快照和启动入口的字节身份。

**本记录没有执行 V7 模型构造、通道搜索、数值实验、负控或原生 CAD 运算。**
V6 已完成的实际结果仍是条件模型 8/16；原 V3 的 4/16、V4 的失败、
V5 和 V6 尚未通过的帧都保持原记录。下面的静态结论只支持一次保留失败记录的正式试验。

## 1. 被使用的外部连通性命题

设平面中的材料区域为 F，F 包含于已知有界矩形 R，且完整拓扑边界
∂F 包含在有限闭载体的并集 K 内。若闭矩形通道 E 满足：

1. E 包含整个待判断的闭目标 Q；
2. E 连接到一个严格位于 R 外的点；
3. E 与 K 中每一个完整载体都严格分离；

则 Q 与 F 不相交。理由是 E 连通且不碰 ∂F。
在去掉 ∂F 后，F 的内部与其补集的内部给出互不相交的相对开集；
若 E 同时包含材料内点与 R 外点，就会被这两个集合分开，与连通性矛盾。
这个结论不依赖近似多边形填充、绕数、采样区域分类或由线方向猜测材料侧。
它不自动处理无法用注册通道连到已知外部的有界空腔。

F 有界且其完整边界由 K 覆盖是**明确的条件模型前提**。
源码没有从 pcurve 的外观、端点靠近或闭环索引推导原生 CAD 面属于此模型。
原生 face-side、曲线语义、闭合误差、trim 成员资格、编译变换误差仍未验证。

## 2. 从完整三维位移域到闭 UV 目标

原记录平面采用 P(u,v)=O+Xu+Yv。源码针对实际保存的有理 X、Y 求
L=(AᵀA)⁻¹Aᵀ，而不是把近似正交向量当作理想正交基。
退化 Gram 系统不能生成新面证明。

对于闭空间通道 C 和该材料完整的原 D：

- B=(C−D)∩old_stationary_face_box；每轴减法使用
  [C_low−D_high, C_high−D_low]；
- Q=L(B−O)，保守投影整个闭 B，不先以浮点平面距离剔除离面点；
- R=L(old_stationary_face_box−O)，同样保留原点平移；
- 固定侧只使用其实际零位移盒；移动侧保留全部原 D 分量。

任一平面材料点在任一允许 D 下进入 C，则其原位置属于 B、UV 坐标属于 Q。
所以证明整个 Q 在 F 外足以拒绝该空间通道上的整个模型平面载体。
零宽区间保持闭集；严格倒置的 B 不被伪装成新证明。
原空间 AABB 分离规则已经负责空候选交集。

静态阅读时发现 basis 的一句自然语言省略了 `−O`。
双方源码和独立 checker 原本都执行完整仿射投影；已要求冻结前将公式显式写成
Q=L(B−O) 和 R=L(old_stationary_face_box−O)。旧草稿字节单独保留，
最终源锁和设计合同须绑定消歧后的 basis。

## 3. 原曲线和闭合不确定度的完整覆盖

每条原 wire 和每个原 edge occurrence 都必须进入模型。位置为原记录的 identity，
方向支持原 FORWARD/REVERSED，原参数端点不被替换为采样点。
Line 的整个闭参数区间由仿射 AABB 与精确法向支撑覆盖。

Circle 沿其完整原闭参数域恰好分为 64 个闭片，两端和所有接缝都保留。
实际保存的 C、r、X、Y 定义实函数 C+r(X cos t+Y sin t)。
每片采用 24 项 Maclaurin 多项式、分母 65536 的有理中心、
公共 degree-47 Lagrange 误差 |c|⁴⁸/48!，以及完整偏移区间上的二阶余项。
这不把原 float64 方向向量理想化。支撑法向与原 X/Y 的对偶方程精确成立。

producer 用递推求多项式和显式逆公式；checker 用反向 Horner 与有理消元。
两者不是共同导入一份新几何实现。所有盒、支撑和参数区间由 checker 重新构造，
而不仅比较 producer 声明的体积或 pass 字段。

每个有向末端的选中后继，其距离上界必须严格小于所有竞争后继的距离下界。
完整关系还须是双射和单个有向闭环。每个连接都保留两端完整区间的坐标凸包，
再按该凸包最大宽度向两轴扩张形成闭合盒。模糊匹配或不完整环只能保留原面。
这些盒是模型边界覆盖的一部分，不是原生闭合已被证实的结论。

## 4. 两套分离枚举不能混淆

原三维通道是开集；原空间坐标与 slab 规则的 `<=`/`>=` 允许载体位于开通道边界上。
对应闭单元边界与切平面继续作为零体积载体保留。

新 UV 通道为闭集。坐标分离和 slab 分离一律使用严格 `<`/`>`；
与任意曲线片、端点或闭合盒相碰均不能给出 UV 排除。
新 `u` 编码只允许用于已有、已应用、具完整源绑定的 `plane_slab`。
其独立 UV 证明映射必须恰好覆盖所有 `u` 位置，顺序固定，不能遗漏或重复。

原 3D edge、vertex、Cylinder patch 和拒绝应用的新面都不被替换。
因此，平面 `u` 成功之后仍可能暴露原圆弧 edge 的 AABB 阻挡。
这种后续阻挡必须成为真实未决；不能把 2D pcurve 关系推广为未经验证的原生 3D edge 成员资格。

## 5. 完整失败、树与原预算

完整失败记录包含全部 12 条注册空间通道。
对于应用模型的平面 blocker，还须保存并检查全部四条闭 UV 路径及其真实不可分离载体。
预算中止只保存已完成前缀和明确的未完成 piece；它不能生成排除或驱动分裂。

新的根恰好是原 V6 保留叶。旧 root 数组索引和旧 node id 共同定位原叶，
旧 root 自身的 V5 locator 另外保留，不相互折叠。
完整旧 V5/R4 证明与 V6 源边界、旧树由固定的先前独立 checker 重新检查。
每棵新树包含全部节点、两个严格内部且不重叠内部的子盒、完整有向正体积，
以及全部闭边界。微小、深度、分裂或谓词预算停止的正体积都完整保留。

固定源上界为 48 个面、520 个原 occurrence、最多 4064 个 UV piece、每面最多 225 个。
原 4943 个 V6 保留根加最多 4096 次新分裂给出 13135 个节点和 9039 个叶的上界。
空间与 UV piece 测试共享原 12,000,000 上限；两种空间的逐条支撑不等式共享另一个
原 12,000,000 上限。600 秒、805306368 B RSS、共享内存、磁盘、输出和元数据门不变。
这提供有界正式试验的算法依据，不保证 V7 在该时间内完成，更不是实测 V7 容量。

首门固定为 case-028/frame1、原 V6 root 76/node 47、原深度 24 的最大保留叶。
其盒和体积用原精确分数，不能换成四舍五入的姿态或更容易的新样例。
只有实际保留量达到原 float64 TOL、实际新增排除量为正、
且最终保存的排除证明真的含至少一个 `u`，才支持后续全 16 帧预检与全域运行。

## 6. 独立控制的登记范围

checker 登记五个解析正例：完整 box 外部、精确分裂与正 tiny 叶、
box 内部全部保留、完整 L-prism 凹口的 `u` 排除、
L-prism 内部包含 12 条空间失败和四条 UV 失败的全部保留。
解析负控共 21 项，包含严格闭边界接触拒绝、完整 UV piece/map/projection、
失败路径与 blocker、以及原空间通道/树/正体积负控。

实际证书另有 phase、根覆盖、空间通道、分裂、正叶、原面/曲线/闭合盒和已保存 UV 证明的修改副本。
只有真实存在的目标才执行。没有 split、excluded leaf、`u`、Circle 或正 Taylor 余项时，
对应项为 N/A，不计入拒绝数。解析对照不能代替实际证书控制。
当前这里只登记实现；实际执行结果须来自随后独立的 owned worker 报告。

## 静态结论

在已陈述的有界面/完整边界覆盖条件模型内，新规则保持保守性。
已阅读的独立实现与 producer 之间未发现需要放宽域、阈值或原资源门的差异。
最终字节锁、只读快照、入口与同源前提检查通过后，可以运行固定真实首叶实验。
这不构成原生几何、完整连续 G2、器件资料、数值五探针或实物 G3–G5 的 pass。
