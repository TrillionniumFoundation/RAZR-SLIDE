## 控制的实际范围

独立 single 阶段拒绝 17 个真实案例变体，full 阶段拒绝 22 个；full 的五个 split 变体在 single 中因真实 split 数为 0 而明确 N/A。每个 checker 阶段另执行 11 个解析负控，全部拒绝。

新增的完整盒 all-retained／no-excluded 解析正控在两个阶段均实际通过，覆盖 12 条未解通道，并检查无实际目标时的 N/A 路径。它不是某个原 V5／V6 实案分支的覆盖声明。所有新 primitive 负控均使用真实可用来源，包括参数端点、正 Taylor 余项、dual normal、闭 angular patch、原边／顶点和完整 D 的破坏。

## 余叶来源定位

随后对已闭合 V6 原件做了独立于几何搜索的有预算只读定位：180 s／512 MiB 上限，实际 1.953573760 s／173,162,496 B，顺序处理 88,781,379 decoded B。没有重跑 channel、曲线包络或 native 操作。结果和执行源码位于 `retained-diagnostic-v1`。

最大 depth-24 叶为 case-028／frame-1、V6 root 76／node 47，来自 V5 `[28,17]`；体积为 0.0035074449511051124 mm³。其 KEY 的竖向通道被原平面面 37／39 的完整矩形加平面 slab 阻挡；对应外圈各含 15 条线和 3 条圆弧。另一 STOP 组出现面 31／33。STOP 的 r=0.1 圆柱同时阻挡该材料方向。八个原完整 D 的宽度仅为 0、4.44e-16 或 8.88e-16 mm，但全部分量仍保留。

这些原记录支持下一步研究平面非凸外圈的保守外部证书。它们没有证明增加 split 预算或仅增加圆柱 angular patches 就能闭合，也没有证明实际材料发生干涉。V7 的新方法及执行必须另立原件、源锁、容量和独立控制，不能改写本轮结果。
