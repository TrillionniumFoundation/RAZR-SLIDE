## 3. 软件允许域和全部正 q 分段

`COMPLETE_SOURCE_MOTION_DOMAIN.json` 明确分析一个独立层：将冻结 binary64 阈值和系数当作精确实数。它没有声称等于完整 float64 执行接受集合。

令 K 为源码 `12/79.75` 的冻结 binary64 值，A 为 crosshead 容许偏差，B 为 crosshead 与 KEY 相对偏差。精确实数模型有：

```
|dx_s| <= A
|dx_s - dq_s| <= B
q_s = K * slide + dq_s
0 <= q_s <= 12
```

其中 `W=A+B≈0.06063697106654654 mm`。消去共享 slide 和左右各自的 dx/dq 后，完整投影为：

```
0 <= qL,qR <= 12
|qL-qR| <= 2W
```

必要性来自两条偏差不等式；充分性给出显式构造：取共同中心 `(qL+qR)/2`，再构造 slide 和各侧 dx/dq。这没有夹回、外推或改写 profile q。整个 `[0,12]²` 是一个保守放大域，不能当作共享 slide 下的实际独立许可矩形。

每个原 ContactProfile 的 plateau、rounded corner、ramp、lower-stop 四段均完整保留，四个 profile 共 16 段。两个接触的末断点之间 **4.440892098500626e-16 mm** 的小区间没有删除。左右合并后的 25 个分支组合中，17 个有精确可行提升，8 个有完整间隔排除。独立脚本用精确平方不等式验证全部圆角根号范围，不导入 producer 或 profile 模块。

STOP 的 X 平移和 SPRING 包络两个 X 端点分别保留每一分段的上下界。SPRING 是半径 0.43 mm 的几何 OD 容差包络，不是受力弹簧模型。原函数对四个 profile 在 q=-0.001、12.001 的八次调用均真实拒绝。另保留不符合共享 slide 条件的 qL=0、qR=12 反例，以及三个域账本负控。

八个完整 STOP/SPRING 原体的 BREP/STEP 共 16 次新读回完成，完整记录 192 个面出现记录，原 factory 的有向体积和边界签名均满足原门，最大两格式签名差约 3.464e-14。运行 0.949 s、249,638,912 B 峰值 RSS。native AABB 只是诊断，未宣称严格连续包含界。

这里的 cam STOP_i 与 q=0/12 的 panel 行程止挡是不同角色。真实恢复力、预载、弹簧 PN、自由长、并圈长、线径、有效圈数、材料、端部固定、摩擦、实际机构允许域均未补入假数据。

新增 T 显式限定任意连续边/接头路径在完整凸 corridor 内，并定义有向 winding 填充域。严格隔离完整查询矩形后，凸域内保持端点连接的同伦保证 winding 不变。这不是把原 gap 吸附为零，也不是由 native `Closed` 标记推导填充语义。
