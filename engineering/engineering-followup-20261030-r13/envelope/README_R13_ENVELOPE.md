# R13：六个导槽端面的保守连接区间与完整孔域条件证书

## 结果及适用边界

本轮保留 R12 的全部原件、精确端点缝隙和原正贡献账本，增加六个导槽端面的完整连接区间与孔域证书。在明确新增的局部 trim 模型下，每侧整件 KEY 沿名义 `q∈[0,12]` 对固定整件 panel 的条件体积上界，从约 `0.9600000000000029 mm³` 收紧到约 **`3.1510793974117154e-15 mm³`**。新模型下满足原始 float64 `1e-7` 判据。

**实际 native 材料属于该模型仍未证明，连续 G2 保持 false。** 本轮没有证明完整实际 native 材料全局实现该模型的存在性；六个局部参考闭环的存在不能替代完整 BREP 的材料集合一致性。原 R12 较弱前提下的 `0.9600000000000029 mm³` 上界没有被覆盖或改判。两层上界均不是实际碰撞体积，也不是实物间隙测量。

| 层次 | 明确前提 | 每侧条件上界，mm³ | 原 `1e-7` | native / G2 资格 |
| --- | --- | ---: | --- | --- |
| R12 保留层 B0 | 完整紧致材料边界包含在 R12 序列化解析支持并集中 | 0.9600000000000029 | 不满足 | 未证明 |
| R13 新层 B0 AND T | 保留 B0，另要求六个完整 trim 域由明示连接区间中的有向闭环及填充规则实现 | 3.1510793974117154e-15 | 条件模型内满足 | 未证明 |

精确左右有理数不同；报告保存各自完整分子/分母，没有以相同显示小数替代精确身份。

## 唯一处理的阻塞

R12 的完整格网和外部通道分析已把大残余定位到六个导槽端面：`104,109,110,115,118,121`。全 UV 矩形支持会覆盖端面的内孔，从而产生约 0.96 mm³ 过填。该过填不证明材料实际碰撞。

R12 已记录 12 个 native `Closed=true` 的 wire 和全部 48 条有序 LINE edge。精确 binary64 参数运算显示其中 44 个连接不完全重合，最大 UV 分量差为 `3/4503599627370496`，约 `6.661338147750939e-16`。因此 R12 没有把这些线直接当成精确闭合矩形孔。本轮继续保留这些缝隙；没有 snap、修复 BREP 或把 `Closed()` 当作数学闭合证明。

## 新读取与原件对应

`native-attempt1/report.json` 从同一原始 `A_BACK_PANEL.brep` 重新读取全部相关拓扑。实际使用 OCP `7.8.1.1`，没有导入 CadQuery 或重建 factory。

- 完整 panel 仍是一个 native valid、正有向体积的 solid，含 298 个面；这些 native 诊断不被当作形式集合证明。
- 六个目标面的 12 个 ordered wire、48 个 edge occurrence 与 R12 精确对应，无遗漏、无重复。
- 48 个相邻连接均共享同一个实际 native vertex identity。
- 每条边保留完整 pcurve 与完整 3D LINE 的原点、方向、有限参数区间、实际 occurrence orientation、SameRange/SameParameter 标志和两端顶点。
- 所有相关 face、edge、vertex 的记录容差恰好均为原件内的 binary64 `1e-7`。这是读取到的几何元数据，未把验收阈值重新用作自行选择的几何误差。

六个 plane frame 都经精确检查，属于有符号坐标正交基。完整 pcurve 和 3D curve 均为 affine LINE，因此两种表示间的平方距离在有限参数区间上的最大值可由端点精确界定；这不是几何采样。最大平方差为 `1/81129638414606681695789005144064`，约 `1.232595164407831e-32 mm²`，在记录 edge tolerance 的平方内。96 个有向 vertex endpoint 的两种表示也分别检查了完整容差球条件。

输入 manifest 包含 14 个逐字节绑定文件：原 panel BREP、R12 完整边界/投影/正箱/trim 证据、当前命名源码及所需辅助模块。全部原件在运行结束后保持不变。

## 连接区间怎样避免吸附端点

对每个相邻 edge 连接，构造一个闭合凸 UV 矩形，包含：

1. 前一条原 pcurve 的精确有向终点；
2. 下一条原 pcurve 的精确有向起点；
3. 对应完整 3D LINE 端点投影；
4. 两端实际共享 vertex 的整个记录容差球的 UV 投影。

对每一整条 edge，再构造凸矩形，包含完整 pcurve 和完整 3D LINE 投影在记录 edge/face tolerance 下的扩张，并包含前后两个完整连接矩形。全部 48 个连接区间和 48 条边区间都写入 `producer-attempt1/complete_trim_corridors.json`。

这些矩形定义了一族允许的连续边界：每条有向边路径可在对应边区间内变化，相邻边之间可采用连接矩形内任意连续路径。原始曲线、原始方向及原始缝隙全部保留。参考闭环仅为算术证书对象，由未修改的原 pcurve 和明确记录的直线连接段构成，没有把该对象冒充修复后的 native BREP。

因为矩形是凸集，任一允许路径都可连续变形到参考路径；连接端点在同一连接矩形内同步变形，完整闭环在变形过程中保持连接。如果整个查询矩形避开全部边区间，它也避开上述所有变形路径，因此每个允许闭环在整个查询矩形上的绕数保持不变。

程序先证明完整查询矩形与所有边区间严格分离，再用精确有理射线运算计算参考闭环的绕数。查询矩形是连通的，且没有边界穿越，所以参考点的绕数等于整个查询区域的绕数；这里没有用一个空点探针猜测整块孔域。各面的 outer/inner 有向绕数分别为 `+1/-1` 或 `-1/+1`，总和为零。

新增前提 T 明确规定面域由完整有向 wire 的总绕数填充。它还允许记录 face tolerance 范围内的 UV 分量偏移，所以检查前会把完整查询矩形按该值扩张。扩张后的最小严格分离为：

`236117379670180653591/4722366482869645213696 mm`

约 `0.049999799999998935 mm`。这是条件模型的解析区间间隔，不是实际加工或测量间隙。记录 tolerance 也没有被宣称为 compiled evaluator 的已证统一误差界。

完整论证见 `COMPLETION_MODEL_DEFINITION.md`。实际 native 域与该模型的对应边界见 `MODEL_MEMBERSHIP_FRONTIER.md`。

## 完整材料通道与剩余正贡献
