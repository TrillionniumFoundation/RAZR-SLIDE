# R5 固定材料站位三维运动与真实 CAD 反例

沿已选 R50/R47/R46 谱系，对完整上滑 79.75 mm 和法向就位 8.2 mm 路径作 481 姿态 × 323 固定 A 端弧长材料站位计算，共 155,363 点。旧 109 个路径顶点随姿态重分配，不能当作固定材料点。原投影运输截面场的 B 端研究宽轴转动约 79.47°、相邻材料姿态跳变约 100.75°，失败场及原生输出保留。

新增解析 Bishop 场只定义光滑段的最小扭转条件。研究 A 端 +y 边界下，B 端亦为 +y；这不是交付的真实两端夹具边界。两处零半径尖角在 481 姿态共 962 站位记录中保持未定义，frame/curvature/twist 的 NaN 和掩码完整保留，没有插值成有限应变或寿命通过。

实际重建三个姿态的原 R50 108-cell 有限截面实体，进行 4,845 个中心/角点实体点检。969 个中心在对应 cell 内，线性角点对应却仍有 4/2/2 个越界，原失败源与回执保留。三个 STEP 各重新完整验证 110 个正实体（两舱与 108 cells）；五项 A/B 正体积干涉继续拒绝路线，OPEN 的 B 穿透没有消失。解析场、线性角点插值与实际 OCC cell 不是同一个实体，不能互换为通过证据。
