## 已执行修正和双机结果

`dynamic_input_rules.py` 加入了最大总叠层厚度、公差、静态/动态用途、铜型、电镀、宽向/扭转、BM28 信号/电源触点和总电流的明确检查。Sierra 原厂的动态 100×成品厚度建议仅作为通用设计筛查，**没有作为本项目铜疲劳限制**。薄的 FLEX1 能通过这一半径比较，仍因静态用途、ED 铜和缺实际资格被拒绝；FLEX2 的名义半径比较通过后，被真实 +0.05 mm 公差翻转为失败。

Cloud 与 X230 分别真实执行 **13 项对抗测试**和筛查，两个子进程退出码都为 0，4 个固定输入的前后 SHA 不变，完整筛查 JSON 字节相同：`f692c8733dbb72eef126edd62ad5acf7eab3affb21166a76e9c3cc969dc5f074`。两套公开静态模板都未被选为项目动态料。X230 原生 job 为 `1a1348f3c88-1f807d-a19`；完整日志与退出回执均保存，不用 launcher 成功冒充测试完成。

另保留 120 mm 长、每条独立导体满宽 1.2 mm、18 µm 铜的理想双导体计算：假设 20°C 铜电阻率，环路 0.191556 Ω，在 5 A 时压降 0.957778 V、损耗 4.788889 W。该例忽略接触、颈缩和传热，也不是本项目导体尺寸或实测温升；它明确阻止用 BM28 5 A 接点额定值给旧 1.2 mm 研究带承诺载流能力。
