# R4 当前结构与 PAWL 释放域：实际证据和边界

本轮完成了原 R3 标量见证到当前整件材料的补查，并修正了释放域的解释。**产品几何没有修改，panel、K1 KEY、PAWL、TAB 的新增及切除材料均为 0。** 原合同要求 `tab=0` 锁止、`tab=3 mm` 释放；没有发现要求 `tab=1 mm` 已完全释放的条款。因此，部分释放时的锁止接触不能直接当成结构缺陷消除。

本报告的数值来自四次实际原生执行、对应独立读回、运行时前后身份观察，以及两个独立列明前提的精确源模型计算。完整证据入口为 `domain-analysis/R4_CURRENT_STRUCTURE_DOMAIN_RESULT.json`、`release-domain/R4_ORIGINAL_RELEASE_DOMAIN.json` 和 `source-motion/R4_STOP_SPRING_SOURCE_MOTION.json`。

## 2. 一个连续排除子域及其完整父件材料依据

从每侧完整 KEY 和 PAWL 分别登记一个严格内缩的矩形棱柱。直接原生 Common 和缺失材料 cut 均已执行；4 个缺失差都是拓扑空体。独立进程读取全部保存的 STEP/BRep，重新构造登记棱柱、检查双向差、重复包含检查，并确认 X 平移 100 mm 的反控制确实被拒绝。

在**数学刚体源模型**下，对每侧 `q∈[0.3,0.4] mm、tab∈[0,0.5] mm、flank∈[-1,1]`，两个源棱柱始终包含一个固定公共内盒。全部面间余量采用精确有理数检查，公共内盒体积为：

`0.0009119999999999789 mm³`（向下舍入显示），大于原 `1e-7 mm³` 门槛。

这个矩形域应与原 shared-slide、左右偏移和机构约束求交；它没有代替原耦合域。若另外能够给出每个原生父件对该棱柱最多缺失 `1e-7 mm³` **真实体积**的认证，则测度论下界仍为 `V_common_box−2×1e-7`，仍大于原门槛。

这里严格区分三件事：实际有限原生包含证据已经取得；源棱柱的全域数学包含已经证明；原生 cut 数值是否是真实体积的认证上界、原生 BRep 的严格集合语义以及所有编译内核变换，仍未闭合。此项不声称全原生连续证明，也不把这些局部接触棱柱当成全局壁厚检查。

独立源码审查确认了包含面间余量和条件测度下界的方向。标量端点使用实际 Python binary64 运算顺序；没有把它们改写为任意实数仿射式的精确极值。登记的精确坐标盒与原生 `p.box` 构造所得盒的严格对应，也仍在原生语义未决项中。

## 3. 原合同下的足够释放域

原 TAB 重新读取的实际参数为：

- `origin = 0.019999999705881955 mm`
- `slope = 0.35333333352941193`
- `halfwidth = 0.026514670992949907 mm`

使用原求值顺序 `z = origin + slope×tab + flank×halfwidth`，最坏 flank 为 -1。当前整 KEY 的原生 Z 上界为 4.4 mm，整 PAWL 的基态 Z 下界为 3.6 mm。KEY 在源模型中只沿 Y 移动，所以足够的 Z 分离条件不依赖 q。

对 `tab∈[0,3]` 的非负 binary64 有序集合执行精确有理支持间隙比较，得到每侧最小的**足够全件支持分离条件**：

| tab / mm | 源支持间隙下界 / mm | 解释 |
|---:|---:|---|
| 2.2825886910551927 | 0 | 阈值的直接 binary64 前驱，尚无严格正间隙 |
| 2.282588691055193 | 1.1102230246251565e-16 | 首个满足严格正间隙的 binary64 值 |
| 2.3 | 0.006151995830579127 | 原生有限控制及源全域充分条件均有记录 |
| 3.0 | 0.25348532930116763 | 满足原合同的完整释放行程 |

阈值处的间隙只有 `2^-53 mm`。它是运算顺序和已观察支持界下的数学分界，**不是制造、实际容差或控制系统的释放阈值**，也不是实际材料几何的最小必要释放行程。全件源支持条件覆盖每侧所有 `q∈[0,12]` 和全部原 flank `[-1,1]`；原生几何到严格数学支持集、所有编译变换以及其余体对的前提没有在此被省略。

另一个独立源审读程序未导入本轮 producer 或 CAD 内核，用原 whole bounds 和 native-slot 参数逐次执行“精确有理数运算→binary64 舍入”。两侧各 6 个 probe 全部一致，并独立核对阈值与前驱相邻、前驱间隙为 0、阈值间隙为 `2^-53 mm` 及原 u=0/u=3 条款身份。其原字节源码和结果位于 `independent-release-review/`；这项结果仍仅是源支持条件的独立复核。

原 tab=0 的闭态阻挡控制仍为正 Common，q=0 的静止控制清空；tab=1 位于未完全分类的过渡区。原 tab=3 已满足上述足够条件，保持原合同即可。曾讨论的提前释放 PAWL 修剪仅作为未执行提议留档，没有创建候选几何，没有执行切除，没有更改任何原功能面。

## 4. STOP/SPRING 的实际源分段

正 q 的两个 profile 保留 5 个联合分段：双 plateau、双 rounded corner、双 ramp、第一 STOP 已进入 lower-stop 而第二仍为 ramp、双 lower-stop。两个 lower-stop 断点分别为 `0.6429179606749895` 和 `0.64291796067499 mm`；这段 4 ULP 差别未被合并。两个终态的 binary64 delta 分别为 `-1.16` 和 `-1.1600000000000001 mm`。

原代码逐侧按 `sign×delta` 平移 STOP。SPRING 项是在每个姿态重新构造半径 0.43 mm 的 `OD_TOL_ENVELOPE` 圆柱，其端点由原 bounds 和 `min/max(0,sign×delta)` 决定。它没有提供真实弹簧丝、圈数、材料、刚度、自由长、预载或恢复力。这份源运动清单不能用于声称自动回程、保持接触、冲击或强度通过。
