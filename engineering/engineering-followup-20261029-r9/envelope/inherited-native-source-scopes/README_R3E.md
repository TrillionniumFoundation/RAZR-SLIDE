# R3E：原 L1 反例的完整表示与连续载体方法

本轮从原 L1 E17 的 17 个实际 case、53 个原 BREP 和原结果 JSON 出发。最终控制执行为 **v3a**：16 个极小位移参考框架、5 个负体积临时 prism 的原 face、1 个 EXTRUSION 的四个向量，以及 3 个不可能 Common 的原输入，共 28 项具名方法检查完成。原 `1e-7 mm³` 门、原有向体积检查和原 `min(volume)+TOL` 条件保留。旧原生失败没有改写。

这里取得的是**有明确前提的完整参数载体证据**。它没有给 OCCT 的一般 Boolean、原生材料边界一致性、编译后的连续变换舍入或完整 factory 的 G2 发放资格。真实样件、电气互连和 G3–G5 不受本轮结果解除。

## 实际原件和读回

两次独立进程各重新读入全部 53 份选定原 BREP。53 份完整边界记录和 16 份完整 Common／负对照记录逐字段相同。每个进程执行 16 次直接 base Common、16 次未修改的 `strict_common`、16 次同一完整 moving 材料的自交负对照；这里 `strict_common` 的 16 次均走 native Common。全部 base Common 为 0，全部自交负对照大于原清空门。

极小位移并非一律相同：12 个原异常是 Y 方向 `±2^-51 mm`，另 4 个是 X 方向 `2^-50 mm`。部分 KEY/STOP case 在首个失败的 Y sweep 后还有独立的 X 区间；新方法保留整个参数盒。它不把极小量截成零，也不以若干姿态样本代替连续域。

原来的边界读取器没有记录 44 个 BSpline pcurve 的控制参数。另两次新进程完整提取了这 44 条曲线，并要求八个相关原体的完整旧边界记录首先与前次逐字段一致。新增 poles、weights、knots、multiplicities、degree 和实际定义域均被独立读回确认。全部 44 条都是 degree 1、两个 poles、权重 `[1,1]`、非有理、非周期；其中 12 条 STOP trim 的终点超出其最后 knot **`9/9007199254740992`**。此偏差未被夹紧。

## 方法和实际结果

| 原问题 | 新方法的实际范围 | 最终保守上界或结果 |
|---|---|---|
| 16 个极小位移异常 | 原 saved base 的直接 Common，加完整边界在整个微小位移盒中的附加载体体积和 | 最大 `1.1014460786400582e-12 mm³`；16 项均满足原门，16 项完整自交负对照仍拒绝清空 |
| 5 个负体积临时 prism | 从各自原 face 的全部 trim、3D edge 和 vertex 重建独立的有理数载体，显式验证闭合拓扑、方向和有向体积 | 上界约 `1.51362766e-8 mm³`；旧 negative prism 的原生材料检查仍失败 |
| 原 EXTRUSION | 完整 affine／line-basis 表示、正确左右方向的斜坐标支持，保留全部有限 trim 相关性 | 原 `+0.2 mm Z` 和反向各 `1.027743935606304e-8`；`2^-51 mm X` 为 `9.840423253756728e-9`；严格零位移为 `9.840101511124191e-9 mm³` |
| 3 个不可能 Common | 以原 A 的完整表示载体体积作为集合交的保守上界，不使用已失败 C 作接受依据 | case-017/019 各 `9.840101511124118e-9`，case-018 为 `5.2066902074902726e-11 mm³`；均满足原门及原 `min(volume)+TOL`，旧 C 的原门失败保留 |

平面使用完整 trim 参数界构成有理数 zonotope；圆柱和圆边使用其原存储 affine 坐标系下的完整周期环形薄层。环层通过精确逆矩阵包含位移盒，不假定存储方向向量在有理实数意义上恰为单位或正交。其体积使用有向 π 区间。低维载体被显式保留为低维闭集，没有冒称为正体积 solid。

其核心包含关系是：若 `S` 是有界闭材料，`D` 是含零的凸位移集，则 `S+D ⊆ S ∪ (∂S+D)`。原生材料是否确有保存记录所定义的完整一致边界，以及 base Common 是否为可靠集合交上界，仍是单独的未闭合前提。

对临时 affine 薄体，完整 LINE trim 的凸包保留了斜向相关性。face 的 U/V 独立极值矩形只是参数外界，不能将全部矩形角点误认成实际 material。新方法要求有界、完整、一致的 trimmed face 语义，并分别包含所有原 3D edge 和 vertex。左右两侧使用各原 case 自己的 q-law 提供坐标基：左侧 `[12,79.75,0]`，右侧 `[-12,79.75,0]`；这只选择支持坐标，不更改任何运动。

对 12 条超出 knot 的 degree-one pcurve，使用另具名的端段仿射延拓。原版 OCCT `V7_8_1` 的 `Geom2d_BSplineCurve::D0 → BSplCLib::LocateParameter / PrepareEval / Eval` 源码保留了非周期实际参数，限定 span 索引，再以两 pole 的仿射式求值。完整原文、许可证、Git blob 身份与 SHA-256 在科学包中。新边界使用**实际 trim 两端**，而非 last knot。发布源码与安装二进制的对应、浮点执行误差以及原生材料的一致性仍未得到形式化资格。

## 保留的真实失败和修正

- v1 的 8 个 BSpline 类型拒绝保留；其余 8 个 tiny frames 完成条件上界。v1 的 4 个 EXTRUSION 和 3 个 Common 粗载体原门失败保留。
- v2 完成 44 条曲线补全后，10 个 tiny frames 完成；6 个 STOP frames 因 12 条真实 trim 外推被严格拒绝。其斜坐标仍误用了左侧方向，4+3 项粗载体失败仍保留。
- v3 的全部 28 项实际计算完成，但最后的文件身份检查因局部 `Fraction a` 覆盖命令行参数变量而触发 `AttributeError`，真实退出 2，`execution_completed=false` 保留。
- v3a 仅修复上述 runner 变量命名；实际数学模块字节未改。新进程完整重跑成功，最终 28 份压缩完整证明与 v3 保存的 28 份逐字节相同。旧失败和完整修正 diff 均保留。

第一组 native 工作的 30 秒、512 MiB、40 MiB 输出估计被实际超过；实测约 110 秒、820 MB 高水位、单份完整 JSON 65.4 MB。原硬门 `1200 s / 1536 MiB / shared 6.8 GiB`、启动附加 2 GiB 和原磁盘余量保持不变，并未触发。最终纯数学 v3a 实测约 18.05 秒、高水位 276,049,920 B，受另行登记的 600 秒／768 MiB 纯数学合同约束。

## 独立复核

另一个实现没有导入本方法模块，独立复算了 v1、v2 和控制版本 v3a。v3a 的 28 份完整证明覆盖 12,727 个载体出现项、4,883 个不同载体和 12,696 个原表示到载体的包含检查；有向体积、拓扑、完整原位移域和原接受门分别复核。v1 的 8 个类型拒绝、v2 的 6 个外推拒绝以及粗上界失败也被独立保留。v3a 独立数学复核实测约 9.22 秒，峰值 177,438,720 B。

独立源码补充审查确认全部 44 条曲线、12 个真实外推区间、88 个标量支持、六份官方源码／许可的 Git blob、69 份 native 完整记录和 28 份 v3／v3a 相同证明。该审查自己的首版因截取源码范围漏了两行声明而真实失败；另具名 v2 仅扩展范围后成功，失败源码、日志和控制记录仍在完整科学包中。源码语义审查和精确数复算均明确保留原生材料、编译对应和全域浮点误差前提。

控制入口为 `R3E_EXECUTED_SUMMARY.json`；`R3E_ORIGINAL_FAILURE_MATRIX.json` 对应原 25 个独立异常；`R3E_ACTUAL_ATTEMPT_HISTORY.json` 保留各实际版本状态。独立审查绑定单独列于 `R3E_INDEPENDENT_REVIEW_BINDING.json`。完整原件、全参数、原生输出、所有失败和全部具名源码在科学归档中。
