## 3. 两类 stop 的坐标与意义不同

### Cam 的 `lower_stop`：X 向 height 分段

四条原 profile 的共同 `a=0.0011145618000001356`、`b=0.09055728089999172` mm。接触 0 的 `c=0.6429179606749895`，接触 1 的 `c=0.64291796067499`；左右分别保存相同原值，未合并浮点差异。

| 正 q 区间 | 源分支 | 含义 |
|---|---|---|
| `(0,a]` | plateau | 保持 home height；q=0 也在此分支 |
| `(a,b)` | rounded_corner | 原有限半径针沿圆角，保留平方根曲线 |
| `[b,c)` | ramp | height 线性下降，斜率 −2 |
| `[c,12]` | lower_stop | height 固定为原 `lower_stop_height` |

S4 将 `height(q)-height(0)` 乘侧别符号后作为 **STOP_i 的 X 平移**：L 符号 −1，R 符号 +1。进入此 lower_stop 后，L 的 X 位移约 +1.16 mm、R 约 −1.16 mm。源码中的“height”在此映射到 X，不是 K3 的 Y 行程终点。

SPRING 模型是半径 **0.43 mm** 的 OD tolerance cylinder；X 区间端点按原包围盒加 `min(0,move)` / `max(0,move)` 扩展。它是几何包络，没有给出真实弹簧自由长、刚度、预载、力、摩擦或变形解。选定 profile 分支本身要求真实回位力；该力仍未被证明。圆角相接为 C1，进入 lower_stop 为 C0、非 C1，动态冲击未资格。

### K3 的 upper stop：Y 向 q=12 行程接触

K3 upper_toe 在 **q=12、Y=17.38 mm** 与 KEY 前横梁接触。cam `lower_stop` 早在 **q≈0.642918** 开始，此后一直保持到 q=12。near/far 的 q≈3.48219/9.16073 已处在 cam lower_stop，但仍位于 K3 两个 Y 行程终点之间。两者不能互相替代为完整行程限制证据。

## 4. 软件独立输入域及未证明的物理域

原软件具有公共 slide `s∈[0,79.75]` 和公共 descent `d∈[0,8.2]`；`d>0` 要求 `s=79.75`。两侧各自有 tab `[0,3]`、flank `[-1,1]`、KEY 偏移 dq 和 crosshead 偏移 dx。每侧：

`q_side = (12/79.75)*s + dq_side`，且原有限 profile 要求 `0<=q_side<=12`，不夹回端点。

同侧两槽约束同时成立：

`abs(dx_side) <= (.425-.4)*hypot(1,K) + 1e-7`

`abs(dx_side-dq_side) <= (.425-.4)*sqrt(2) + 1e-7`。

因此 L/R 偏移可以分别取值，但共享 s；不能直接把任意 `[0,12]×[0,12]` 当作同一工况可取的左右 q 矩形，也没有要求 q_L=q_R。基于两不等式的实数投影只是软件接受域的实数松弛，未证明与全部 binary64 比较边界完全等价。

每侧 telescope 有三个独立关节，`.1-1e-7<=j<=2.9+1e-7`，同时 `abs(sum(j)-8.5+d)<=1e-7`；两侧共享 d。默认等分分配没有实际机构约束。OPEN 附件要求 `s=79.75,d=8.2`。tab 的软件数值范围允许构造错误释放顺序的几何状态；因此输入可构造不等于无碰撞或物理可达。
