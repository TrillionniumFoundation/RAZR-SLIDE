# 实体防错定位架：r3

端接板r2仅有不对称三孔，缺实体定位销；连接器本身无极性。此修复从两块冻结原生PCB回执读取实际孔位，新增连通底座、三根定位销和四角底板支承，导出实际可编辑CAD源码及三份STEP。

正确Rx180方向可沿2.6→0.6mm安装路径就位；错误Ry180在安装平面下降到2.3mm时已产生真实实体相交，最终相交6.1072561186mm³。49个builder检查包括±0.05mm平移扰动；独立程序不导入builder，从实际STEP重构42个路径位置。Cloud/X230各自真实退出0，3STEP全部9正实体、无自由非实体；96个数值跨机差0，输入SHA保持一致。

`REJECTED_MISSING_PINS_WRONG_ESCAPE.step`保留缺销时错误方向仍能就位的真实反例。定位销只能防止该刚体方向错误；未验证销损坏、板弯曲、倾斜插入、磨损、装配力或26端子实际连续性。

板厚0.8mm、销径1.8mm和相应0.1mm径向名义间隙为研究参数；底座与销尚无选定材料/工艺/紧固及公差资格。STEP内的板体不含铜层、连接器原厂实体、焊料或动态FPC。没有借此更改原机装配。`coupon_fabrication_go=false`；`manufacturing_go=false`。

本修复只解决之前尚未建模的实体防错界面，不把研究台架冒充整机。r2源码和PCB保持原样。
