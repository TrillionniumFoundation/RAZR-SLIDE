真实供应商 STEP 已在 qian-qi 用 FreeCAD 1.1.1 **只读导入**；精确 header／receptacle 配对已核对官方规格。此轮纠正了 R38 只使用 header 盒体的尺寸下界，并把信号、USB、A/B 两电池放电与充电拆成独立接口方案。端接安装、跨舱导体和电源电路仍未制作，`manufacturing_go=false`。

## 对 CAD 的实质修正

R38 的 `6.12 × 1.50 × 0.60 mm` 盒体小于真实 receptacle，长边少 **0.68 mm**、短边少 **0.20 mm**。这个差异足以推翻“header 盒体无碰撞，所以配对座也无碰撞”的推理。真实 PCB、焊料、FPC、补强板、固定罩和缓冲材料会继续增加安装体积；0.60 mm 是配合间距，不是完整端接总厚。

随后已直接执行同一 R38 端点位置的 **10 姿态 × 3 类原创建模空间包络** OCC 复核，原始 A/B 与 R38 旧切削 BRep 均未修改：

| B 舱端接空间假设 | 与未切 B 研究体重叠 | 与 R38 旧切削 B 研究体重叠 |
|---|---:|---:|
| 旧 header 6.12 × 1.50 × 0.60 mm | 1.849895679 mm³ | 0 |
| 配对座下界 6.80 × 1.70 × 0.60 mm | 2.443348436 mm³ | **0.593452757 mm³** |
| 局部禁布下界 7.00 × 1.90 × 0.60 mm | 2.844801193 mm³ | **0.994905514 mm³** |

该反例证明旧研究空腔不能容纳新的尺寸预留区；它是**空间预留失败**，不证明带空隙的原生配对座实体必然相交。没有因此继续挖 B 舱。10 个姿态的其他 A/OLED/FPC 预留区相交为零；完整 PCB/FPC/补强/罩体、公差和连续运动仍不在此结果内。自建空间研究 STEP 已在收纳/就位两姿态导出并成功重新导入，文件名明确为 `RESEARCH_DIMENSION_ENVELOPE_NOT_VENDOR`。

供应商 guideline ETAD-H1016-00 要求覆盖端接区的柔顺压持缓冲、背面补强和局部 FPC 自由度；建议 FR-4 补强至少 0.30 mm 或不锈钢至少 0.20 mm，更薄需咨询厂商。不得把动态应力释放夹具做成直接锁死连接器附近 FPC 的定位柱。24 针 header 的局部无异物区下界为 **7.0 × 1.9 mm**；仍须以最新供货图和实装测试冻结。

正确的结构关系是：舱内静态配对端接 → 保留局部柔顺颈 → 独立夹具承接动态线载荷 → 定长跨舱导体。滑动机械载荷走导轨和双侧捕获结构；8.2 mm 法向就位由导体真实弯扭路径吸收。R44 后背环两端是外部 GHOST 点，未与 BM28 接通；其应力释放长度和引入孔都未获厂商/OEM 许可，不能把两个有效原生零件当成完整装配。

## 独立线路方案

`interconnect_partition.json` 是本轮新增的可审阅接口方案；明确所有位置、铜层、针表、实际负载和资格字段仍缺失。它不是电路网表或已冻结 BOM。

| 路径 | 本轮分区 | 不能混用的角色 | 尚缺资料 |
|---|---|---|---|
| SIGNAL | 独立低速控制/唤醒柔性线及 S_A/S_B 静态端接 | 不承担电池主电流，不承担高速 USB | 针表、掉电 IO 防反向供电、返回路径、ESD 与动态线束 |
| USB | 保留 R22 的 B 舱 PHY/端口局部方案；若实际布局要求跨舱，则使用独立 H_USB 与 U_A/U_B | USB 地/屏蔽不能充当电池主回流 | 必须先冻结版本、速率、差分对数、端口位置及回流，再测 TDR/VNA/眼图/BER/EMI/ESD |
| A 放电 | A 本地 BMS/熔丝/隔离后，经专用正向与回流导体到受控系统电源组合 | 禁止裸 A/B 电池正极并联；禁止沿信号/USB 回流 | 真正电芯、最低电压、持续/峰值电流、铜厚、温升、绝缘与残余能量 |
| B 放电 | B 本地独立保护到系统电源组合 | 不能以 A 的 BMS 代替 B 保护 | 逆灌阻断、失效隔离、欠压和短路台架 |
| A 充电 | 独立受控充电输入/回流到 A 充电控制器 | 不直接连通 A/B 原始 BAT+ | 输入电压、电流、充放电互锁、异常断接及反灌 |
| B 充电 | B 本地独立充电控制器 | 不靠单一共用 BAT+ 线并联充电 | 实际充电器拓扑、共同供电故障和双电池管理 |

“独立”指分离物理导体、接口角色与保护边界；USB/信号共模参考或地屏蔽是否电气相连必须由真实网表定义，本轮没有宣称电气隔离。动态夹具失效、共同固定罩损坏、磨破跨线短路和单一 PCB 旁路仍是共同失效，不能因文件里有六条路径就宣布闭合。

BM28 的 USB4 Gen.2 20 Gbps 系列能力适用于连接器接点设计条件；它不能替代本项目完整 PCBA＋FPC＋双端接链路资格。电源 BM28 候选不能在负载未测、线束未选、插座温升未证实时定案。两电池组合允许受控输出组合，禁止原始电芯直接并联；是否采用 DC/DC、理想二极管或其他实现，需真实系统电源需求后冻结。

## 资料冲突与真实硬阻塞

系列目录与精确料号规格在 10 次配合后的接触电阻、绝缘电阻、冲击条件上存在数值差异。两者都保留；不得挑更宽松数值作为合格依据。下次采购资格需要 Hirose 确认适用修订和测试条件。

现有文件仍无法提供：同版本 PCB pad/焊接/补强/罩体实装；恒定材料站位的三维动态 FPC 铜层、最小动态 R、弯扭寿命；主板/相机/大电池的真实可改边界；两电池 BMS/隔离/预充/反灌/单点旁路台架；完整 USB SI/EMI；OLED 全包络和长期储存/展平/疲劳证据。这些需要供应商资料或样机，软件测试不能替代。

原件附带 Readme 的 3D 模型限制明确要求书面许可方可发布或修改，且要求以最新 2D 图纸设计。私人 GitHub 也是发布渠道；因此只提交原创脚本、事实、尺寸研究包络、回执和原件哈希，不提交供应商原生 STEP/ZIP 或其派生 STEP。原件保持在 qian-qi 既有位置。此前未取得书面再分发许可，未替用户联系供应商。

## 复核入口

`inspect_vendor_step.py` 只读取 qian-qi 既有原件，不导出供应商几何。在能访问原件且已安装 FreeCAD 的授权机器运行：

```bash
QT_QPA_PLATFORM=offscreen freecad.cmd inspect_vendor_step.py
```

原创建模空间复核可运行 `python3 inspect_catalog_envelope.py`，需要 CadQuery 和现有 R39 基线。完整 30 行、基线前后 SHA-256 与 STEP 再导入回执在 `catalog_envelope_screen.json`；真实进程退出码为 0。

FreeCAD 首次启动曾输出 snap 挂载/旧 GNOME schema 警告；有效实体和原件不变回执均已生成。第二次原件复核的真实退出码为 0，实体结果逐字段一致，脚本/回执/原始日志的本地与远端字节哈希相同，见 `BM28_machine_execution_receipt.json`。回执没有装配对准、力、温升、疲劳或制造资格通过字段。所有物理资格维持未证实。
