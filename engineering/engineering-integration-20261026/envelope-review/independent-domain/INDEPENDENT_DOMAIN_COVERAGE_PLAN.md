# 从 nominal SLIDE 到左右独立域的保守覆盖路径

状态：算法设计与源域审阅；没有新增 native CAD 执行。本文件不冻结新运动范围、不宣称物理机构可达性、不把 V4 容量结果或未来九片 nominal SLIDE 结果升级为真实独立域通过。功能源码仍为 S4 `dd7def6e6a4de9f47dc91ca2ab336fb1a8828560`，K1 只是已有两处完整 KEY 的材料替换。

## 1. 三种不同的域必须分别记账

现 V4 和计划中的九片验证调用原 `geometry/slide/slide_domain.py` 合同：`s∈[0,79.75]`、`d=0`、共同 `q∈[0,12]`、左右 KEY/crosshead 偏置全部为零、tabs 固定为 3，左右 flank 与固定总伸长下的关节分配独立。两个 KEY 材料已变，控制域没有变。即使九片的 11,781 对全 clear，也只是这一合同的结果。

真实原 factory 的槽偏置参数是

`x=(s, dxL, dqL, dxR, dqR)`，`q_i=K*s+dq_i`，

`0≤s≤79.75`，`|dx_i|≤a`，`|dx_i−dq_i|≤b`，其中记录的 binary64 常量为 `K=0.15047021943573669`、`a=0.0252814320072192 mm`、`b=0.035355339059327334 mm`。源码还在比较中加入 `TOL=1e-7`。左右偏置独立，但共享 s；不能把 qL、qR 误设为同一个变量。

已有 `S4_SOURCE_DOMAIN_ANALYSIS.json` 的实数半空间模型再与两侧有限 `0≤q_i≤12` 相交，得到 60 个顶点。加入记录的浮点比较阈值后，另一个实数模型也有 60 顶点。这两个 60 顶点集合都没有证明等于整个 binary64 程序的接受集合。

更外侧的槽约束域未加 q 剪裁，有 32 个顶点，其中 24 个至少一侧越过当前有限 profile。`UNCLIPPED_SLOT_SOURCE_DOMAIN.json` 与 `FINITE_GROOVE_ENDCAP_PROJECTION.json` 保留了这点；现有 groove endcap 尚不能证明这些状态不可达。源码拒绝调用不能充当实际止挡。K3 尚为 pilot，因此外侧状态保持“物理约束未定义 / 当前 profile 无法求值”，不能将其删去后宣布全域通过。

上述四份原件位于 `engineering/engineering-integration-20261026/domain/`；精确 SHA 和独立实数顶点读回结果保存在同目录本计划的 `EXACT_DOMAIN_RECORD_READBACK.json`。

## 2. 运动阶段不是一个任意笛卡尔积

`cam_coupling.pose` 要求 `d>0` 时 `s=79.75`。需要分别覆盖两个闭集合，并保留共同边界：

1. SLIDE：`d=0`，s 全行程，左右槽偏置与有限 profile 的源域；每侧三节伸缩的和为 8.5 mm。
2. SEATING：`s=79.75`，`0≤d≤8.2`，左右槽偏置的该 s 截面；每侧 `j1+j2+j3=8.5−d`。

理想十进制伸缩域以 `(d,jL1,jL2,jR1,jR2)` 表示，各侧第三节为余量，每节在 `[0.1,2.9]`。14 个精确半空间的完整五维多面体有 28 个顶点，在 d=0、2.6、5.4、8.2 的顶点数依次为 9、9、9、1。SLIDE 的 d=0 截面只有每侧 3 顶点的独立积，共 9 顶点。SEATING 必须覆盖整个 28 顶点的凸包，不能只检查 28 姿态的 Common。

原 native factory 接受的是带 TOL 的关节范围及总和薄层。把第三节直接代成精确余量，会漏掉这些源码接受的残差状态。面向源码接受集合的新合同必须采用六个显式关节加 d 的总和薄层，或保留每侧余量变量 `rho_i`，并向外覆盖原两次总和比较及其浮点舍入；不能沿用理想五维 28 顶点作为完整证书。

原 factory 另允许两侧 tabs∈[0,3] 与 flank∈[-1,1]。除非有机构和接触证据限制 tabs，完整源码域必须保留这四个控制变量。理想 SLIDE 因而有 5+4+4=13 个连续自由参数；SEATING 是 4 个槽偏置、5 个伸缩参数、4 个手动/flank 参数。浮点总和薄层还会增加形式上的变量数。OPEN 可安装的七件附件是另外的离散参与体合同；154 体 / 11,781 对不能替代含全七件附件时的 161 体 / 12,880 对，安装路径也另需证据。

## 3. 可执行的包含算法

### 3.1 先建立完整材料运动表

按原源码为每一个 whole body 给出相对 q0 的运动表达式，并绑定 S4、K1 q0 材料 SHA 与实际 factory。KEY 用本侧 q_i；crosshead 与所有伸缩分件的 X 位移用 `sign_i*(K*s+dx_i)`；伸缩 Z 用对应累计关节；B 侧全材料用 `(0,s,−d)` 相对基姿态；STOP 及完整增长圆柱用各自 `h_i(q_i)`。tabs/flank 分别映射原完整手动件和平移 pawl。

需要扩展当前仅检查 nominal 五探针的构造验证，使新增独立系数、所有分件、上下边界均对到真实完整 factory。有限 native 探针负责发现实现错误；连续律的依据仍是源表达式与完整材料重建。K1 frozen adapter 能保持真实独立参数，并拒绝 profile 越界，但该能力本身不证明全域。

### 3.2 按实际左右分支分域，不合并微小区间

原四个 profile 的 union 共有五个 q 闭区间。左右 25 组合中，已有理想实数域 17 个非空、8 个精确为空；17 格共 548 个顶点计数（跨格边界重复），每格至多 54 顶点。两终止断点间 `1/2251799813685248 mm` 的细格必须保留。

新浮点外包域加入 TOL / 运算舍入后，重新证明每格可行性；不得把原 8 个空格未经重证直接丢弃。分割 q_i 是实际计算后的 q 坐标。域枚举必须记录完整半空间、父子覆盖与边界共享关系；任何 region cap 或深度上限剩余格保留 unresolved。

### 3.3 对每一实体对投影完整相对运动像

对刚体 A、B，在 A 的移动参考系中固定原件 A0，只需包含所有 `Delta=t_B(x)−t_A(x)`。在某个仿射闭格 C，`M={Delta(x):x∈C}` 等于该格全部顶点像的凸包；支持函数 `max(n·Delta)` 可用精确有理顶点求得。**在顶点处做碰撞测试不能推出内部无碰撞；包含整个顶点凸包的扫掠材料才可用于连续排除。**

首层采用向外包围 M 的三轴区间作低成本间隙检查。若未排除，采用包含 M 的有限盒 / 平行体覆盖，逐片用 V2 的 whole-body 加完整边界扫掠构造 `B0⊕M` 的保守外包。盒本身的所有位移连续点均在内，不能只用两个端点 BREP。必要时分裂源格，保留完整覆盖图。可实现更紧的凸多面体平移扫掠，但须另做全材料包含证明和原 L1 负向 / tiny / EXTRUSION / Common 反例回放，不能直接以较小体积当改进。

三维投影秩最多为 3。相互独立且平移同向的参数先做精确区间投影，而不是枚举其笛卡尔积。SLIDE 的伸缩相对位移全在 Z，可以分别对每侧 3 个顶点求线性极值后相加；SEATING 的 d 同时约束左右关节，应直接对完整 28 顶点求 `c_d*d+c_L1*jL1+c_L2*jL2+c_R1*jR1+c_R2*jR2` 的极值。若为安全采用更大的独立外包，要记录丢失的相关性和由此产生的 unresolved。

### 3.4 保留非线性相关性

plateau / ramp / lower-stop 格中的 h 是常值或仿射。rounded-corner 的 h 含平方根，不能把非线性像只用顶点凸包代替。第一版可用有向区间高度外包；更紧的版本以 h 为提升变量，用凹圆弧的弦线下界、切线上界及严格向外舍入构造多面体外包。须证明整个区间的正 radicand、曲率、根运算界和 branch 连接误差，记录所有 native 浮点偏差；端点数值吻合不是证明。

同侧完整 KEY/STOP 与 SPRING/STOP 仅依赖 q_i，若材料重建与源律检查通过，L3 的相关包含论证可作用于投影后的完整 q_i 范围，其他自由度在这一对的相对律中消失。这是可复用的主要降维。跨侧 KEY/STOP、两个不同 profile 的 STOP / SPRING 或其与 telescope 的组合不得套用这条同侧规则；必须保留实际 qL / qR / d / joint 相关性。

FPC 与 OLED 会随 s、d 改变形状，不是将同一刚体沿上述 Delta 扫掠。原 SLIDE 的有限材料 cage 合同只覆盖原 d=0 构造。SEATING 需要新增完整曲线、截面、厚度及自交范围的包含证明和真实 factory 重建；未证明的 cage 记 unresolved，不能用两个端态或包住若干控制点代替全材料。

## 4. 浮点接受域与 CAD 数值边界

要覆盖源码所有接受输入，需对原 binary64 运算序列建立向外前像界：例如 `q_i=fl(fl(K*s)+dq_i)`、`fl(dx_i−dq_i)` 与两处 telescope 总和比较。`K*79.75` 的精确实数积与 12 相差 `23/36028797018963968`，而实际乘法可舍入到 12；这已足够说明纯实数 q 剪裁不能直接代表程序边界。外包中可显式保留乘加残差变量并给每次运算可核的有理舍入界，或使用验证过的区间执行器。不得随意选一个小 epsilon 后声称完整。

源参数层的精确多面体证书与 native 几何层是不同证据。V2/V4 的 OCP bounds、cq.Plane 变换、tiny-vector 归一化、Boolean Common 仍是普通浮点操作。当前 padding 和有限读回不是全连续的区间内核证明。若要求形式化 CAD 包含，必须再提供每个修剪面 / 曲面的认证包围、变换误差以及 Boolean 上界证书；未完成前只能称有明确包含构造的 native 数值验证。

所有原有 guard 保持：whole material、每 solid 正有向体积、有效拓扑、Common 不得超过两输入上界、完整 spec / region 的总和 `≤1e-7`，及原资源 / region / 深度限制。不能取 abs(volume)，不能给每个片段单独发新的 1e-7 预算来绕过整体总和。分域、参考系、两帧、所有材料 cage、实例与未决项必须有可逐项重建的覆盖账。

## 5. 容量路线与停止条件

单把 17 个源分支格与 11,781 对相乘，就是 200,277 个 pair-cell 根记录，尚未计递归、柔性材料、Common regions。逐顶点测试甚至更差：548×9×16×11,781=929,662,272 次姿态-体对检查，而且仍不证明连续域。把全 60 motion 顶点与 28 telescope 顶点任意相乘既不符合运动阶段，也已有 19,792,080 对，不能作为计划。

因此先预计算每类相对律的精确支持函数，缓存以 `source material SHA + relative-law SHA + domain-cell SHA + bounds method` 绑定的结果；只对新域下仍不能严格排除的完整实体对构造扫掠。原全 SLIDE 的 12,885/13,770 次轴向排除与 1,236.487 s 只表明这条路径有潜在价值，不能把该排除率或旧时间移植到新域。

V4 先提供当前 K1 的五 factory-law probes、17 对（尤其七 telescope 对）的实际完整 q 时钟、regions、Common 数、导出大小、峰值内存和终止原因。随后独立域 pilot 至少包含：新的偏置极值 telescope、同侧相关接触、跨侧不同分支、tiny 分支、实际丢失原 axis-gap 的 pair，以及 s/d 依赖柔性材料。pilot 的目的同时检查新包含合同和测量各成本类别，不能直接启动所有 pair-cell。

预计容量只能依据这些实测类别给出区间，并保留每个 worker 原 1,800 s、1,536 MiB 及原磁盘 / 6.8 GiB 地址空间限制。九片 nominal 方案本身也须服从 V4 实测，不承诺每片必然完成；若需进一步拆片，只拆完整带覆盖索引的源区间 / 体对合同，不减少原域。任何超时、无效拓扑、缺少材料、区间失败、超过 region cap、深度耗尽或未定义物理状态均保留显式失败 / unresolved。

当前没有批准执行新的独立域大计算。下一交付应先是绑定实际 V4 容量数据的预算表、完整材料运动表、新域外包与覆盖 reader；K3 的机构止挡只有在实际结构、接触和容差证据成立后才能成为新的物理允许域约束。
