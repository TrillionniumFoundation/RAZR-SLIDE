# Power / USB circuit architecture, 2026-10-13

**Candidate for engineering review only. `manufacturing_go=false`. No Gerber, board assembly, cell selection or full USB implementation exists.**

This work replaces the previously unspecified energy routes with a node- and terminal-annotated circuit proposal and explicit placement constraints. It preserves R50, its failures, equal finished A/B sizes, one approximately 7-inch OLED, 79.75 mm slide, 8.2 mm normal seating and A battery priority. `candidate_netlist.json` is an architecture netlist: IC terminals are mapped where a public datasheet supports them, but OEM pins, charger circuitry, pack protection, connectors, PCB positions and component values remain unselected. It must not be imported as a fabrication-ready schematic.

## Circuit proposal

Use **permanently connected insulated harnesses**, with static service terminations, for A discharge and A charging. Eliminate repeated live docking contacts from this candidate. This removes their normal exposure mechanism, not cable-break or abrasion hazards. No nominal mating pad is retained or silently assumed safe.

Each cell remains inside its own pack protection boundary. A discharge passes through two independently controlled source eFuses before the flexible power conductor, then a receiver eFuse at B before the system rail. B local discharge has two source stages before the system rail. Reverse-blocking source ORing prevents the system rail charging either pack through its discharge path. Precharge uses the protected stage's controlled output ramp; no parallel resistor branch bypasses the final isolation cut.

USB input charging is a separate route. Port VBUS passes through an independent sink cut before the charge bus. A charge feed has its own source cut at B and input cut at A; each charger terminates only on its own pack. The charger SYS output is **local**, not directly tied to the common system rail or the other charger SYS output. If charger SYS later supplies the common rail, it must enter upstream of that pack's two discharge cuts and have a separately audited netlist. OTG/source operation requires another correctly oriented, independently cut regulated path; its implementation is unknown. No USB role or speed is downgraded here.

The full-motion copper USB requirement remains. `USB_CROSS_CABIN` provisionally reserves a separate harness, static terminations, reference and shield; pair count, speed and pinout are null. `USB_LOCAL_B` is an old alternative and does not discharge the explicit cross-cabin conductor requirement without an approved topology change. No fault-free motion state commands a USB data disconnect. Fault shutdown may disconnect data and power.

## Newly exposed counterexamples

1. **Pack negative bypass.** A BQ297xx-style low-side protection circuit opens CELL_N to PACK_N. A raw CELL_N connection to signal ground, USB ground, shield or chassis bypasses that protection. The path tracer preserves a concrete cell-to-load loop with the pack protection OFF. All external reference/shield paths must terminate on the protected pack/system side, with raw cell nodes confined to a separate pack module. A “dedicated power return” label alone does not prevent USB or chassis from becoming a parallel current return when the intended power return breaks. Actual routing/current measurement is still needed.
2. **USB/adapter survives a battery OFF command.** The BQ25622 datasheet describes shutdown commands ignored with an adapter present. This candidate therefore gives VBUS its own independent cut instead of counting charger ship/shutdown commands as a physical energy isolation stage. A node trace also demonstrates VBUS-to-system supply surviving disabled battery discharge cuts in an unsafe charger-SYS tie.
3. **Data protection orientation matters.** TMUXHS221F protects its common D+/D- pins against the specified high-voltage event; its D1/D2 sides have a different limit. A part placed backwards does not protect the host. Its candidate pin map therefore places the incoming vulnerable harness on the common side. This only screens a USB2 subsection; no USB3/4 capability is inferred.
4. **PCB bypass remains possible.** Moving two switches onto one board cannot close a raw-rail-to-final-harness short across both. The architecture assigns raw cell nodes, first cut, second cut and final harness launch to separate constrained zones; physical coordinates, separations, insulation and assembly proof are null. The tracer injects the forbidden direct connection and still finds a live route. There is no fabricated assertion that the three R27 shorts are eliminated.
5. **Separate harnesses still share current returns.** The candidate connects protected grounds, so an open H_POWER_A return lets current return through the charging harness ground. This is reproduced with an exact path. A dedicated-return label cannot close it. The proposed independent cut is U_A2, physically before the A power cable launch, driven by a local hardware forward/return-current imbalance detector, with U_ARX retaining B-side reverse blocking. Sensor part, trip level, worst-case latency and maximum energy before cutoff are null. The hardware must either cut before damage to any alternative USB/signal/charge return or qualify those alternative returns for the fault. No fast cutoff is assumed by the graph.

## Sizing and layout work

`design_review.py` calculates the source-ramp capacitance, current limit resistor, conduction loss, residual stored energy and bleed-time requirement only when the needed measured quantities exist. The released product input file contains null values and returns explicit incomplete results. A separate synthetic case verifies arithmetic without assigning those values to RAZR SLIDE.

TPS259470LRPW is a **conditional screened candidate**, not a selected BOM part. Check its 2.7–23 V operating input range and 5.5 A continuous device specification against actual pack voltage/current. Its reverse-blocking function is appropriate for a discharge OR path, not bidirectional charging. Circuit-breaker TPS259474L is a different variant and must not inherit the TPS259470 pin map. Installed thermal rise, pulse SOA, cable I²t, fuse coordination and finite leakage remain unverified. Two identical eFuses also do not establish independent failure behavior without separate enable, sensing, supply and placement evidence.

Layout rules are executable as architecture constraints, not as completed DRC: raw cell rails must not enter the interconnect board; final cable launch must have no pre-cut rail copper; main and charge cuts must have no bypass; USB reference/shield must not tie to raw CELL_N; signal clamps must not provide phantom supply around an OFF cut. Missing exact pad/clearance dimensions are represented by nulls. High-Z data switches have finite leakage; graph disconnection is not a zero-voltage or zero-energy certificate.

Supply pack-module and PCB coordinates, insulation/clearance/creepage and actual raw-rail segregation.
