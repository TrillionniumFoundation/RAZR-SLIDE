## Whole-phone continuous acceptance still required

1. **Nominal path and complete material:** partition the whole path into release, SLIDE, SEAT, OPEN accessory installation/removal and return phases. Generate conservative complete-motion enclosures for every changing FPC region, KEY, crosshead, spring envelope, shell and support participant in a common frame. Use relative motion for pairs of moving bodies; a stationary-world cage alone can create false collisions. Include external/external pairs. Export unresolved positive enclosures and refine them; never convert an unresolved superset overlap into a collision-free result.
2. **Independent manual controls:** current three-state full runs use tabs `(0,0)` at STOW and `(3,3)` at PREDOCK/OPEN, with both slot flanks zero. Cover both independent tabs in `[0,3]`, finite slot flank extremes and the admissible coupled domains. Reuse historical sweep algorithms only after validating source/material equivalence to these changed parts. The complete current PAWL must be included; the old mounted PAWL cannot substitute for it.
3. **Admissible telescope and clearance states:** equal extension is expressly not mechanically enforced. For each seating height, cover all joint allocations `0.1 <= j_i <= 2.9 mm` with `sum(j_i)=0.3+(8.2-d) mm`, plus cam/KEY backlash and permitted flank states. Existing functions validate allocations; the nominal three-pose result is not a universal result over that domain.
4. **OPEN accessory transition:** the five B support pieces and two hold screws appear only at seated OPEN. Validate their assembly/removal paths and interlocks separately. Existing model disallows them at other positions, and no onboard storage is claimed. Reverse occupancy cannot assume they move through SEAT/SLIDE while installed.
5. **Supplier and physical gates:** obtain actual FPC/OLED/connector parts, electrical routing and interfaces, tolerances and material properties; qualify finite-relief strength, assembly process, drive/holding force, hysteresis, relock margin and lifetime on identified specimens. Software geometry cannot supply G1 or G3–G5 physical evidence.

## Reproduce

Use a complete merged checkout with its locked CAD dependencies. Set `EP5_REPO` to that checkout and `EP5_EVIDENCE` to a new output parent outside it. The following runs native full material and then a separate reader; completion can legitimately report geometric rejection and is not release approval.

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$EP5_REPO/integration" python3 -m unittest discover -s "$EP5_REPO/integration/ep5-routing-tests" -v
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$EP5_REPO/integration" python3 "$EP5_REPO/integration/product_routing_ep5.py" --native-local-motion --output "$EP5_EVIDENCE/local"
PYTHONDONTWRITEBYTECODE=1 python3 "$EP5_REPO/engineering/product-integration-20261018/phase5-20261022/read_ep5_step_independent.py" --manifest "$EP5_EVIDENCE/local/native-report.json" --repository-root "$EP5_REPO" --output "$EP5_EVIDENCE/local-readback"
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$EP5_REPO/integration" python3 "$EP5_REPO/integration/product_routing_ep5.py" --native --poses STOW PREDOCK OPEN --output "$EP5_EVIDENCE/full"
PYTHONDONTWRITEBYTECODE=1 python3 "$EP5_REPO/engineering/product-integration-20261018/phase5-20261022/read_ep5_step_independent.py" --manifest "$EP5_EVIDENCE/full/native-report.json" --repository-root "$EP5_REPO" --output "$EP5_EVIDENCE/full-readback"
```

Only for the explicit local recovery case, append `--verified-mounted-members "$EP5_VERIFIED_MOUNTED_MEMBERS"` to the full native command. The reader revalidates that declared input automatically. CI with a complete Git checkout uses the original archive by default. The exact-commit driver has since completed as recorded above; these older R4 working-tree results remain separate evidence.
