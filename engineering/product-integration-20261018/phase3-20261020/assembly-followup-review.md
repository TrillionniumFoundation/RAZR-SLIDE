# B 侧分配、完整端接与薄件连接审阅（2026-10-20）

## 结论与证据范围

现有两条 B 侧 `12 × 68 × 4.4 mm` 区域分别是主板和电芯的设计分配，并非另行留给端接的空通路。完整 EP2 不能靠刚体旋转塞进保持 12 mm 宽度的参考内腔；当前锚点又使 A 端侵入相机/电芯分配、B 端侵入储屏导板。EP3 必须改变实际材料排列，并在保留这些参与体的同一场景中检查。

此前分件装入研究解决的是声明的局部几何顺序。其材料、接头工艺、公差和保持载荷仍为 `null`，不能直接作为已具备材料与紧固依据的加工放行包。

本说明是源码审阅、旧报告边界读取和解析推导；未运行 CAD、测试、FE/QP，也未制造或量测新样件。三个 `prior-scene-*.json` 是已执行 F = `1c970e34a72f83ac1148ed3dee11e050ed5508dd` 的完整分件总装 manifest 提取，原压缩报告 SHA256 为 `90f528b83a2c94fa1a32c2d0b60ad8a74a1ba776541e3fa2dec9aa9171fef837`。它们明确标注 `extraction of already-executed native manifest, no new CAD execution`。本说明不将提取结果改标成新提交上的 CAD 执行。

以下分清三种依据：源码中的有限实体构造；F 报告已经记录的 bounds；从这些输入得到的必要条件或实体内部见证盒。AABB 相交仅用于列出需查对象，不能自行成为实体交叠证据。

| 对象 | B 局部范围 |
| --- | --- |
| 下导板实体 | X `−33.7 … 33.7`，Y `5.4 … 85.9`，Z `5.65 … 5.85` |
| 上导板实体 | 同 X/Y，Z `6.15 … 6.35` |
| 返回 OLED 名义厚度层 | 中面 Z `6.0`、厚度 `0.2`，即 Z `5.9 … 6.1`；实际覆盖 Y 随材料运动变化 |

## 2. EP2 任意刚体旋转仍不能进入严格 12 mm 侧带

依据：`product_routing_diagnostic.ep2_local_parts` 的实际下承载板构造。

EP2 下承载板含 `X = −7.3 … 7.3`、`Y = −14 … 21`、`Z = −1.65 … −1.15` 的有限材料。M2 孔在 Y = 15 / 19；M1 支承台孔从 Z = 0.1 起，不穿负 Z 的底板。取底板平面 Z = −1.4、圆心 `(0, 0, −1.4)`，半径 7.3 的完整圆盘仍在实体内。端接的 A/B 镜像不改变这一事实。

任意刚体旋转后，该圆盘平面总有一条平行目标 X-Z 截面的直径。该线段长 14.6，因此目标侧带的 X-Z 矩形必须容纳至少同长的对角线：

`sqrt(W² + H²) ≥ 14.6`。

| 严格侧带参考截面 W × H | 截面对角线 | 对保留原 EP2 底板的结论 |
| --- | ---: | --- |
| 12 × 4.4 | 12.781236 | 不满足必要条件 |
| 12 × 5.0，下导板以下 | 13.000000 | 不满足必要条件 |
| 12 × 6.7，参考全部内厚度 | 13.743726 | 仍不满足必要条件 |

这是任意刚体旋转的否定条件，不只针对 90° 翻面。即使忽略其余端接零件和全部装配间隙，高度限制为 5.0 时，圆盘要求的宽度下界也为 `sqrt(14.6² − 5.0²) = 13.717143`；高度放宽到 6.7 时，下界仍为 12.971893。实际完整端接可能要求更大的空间。

若只做 XY 平面内旋转，底板投影宽为 `14.6 |cos θ| + 35 |sin θ|`，最小仍为 14.6。

本结论仅否定“保留此 EP2 底板、塞进严格 12 mm 侧带”的方案。它不否定更窄的 EP3 底板、明确改过的舱内布局或其他端接拓扑，也不把参考腔体宣称为已测得的手机内腔。

## 3. 向内或向外借宽度会遇到什么

将宽 14.6 的端接中心放在右侧分配中心 X = 27 时，它占 X = `19.7 … 34.3`，向两侧各超出原分配 1.3。若坚持内边不越过 X = 21，则外边要到 35.6。

### 向外：B 支撑座不是空白

`product_templates` 已将四个 B 支撑螺钉座融合进 `B_SHELL`，即使 OPEN 支撑附件尚未安装，这些座也存在：

- 中心 X = ±34.5、Y = 40 / 70，半径 1.1，Z = `0.6 … 2.15`。
- 座上名义孔半径 0.5，不能把座当作整块圆柱；但外环材料保留。
- 支撑脚/附件在 X 的外延至 ±35.6；OPEN 另有四颗支撑螺钉。

保持当前端接朝向、把 EP2 降到参考地板和下导板之间且不留上下间隙时，完整端接最低 Z 只能落在 `0.65 … 1.00`；底板的 Z 随之位于这一最低面之上 0.5 内，与支撑座的实体高度重合。对 X = `21 … 35.6` 的底板，取支撑座外环中避开中心孔的一点，例如 X = 35.3、Y = 40 或 70，其半径偏移 0.8 位于 0.5 … 1.1 的材料环内，也在底板范围内。任何被限定在 Y = `16 … 84` 内的 35 长区间至少跨过 Y = 40 或 70 之一。因此该“保留朝向、向外借 2.6 并降低端接”的具体方案仍有实体阻塞。

该支撑座反例的朝向与 Y 范围已经明示，不能扩展成所有新端接或任意新位置均撞该座。改变底板方向、Y 布局或支承高度时应重新检查有限材料。

### 向内：必须把 X、Y、Z 的同步运动一起查

F 的已观察右侧随动件边界如下；左侧有相应参与体，检查时不能仅以对称名称替代实际左右状态。以下均为世界坐标，数值按 6 位小数展示。

| --- | --- | --- | --- |
| `R_CROSSHEAD` / STOW | 5.85 … 8.65 | 76.85 … 84.30 | 0.70 … 3.90 |
| `R_CROSSHEAD` / PREDOCK、OPEN | 17.85 … 20.65 | 76.85 … 84.30 | 0.70 … 3.90 |
| `R_TELESCOPE_3` / STOW | 6.85 … 7.65 | 81.10 … 81.90 | 9.20 … 13.20 |

### 还有一个旧报告直接显示的内包络反例

`prior-scene-STOW.json` 中有限 FPC 的 Y 上界约为 **97.740298048 mm**，当时 A、B 两舱 Y 上界都为 **94.25 mm**，带体向头端外伸约 **3.490298048 mm**。这是旧 F 原生 bounds 的读取结果，没有重新生成材料或求碰撞。

## 5. EP3 完整场景不能遗漏的检查

### 5.1 先固定参与体和构造身份

`product_fpc.current_shared_scene` 仍调用原 `product_assembly.product_scene`：常装 94 个机械体，OPEN 附件齐全时 101 个；加四分配和 OLED 后是 99 / 106 个障碍。它不会自动切换到分件入口。

`product_split_assembly.split_scene` 将每侧七个新分件放回实际母件，常装机械体为 108、OPEN 为 115；加四分配和 OLED 后，作为端接/带体之外的障碍应为 **113 / 120**。它同时验证分件对该姿态原母件的双向材料重组。若为节约计算使用未分件障碍，必须明确保留其与分件母材料的对应依据，且不能把 99 / 106 的调用报告写成实际检查了 113 / 120 个独立障碍。

旧完整 EP2 场景总数为 154 / 154 / 161，因为在上述障碍外另含 40 个端接体和一条有限自由带。新 EP3 若增减螺母、背板、支承或导线实体，应由显式部件表重新得到计数，不能强制沿用旧 20 体/端来省略新增材料。

最低比较矩阵：

| 比较组 | 若仍为 20 体/端时的数量 | 用途 |
| --- | ---: | --- |
| A 端组内、B 端组内 | 各 190 对 | 两块 PCB、连接器、补强、尾部、夹爪、承载和全部紧固件互相检查；刚性组内可按同一源码缓存 |
| A 完整端接 / B 完整端接 | 400 对/姿态 | 不省略对端板、螺钉头或静态连接 |
| 有限自由材料 / 两端全部材料 | 40 对/姿态 | 保留 OPEN 的另一条腿切过 B 夹持结构这一类反例 |
| 两端全部材料 / 完整障碍 | 40 × 113；OPEN 40 × 120 | 同时含四分配、OLED、全部机构/壳体和相应附件 |
| 有限自由材料 / 完整障碍 | 113；OPEN 120 | 显示、机构、原分配不能遗漏 |
| 完整柔性材料和端接 / 允许内域 | 按明确的域定义 | 防止壳外绕行被无碰撞结果接受 |

负候选可以在保留参与体身份后用一个可靠见证早停，其余配对应写为未查。若要说新候选某姿态全部清零，就必须完成该姿态所声明矩阵；native 失败不能转成“没有交叠”。零 Common 仍不是正间隙，也不是连续运动证明。

### 5.2 材料坐标必须随端接方案一起改变

旧 `material_return_sections` 明确要求 A/B 同 X、正 Z 层间距，宽度固定 +X，中心线在 Y-Z 平面。`route_pose` 不读取 JSON 的 `tangent_A` / `tangent_B` 来构造任意方向，而由该固定模型生成 +Y / −Y 两端切向。因此：

- 只把 B 端移到侧边、A 留在中央，旧路径函数不再成立。
- 单独旋转刚体板夹而不重接有限尾部、补强和刚柔转换，可能得到不连续的假总装。
- 若只旋转板对而保留端夹方向，板到焊盘之间的静态导线也必须有完整端点、绝缘外径和有限路径，不能只移动一个预留盒。
- 旧 `finite_material_solid` 是实际离散材料站截面多边形的宽度挤出，不是光滑曲面的保守包络。要排除站间穿入，需有明确误差上界或连续包络方法。
- 对仍采用旧 G2 拓扑的方案，改变自由总长不改变 `R_min ≈ 0.4365708 ΔZ`。供应商未给动态条件时，不能把较大半径自行转成寿命通过。

### 5.3 最少、有限的后续原生试验

建议先只对一个明确 EP3 候选执行下面的有界流程，另建输出和源码身份，原 EP2 失败证据保持原字节：

1. 输出完整 A/B 端接部件表，确认新增紧固/承载有实际实体；完成两端组内检查，并核对尾部、补强、焊盘与材料端点坐标一致。
2. 在 STOW、PREDOCK、OPEN 上运行完整矩阵和内部域包含。任一决定性失败即记录并停止后续通过论证；不能因完成了程序就修改候选接受标志。
3. 三态均通过后，再针对已发现的导板、足端、CROSSHEAD/KEY 接近区补检查中间上滑与就位姿态。应说明采样/区间依据，不能把端点检查或少量姿态叫全程证明。
4. 保留左右独立解锁、单个保持螺钉、OPEN 支撑件装入/拆除和反程状态。B 开放支撑的右侧入口、四个紧固点及工具体积属于安装检查。反程仅在材料、障碍和全部手动状态确实相同时才可复用相同姿态计算。
5. 若最终产生样片图稿，单独列出加工版本、成品叠层、端夹保持方式和检查方法；几何候选通过不能代替动态材料或手机接口资格。

本说明没有执行以上试验，也没有为其预先填写通过结果。
