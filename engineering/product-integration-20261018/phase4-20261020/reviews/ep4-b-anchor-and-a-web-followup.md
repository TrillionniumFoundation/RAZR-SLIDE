# EP4 首次 PREDOCK 后：B 锚点/带长无交集，A web 螺钉头退让

2026-10-20。独立纯算术和源码复核，没有运行 CAD、原生主机或实物试验。依据冻结 EP4 模块 `f8286416e8d4f835b5a280f3c76e7dd69aaebda25ac2217f40f33e19e92251b8`，以及父任务给出的首个 native PREDOCK Common 位置。本结论不替换该次原生报告。

## 1. 只调 B 锚点和带长，不能将完整 PCB 移过横壁

固定 A 锚点 Y=51、S 世界 Y=80..90、U 高差3.4、材料厚度0.1、B PCB 材料 Y=24..36、完整端接方向及上滑79.75。只允许改变 B 锚点 Y=b 和自由带长 L。

B PCB 的局部世界 Y 范围是 `[b−36, b−24]`。要把整块12 mm PCB 放到横壁 Y=14.7..15.35 后方，并留0.2 mm间隔，必要条件为：

```
b − 36 ≥ 15.35 + 0.2
b ≥ 51.55 mm
```

沿用原曲线积分，T_U=6.994791409655915，J=0.37095510227064343。有限 U 头超出 U 起点的距离是：

```
C = T_U J + t/2 = 2.644753562730728 mm
E = T_S(8.2) − 10 = 3.656343682694377 mm
Y_U(s) = (L + 51 + b + s − E − T_U)/2    [上滑阶段]
```

STOW 有限头≤94，要求 `L+b≤142.36162796688882`。

PREDOCK 的 B 尾直段≥3，要求 `L−b≥45.401135092350295`。

两者合并后：

```
b ≤ 48.48024643726926 mm
```

**必要的 B 锚点区间没有交集，缺口为3.06975356273074 mm。** 对最小可越壁锚点 b=51.55，带长必须同时满足下表中的两个互斥条件。

| 条件 | L 的要求 |
| --- | ---: |
| PREDOCK B 尾段至少3 mm | L≥96.9511350923503 mm |
| STOW 有限头不超94 mm | L≤90.8116279668888 mm |
| 两界缺口 | 6.13950712546149 mm |

取满足头部限制的最大带长，PREDOCK B 尾段反而是 **−0.06975356273075 mm**。取满足3 mm尾段的最短带长，STOW有限头达到 **97.06975356273074 mm**。

这个矛盾无需依赖 S 弧长的精密数值：上滑时 S 不变，因此 U 起点恰好前进上滑量的一半，即39.875 mm。头部限制要求 `Y_U(STOW)≤94−C=91.35524643726927`，尾段限制要求 `Y_U(STOW)≥b+42.875`；L和E直接抵消。

**决定：停止以整块 PCB 置于横壁后方为目标的 B 锚点和自由带长搜索。** 本推导只排除题设组合，不判定把 PCB 放到横壁另一侧是否可行，也不排除其它 PCB 位置、方向、Z 堆叠、跨壁开口或不同路径；这些不属于本次计算。

## 2. A web 的实际问题是螺钉头半径，不能用 shaft 孔边替代

A 工厂已经将材料 Y 镜像为负的端局部 Y。第一颗 M2 头的圆心为 `(0,−15)`，半径1.75，Z=0.85..1.45。新 web 为 X=−6..6、Y=−13.7..−13.25、Z=0.8..3.3。中央静态转接窗口已经移除 X=−5.4..5.4、Z=1.1..1.75 的材料。

因此实际 Common 是半径1.75、圆心至弦距离1.3的圆帽，乘以 Z=0.85..1.1 的0.25 mm厚度：

```
V = 0.25 × [R² acos(1.3/R) − 1.3 sqrt(R²−1.3²)]
  = 0.18081185628459456 mm³, R=1.75
```

它与父任务报告的 native `0.1808118563 mm³` 一致，也解释了其 X边界约±1.17154。此前0.2 mm检查只针对R1.1 shaft孔，未覆盖实际R1.75头；该检查不能作为头部无交叠依据。

## 3. R1.95 头部退让保留两侧几何连接

在 A 端局部 `(0,−15)` 沿+Z切除 R1.95、Z=0.85..1.65 的圆柱。0.85保持头部承压面；头部以上的0.2 mm轴向退让位于已有中央窗口内。因此相比Z终点1.45，延伸到1.65不再多切材料。

父任务的 `/workspace/scratch/5547df349f5a/razr_phase4_root/ep4_a_head_relief.py` 按上述端局部坐标切除、检查20体190对、侧柱与承压环，并记原体/去料/新增/新体账，未发现坐标或探针逻辑阻碍。提出的一处语义修正是：只有实际新增材料为0时才给出严格材料子集结论；仅 `added≤1e−7` 应称为“容差内未见新增”，不能直接用作严格子集证明。该建议已通知父任务。
