# EP4 S+U 联合改形：独立约束复核

2026-10-20。检查 scratch 中的冻结 EP3 源码、最终 EP4 实现及纯数学计算；本复核没有运行 CAD、没有操作原生主机、没有执行实物试验。A33 的既有碰撞结果由父任务提供。正文给出独立推导，末节记录最终源码和数值见证。

## 本轮可执行决定

1. A 承载板起点改为材料 Y=13.2，web 改为 13.25..13.7，可按坐标排除旧 A 板与电池分配体的 18 mm³ 交叠，同时保留 web 与夹爪、板的正体积连接。仍需原生检查整个融合体、其它障碍和孔边薄截面。
2. B 的 PCB、板、支撑和完整静态转接均退到自由端后方，不能只移动 PCB。它们在 B 局部世界坐标的最低 Z 为 1.55，而低层自由带最高 Z 为 1.50，只有 **0.05 mm 名义间隙**，尚无制造公差、载荷变形或实测余量。
3. 新 S+U 在声明的有序运动中可保持同一条 100 mm 自由材料路径，且新的 S 消除了旧 PREDOCK 低直段必须在两舱外的那个反例。此结论只涉及两个外包棱柱的并集；棱柱内部的壳体、机构、OLED、占位件均继续是实体障碍。
4. **OPEN 的自由带解析路径与旧 EP3 OPEN 相同。** 因为 S 在 h=0 时成为直线，既有 A_FRAME、KEY、B_SHELL 外部交叠不能靠新 S 自动消失。下一次有限 native 的有用输出包括正 Common 的实际位置，随后才能决定在哪里开口或改形。
5. STOW 的 S/U 中间直段为 0.17443245 mm。有限法向厚度不会再次机械扣掉 0.1 mm 后造成相交，但这个长度不等于能放入导向/支撑件。固定 S 终点 Y=90、有限 U 头上限 Y=94 时，此直段即使调整自由长度也不可能超过 **1.35524644 mm**；如实物导向要求 3 mm，单改带长已被排除。

## 1. 采用的几何与材料坐标

滑动 s∈[0,79.75]；就位只能在 s=79.75 进行，下降 d∈[0,8.2]。令 h=8.2−d。A 自由端世界坐标为 (0,51,1.45)，B 为 (0,40+s,4.85+h)。自由长 L=100，宽 W=12，厚度 t=0.1；这仍是项目假设厚度，不是供应商确认的动态叠层。

路径依次为：A 端到 Y=80 的 29 mm 直段；Y=80..90 的 S；到 U 起点的低层直段；固定升高 3.4 mm 的 G2 U；到 B 端的反向直段。

S 以 u=(Y−80)/10 定义：

```
q(u)   = 10u³ − 15u⁴ + 6u⁵
q′(u)  = 30u²(1−u)²
q″(u)  = 60u(1−u)(1−2u)
Y      = 80 + 10u
Z      = 1.45 + h q(u)
T_S(h) = ∫₀¹ sqrt(100 + h² q′(u)²) du
```

U 保留原弧长参数角 θ(v)=π(3v²−2v³)。I=∫₀¹sinθ dv≈0.486075967227056，J=∫₀½cosθ dv≈0.370955102270643；固定 U 长 T_U=3.4/I≈6.99479140965596。

宽轴全程 +X；单位切向 T 按路径的实际前进方向，法向 **N=W×T**。S 的曲率在 u=1/2 变号，法向不因此翻转。S 中令 m=h q′/10，则 T=(0,1,m)/sqrt(1+m²)，N=(0,−m,1)/sqrt(1+m²)。A 端 N=+Z，B 端 N=−Z，与原端接的有向材料框架一致。

## 2. 固定长度及连续运动的极值

令 E=T_S−10。严格按材料总长分配：

```
Y_U = (L + 51 + 40 + s − E − T_U) / 2
中间直段 m_U = Y_U − 90
B 尾直段 b_U = Y_U − 40 − s
总长 = 29 + T_S + m_U + T_U + b_U = L
有限 U 头 = Y_U + T_U J + t/2
```

独立 128 点 Gauss 积分得到以下数值。32、64、96、128、256 点 S 积分的差异在 3.2×10⁻¹⁴ mm 内；这是数值一致性，不能替代对有限实体或连续碰撞的证明。

| 状态 | T_S / mm | Y_U / mm | 中间直段 / mm | B 尾直段 / mm | 有限 U 头世界 Y / mm | 有限 U 头 B 局部 Y / mm |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| STOW | 13.65634368269436 | 90.17443245382485 | 0.17443245382485 | 50.17443245382485 | 92.81918601655559 | 92.81918601655559 |
| PREDOCK | 13.65634368269436 | 130.04943245382486 | 40.04943245382486 | 10.29943245382486 | 132.69418601655562 | 52.94418601655562 |
| OPEN | 10 | 131.87760429517203 | 41.87760429517203 | 12.12760429517203 | 134.52235785790280 | 54.77235785790279 |

这些极值不是从三个姿态外推而来：

- T_S(h) 对 h≥0 单调增加。上滑期间 h=8.2，Y_U 随 s 以 1/2 斜率增加；就位期间 T_S 下降，Y_U 增加。因此中间直段的全程最小值在 STOW。
- B 尾段在上滑期间随 s 下降，就位期间随 T_S 下降而增加，因此其全程最小值在 PREDOCK。
- 有限 U 头的 B 局部 Y 在上滑期间下降，在就位期间增加。比较 STOW 与 OPEN 两端即可得到全程序最大值在 STOW。反程使用同一参数集合，所以这些几何极值不变；摩擦、滞回、松手保持和操作力不由此确定。

还能给出不依赖密集姿态采样的保守界。由弦长下界、Jensen 不等式和 ∫q′²du=10/7：

```
sqrt(100+h²) ≤ T_S(h) ≤ sqrt(100+(10/7)h²)
T_S(8.2) ≤ 14.002040667600664
```

这使全程序中间直段保守下界仍为 0.00158396 mm，B 尾直段保守下界为 10.12658396 mm。U 头的保守上界小于 93.182 mm，低于 94 mm 请求及 94.25 mm 外包边界。

为避免把很小的正直段下界建立在未经说明的积分精度上，可用 |(sinθ)″|≤(1.5π)²+6π 给出 4096 分段梯形积分的截断误差上界 2.0393×10⁻⁷，对应 6.994788475<T_U<6.994794345。将 T_S 向上取 14.00205、T_U 向上取 6.99480，仍得到中间直段下界 0.001575 mm。这里没有声称做了机器定向舍入证书。

## 3. S/U 连接、有限法向厚度与外包域

q′、q″在 u=0、1 均为 0；U 的端角速度也为 0。因此各直段、S 和 U 的位置、切向和曲率连续，S→直线→U 为 G2。h=0 时 S 平滑退化为长度 10 mm 的直段，不需要删除或制造零长度段。

S 的有符号曲率为：

```
κ_S = (h/100) q″ / [1+(h q′/10)²]^(3/2)
|q″| ≤ 10/sqrt(3)
|κ_S| ≤ 0.473427220735494 mm⁻¹     (全部 u、全部 h)
R_S ≥ 2.11225708240107 mm
```

U 的最大曲率为 1.5π/T_U≈0.673699715173704 mm⁻¹，最小中心线半径约 1.48434083832463 mm。因此整个路径的有限法向偏移 r+ηN（|η|≤0.05）具有连续局部 Jacobian：

```
∂(r+ηN)/∂s_material = (1−ηκ) T
1−ηκ ≥ 0.966315014241315 > 0
```

这证明当前几何厚度偏移不发生局部翻折，不能代替层合材料中性轴、铜层应变或寿命数据。

因为 S 的 T_y>0、偏移 Jacobian 为正、两个端点 N_y=0，其有限厚度的 Y 范围仍然精确为 **80..90**。U 的有限偏移 Y 最小值在两端，为 Y_U。因此短中间直段不再额外损失一个 t 的长度。S 最高 Z≤1.5+h，B 回程直段最低 Z=4.8+h，二者至少有 3.3 mm 的坐标分离。

S 的 Y=80..90 在全部 s≤79.75 时都处于 A/B 的 Y 重叠区。A 外包 Z 为 −1.15..8；B 为 h−1.15..h+8，两者在 h≤8.2 时重叠。S 的有限 Z 在 1.4..1.5+h，因此落在这两个外包棱柱的并集内。A 初始直段在 A 内；S 后的低层直段、U 和回程直段按上述 Y 与 Z 界落在 B 内。

**这仅排除了旧单 U 的必要外包域矛盾。** 它没有定义真实跨舱开口，也没有证明壳体、OLED、结构件、线束、RF/热区为空。

## 4. A 板与 B 完整端接的局部坐标检查

A 原板材料 Y=7..36 对应世界 Y=15..44，Z=4.35..4.75。电池分配体为 X=−32..32、Y=38..78、Z=4.5..7.25；交叠为 12×6×0.25=18 mm³。板起点改 13.2 后，世界 Y=15..37.8，留下 0.2 mm 名义间隔。

web 材料 Y=13.25..13.7 对应世界 Y=37.3..37.75，电池方向间隔至少 0.25 mm。其 Z=0.8..3.3 与内夹爪 Z=0.05..0.85、板 Z=2.9..3.3 均有正体积交集；静态转接窗口仍需保留。最近 M2 孔中心材料 Y=15、半径 1.1，孔下界 13.9，与 web 上界 13.7 有 0.2 mm 名义间距。孔边、web 窗两侧、0.2 mm ledge 均未作承载或工艺证明。

B 全端后置至 PCB 材料 Y=24..36 后，正确的末端 T=−Y、N=−Z 将 PCB 放在 B 局部世界 Y=4..16。完整夹爪、载板、紧固件、静态转接也应全部在 B 自由端 Y=40 的后方。它们的最低局部世界 Z=4.85−3.3=1.55，低层自由带最高为 1.50，名义间隙 0.05 mm。

同样，A 端最高 Z=1.45+3.3=4.75，OPEN 回程带最低 Z=4.80，名义也只有 0.05 mm。上述上下界必须依据实际新工厂生成的全部部件复核；不能靠移动后的 PCB 表格推定其它零件已经移动。

## 5. 本次有限计算必须能回答的问题

- 新源生成的 A/B 端是否仍各为 20 个正体积、有效单实体，局部 190 对是否没有正 Common 或计算错误？A 载板是否仍连续，完整静态转接是否穿过真实保留窗口？
- 三态同一新路径和完整端接是否消除旧电池交叠、B 端自由带交叠、旧 PREDOCK 域外材料？所有机械、分配体、OLED 均继续参加，不用包围大箱替代两个独立外包棱柱。
- 对每个正 Common 输出世界体积、bounds；若 Common 有多个分离实体，给出各分量的 bounds 和体积，避免下轮按一个跨越空白区域的大 AABB 开槽。保存对应姿态和参与部件名称，才能决定开口是否切到承载、卡销、OLED 或电池。

计算停止或拒绝的具体情况：有序运动外输入；负或零长度段；坐标、切向或曲率在接头不连续；弧长反解失败或材料标签漂移；有限偏移 Jacobian 非正；端接缺体或失去连接；Common/containment 报错。正 Common 是候选的实际拒绝结果，应保留其位置；不必因为已经拒绝就丢掉其余同次已授权矩阵。

全局材料站点必须按同一自由弧长 s_material 标记；S 的 u 不是弧长。闭合分配使用的 T_S 与反弧长映射需有明确数值残差，至少检查各接头和两端位置。仅有代数总和 100 不足以证明 S 的实际积分也等于被分配的长度。

由有限站点生成的截面多边形是本次 STEP 的真实几何；它与解析曲线之间仍有离散误差。中心线弦长、实体体积可能随姿态有微小差异，不能由解析总长直接声称有限 STEP 精确恒长或恒体积。有限姿态检查也不能称为全部中间姿态的外障碍无碰撞证明。

## 6. 尚缺的实际输入

需要动态 flex 的真实叠层、允许弯曲/反弯半径、厚度公差与中性轴数据；S 和 U 的完整支撑、滑动/牵引方式及其实际占用尺寸；端子、连接器、补强、静态转接的实物尺寸与保持力；薄板/web/ledge 的材料工艺和载荷；实际跨舱开口、OLED、机构件与它们的公差。0.05 mm 名义层间间隙是否可用以及0.174 mm直段能否保持指定路径，都需要这些输入。

材料 s 的实现采用同一 Gauss 弧长函数分配 S 长度并作带括区保护的 Newton 反解。每个姿态都保留相同定义的全局自由材料弧长；S 的多项式参数没有误作弧长。曲率保留符号、N=W×T、N′=−κT，精确接头插入有限截面表。A 的板/web 和 B 的完整 PCB、载板、支撑、静态转接、M1/M2 都按上述修改生成，未发现只移动 PCB 或遗漏端体的情况。

Common driver 会保留每个正 Common，包括低于拒绝体积容差者，并输出完整 Common STEP、各分离实体的 bounds/volume、参与件名称、世界或端局部坐标系和 2 mm 邻域裁剪。邻域裁剪错误会使诊断拒绝；不会用 AABB 厚度代替局部壁厚。外包域仍是两个独立棱柱，只有经 `whole_material(..., empty=True)` 验证为空才停止后续 cut。ROI 和外包框的坐标传入严格 box API 前转换为 Python float。`integration/straight_envelope.py` 的实际原生路径已由父任务确认存在；缺少 scratch 参考副本不是源码路径错误。

独立 reader 的字段与最终 driver 对得上：20 体端件、154/161 体整装、端自身 190 对、A/B 400 对、带/端 40 对，以及 41×113 或 41×120 外部对。它对全部装配参与体和 Common/邻域分量作匿名一一数值匹配。复核提出的 `solid.located(location)` 会替换导入局部位置的问题已由父任务改为 `solid.moved(location)`，与冻结 reader 和生成器的复合刚体变换语义一致。该 reader 仍不声称仅凭 bounds/volume 证明完整材料同一性。
