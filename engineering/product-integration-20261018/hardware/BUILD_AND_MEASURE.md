# 研究样件制作与实测回写

本文件对应 WP8。当前交付的是可复算的设计研究、原生几何和无电柔性线路样片文件；本轮没有制造样件、装入真实电芯或完成手机上电。`connection-check.json` 记录了当时 main / pocket4 上的连接检查，设备清单为空，只说明这两处检查没有获得可读取的 donor。

## 1. 让样件与同一个设计版本对应

每次制作保留所用 Git commit、`design/product_geometry.json` 和 `design/product_interfaces.json` 的 SHA256，以及实际加工文件的 SHA256。使用本目录的 `measurement-record.template.json` 复制出新的记录；模板中的 `null` 表示尚未观察，不是零值或通过。将照片、尺寸表、仪器输出和循环日志放在同一个样件记录目录，原始文件与分析结论一同保存。

加工时采用当前 `../mechanical/` 与 `../electrical/` 的交付说明和文件索引。历史零件、失败试验和当前候选具有不同身份，不把早期 STEP 文件与新槽窗、新侧边操作件混装。尺寸或材料有任何实物偏差，都在样件记录中填写实际值；修改 CAD 后产生新的设计版本，不覆盖先前样件的记录。

## 2. 无电机构、尺寸替身与装配

第一件样件先使用无电芯、无 OLED 的尺寸与质量替身，验证零件确实能按当前机构装配顺序装入，销、伸缩件、夹具、螺钉及工具都有入口。预留体积不是已经选中的手机部件，不能把占位块上的空间容积换算成电池容量。

当前研究中的极薄 KEY、PAWL 间隙、微型螺纹与屏支撑件需要逐项确认加工方法。STEP/STL 的存在不表示普通 FDM 打印能复现这些截面和间隙。可打印的壳体或质量替身与需金属薄件、精加工或其他工艺的零件分别安排；加工方的实际最小特征和公差回填到尺寸预算。尚未完成具体采购选型的螺钉不以几何圆柱模型替代采购 BOM。

使用实际部件或有实测尺寸的替身填入主板、相机、连接器、A/B 电池、天线禁布区和散热接触面。替身明确质量、重心、紧固点和最大外形，质量未知时填写 `null`。电池厚度记录完整封装、引出片和保护组件，膨胀余量采用所选电芯的可追溯依据；本项目没有通用的已批准膨胀值。

逐步执行机构说明中的解锁、上滑、就位、OPEN 保持、解除保持、退出就位、下滑和复锁。每步先记录驱动点与另一只手的支撑位置，再记录松手后的状态。OPEN 附件若需独立装入，则在样件 BOM 和操作记录中实际出现；不能把“操作者一直扶住”写成结构自保持。左右偏差测量必须包括左先动、右先动和正常双侧操作，不仅测理想同步轨迹。

建议第一轮只安排少量完整循环，以发现装入、卡滞、脱落和夹持问题；记录实际循环数和停止原因。它是初始操作研究，不代表寿命结论。出现无法按顺序装配、支撑脱落或接触真屏的尖锐边缘时，先修改具体结构再继续该段动作。

## 3. 柔性材料与 26 路无电端接样片

OLED 几何研究使用恒长材料带和规定的储屏路径。先以可标记的无电柔性材料核对正面可视区域、非可视边缘、转向弯曲区、B 舱平面储存区、固定端和牵引端。替代材料的弯曲性能不能证明实际 OLED 能承受同样的曲率；真实屏的可视区、总材料长度、COF、触控层和动态弯曲条件仍须按具体模组核对。

在带材上标出材料坐标，使 STOW、PREDOCK、OPEN 与中间阶段能对应同一个物质点。拍摄侧视与正视记录，观察储存段是否保持平面、边缘是否翘起、转向轴是否迁移、进入和退出支撑时是否形成悬空弯折。记录夹持位置和实际带长，不能通过每个姿态分别裁一条不同长度的带材获得表面上的通过。

26 路 continuity 样片用于独立无电导通研究。按照当前端子表接入其 A/B 尾部、补强、上下夹具和研究端接板，并保留所有固定件。先检查静态每路导通、邻路短接，再在完整往返过程中采样导通状态；记录采样率、仪器范围、线路对应表、原始数据和掉线时刻。只在端点测两次电阻无法证明运动过程连续。该样片没有 OEM 显示、充电、USB 或天线的信号授权，不把 26 条测试网映射为真实手机接口。

新 PCB 的原生 DRC、Gerber/钻孔文件和生产层叠需要采用本轮电气交付记录中的实际结果。存在未解决的 DRC、未确认板厚或未确认补强工艺时，只制作明确标注用途的尺寸样件，不能把布局研究当作已验证的可装机电路。

## 4. 实际 donor 与原系统运行基线

连接已允许 ADB 调试的 donor 后，可以运行：

```bash
python3 tools/read_donor.py --output /tmp/razr-donor-readback-NEW.json
```

多台 Motorola 设备连接时，通过 `--serial` 明确选择。工具仅采集软件身份，不修改设备设置；输出保存序列号摘要，不保存原始序列号。返回码 `2` 表示没有选到已连接的 Motorola donor，记录仍会保存。软件型号、SKU 和主板属性不代替拆机标签、PCB 修订号、屏幕料号或电芯型号。

先为匹配的一整套原主板、原屏幕/触控、原双电池与保护充电链、USB、相机和天线建立运行基线：开机、画面、触控网格、充电与电量读取、USB 数据、相机和无线连接分别记录。接口表中的原始针脚与电气条件未核实时，保持原配互连；新增适配器只能连接已追溯确认的端子。板间研究自检逻辑的通过不能替代这一步真实回线测试。

装机后的运行记录复用同样的软件测试，并增加完整运动中的供电、显示、触控与 USB 连续性记录。电芯容量以实际电芯/电池组规格与后续可追溯测量填写，4700 mAh 是总目标；当前研究的空间分配尚不能证明达到该目标。热路径与天线预留在真机中分别测量温升和通信表现，不从“已画出保留区”推定性能。

## 5. 第一批需要回写的量

| 对象 | 原始记录 | 对应设计更新 |
|---|---|---|
| A/B 完成外形 | 两舱完整宽、高、厚度轮廓；突出件；装配照片 | 同尺寸外包络和运动避让 |
| 主板/连接器/相机 | 正反面外形、各区高度、紧固点、光学孔径、配套料号 | 从占位区替换为实测实体与固定 |
| 双电池 | 完整料号、封装、引出片、保护器件、规格容量和膨胀依据 | A 优先的真实装机与总容量结论 |
| 机构 | 左右位移、偏差、就位量、操作力、卡滞位置、复锁情况 | 槽销、导向、侧边操作件和截面预算 |
| OPEN 保持 | 实际附件、保持方式、施加载荷、松手位移、持续时间 | 保持与支撑的尺寸及真实载荷 |
| OLED 替代带/真模组 | 总长、可视区、边缘、COF、材料标记轨迹、最小弯曲半径 | 材料路径、夹持、转向与支撑转换 |
| 动态线路 | 完整端接、每路静态电阻、运动原始日志、短路与断路位置 | FPC 长度、夹持出口、补强与走线 |
| 实机功能 | 与 donor 基线对应的显示/触控/USB/供电/相机/无线记录 | 实际平台接口与运动中连续性 |

每项记录测量方法、单位、仪器分辨率或不确定度、设计版本和附件。首批实物尚未发生，因此本轮交付没有在模板中填入虚构测量值，也没有据此提升任何整机或制造完成状态。
