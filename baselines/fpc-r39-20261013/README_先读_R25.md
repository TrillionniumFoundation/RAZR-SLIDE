# RAZR SLIDE R25 — 独立捕获止退与二阶段挡门：研究型 CAD，不可投产

**结论：NO-GO / 禁止制造放行。** 这是接续 R24 源码和实际 OCC 实体的候选；部分 STOW（收纳）机构通过局部刚性几何证明，但 OPEN（展开）二阶段锁仍不成立。静态碰撞不是实物弹簧、锁止、承力、生命周期、电气隔离或 OLED 许可。

## 如何阅读

1. `r25_capture.py`：沿用 R24 融入 A 壳的四个实体钥匙，建立 B 侧横向捕获爪（收纳/展开×左右），用真正 OCC 接触证明坐实后反向 0.05mm 出现阻挡；同时反例检查远距误扣与临近时卡死。
2. `r25_gate.py`：仅收纳端独立二阶段挡门（左右分开），闭锁时真实阻挡载体 z=0.8mm 强制伸出；未扣上的爪在挡门第一段行程实体阻止其开启。**挡门返回弹簧、两端释放执行轴、完整常闭及承力均未设计成可加工样机。**
3. `r25_integration.py`：从 `baseline_R24/` 的原 R24 CAD 实际布尔重新切除 B，保存有效 BRep；B 单实体不意味着强度足够。新增 8 处扫掠让位。
4. `r25_dynamic.py`：10 个名义姿态及独立新部件碰撞；仅针对现有模型已知实体。OEM OLED 完整封装未知。
5. `r25_tolerance.py`：216 组 ±0.02mm/±0.05mm 的**假设**多轴偏移；没有制造公差上限或屏幕材料保证。
6. `r25_faults.py`：32 组新增组合故障 + 继承 R24 8192 组离散状态；故障逻辑检查不是故障概率认证。
7. `r25_export.py`：7 份 R25 STEP（含有意的 GHOST 反例），自动重新导入及 SHA256。
8. `test_r25.py`：30 项新测试；`baseline_R24/r24_checks.sh` 为 R21~R24 继承 123 项回归。`r25_checks.sh` 独立复现；需 CadQuery 2.8 / OCP 7.9 / Shapely。

## 未改变的产品约束

相同尺寸两舱，目前各 94.25 × 73.99mm；B 收纳后向上滑 79.75mm，再法向就位 8.2mm；A 优先大电芯、B 储屏和主板/相机；只有一块约 7 英寸柔性主屏，无外屏；4700mAh 仍是目标值不是装配实测。

## R25 新增实际量化

- 两端×两侧 4 个 A/B 捕获爪：完全接合名义无穿透，强行反向移动 0.05mm 时 OCC 交叠；但不能推断力或真正防止拆卸。
- STOW 新左右单体挡门和载体耳：载体收回不冲突，强行伸出 0.8mm 时挡门交叠，手动假定挡门开启 2.0mm 后该交叠消失；默认闭锁与捕获爪的机械互锁可在理想实体中成立。
- 对 A/B 主壳做真实 R25 切槽：B 相对 R24 切除约 12.509644mm³，A/B 仍是各一个有效 OCC 实体；**没有导轨静强度、螺栓/轴/弹簧实装，也没有 OPEN 双阶段锁**。
- 复制 STOW 到 OPEN 失败：B 端缘侵出 0.56mm；OPEN 拟议捕获爪外侧剩 0.285mm 名义包络，左右 OPEN 爪让位对 B 现有实体减材均为 0，这既不证明 B 有安装支座也不证明爪有实际导向。
- ±0.02mm 假设公差 108 组中，36 组无法在反向 0.05mm 时得到止退接触；±0.05mm 的另108组中，36 组坐实时出现穿透、36组没有 0.05mm 止退接触。
- 原 R24 正常开颚提前1.6mm / OPEN q6.6mm，仍被完整保留在基线；STOW 新挡门是在理想独立健康状态下额外阻止载体，**没有**物理证明在远离 A 时爪不能自行误扣而开门。
