# RAZR SLIDE R26 — 展开端内侧停泊止退爪 / 低位二阶段挡门（研究 CAD）

**整机制造放行：NO-GO。任何通过仅指源码、刚性 OCC 代理、离散姿态和指定故障测试。** 不含可制造的常闭弹簧、轴承、锁体安装座、推力/跌落/疲劳实证、电源原理图或 OEM OLED。

## 不能改变的产品形态

- 两个同外部尺寸功能舱，各 94.25 × 73.99mm 名义包络（非实际 OEM 许可尺寸）。
- B 舱由后下层沿纵向向上滑动 79.75mm，展开端法向坐实 8.2mm；A 舱优先大电池，B 舱储屏与核心功能。
- 仅一块约 7 英寸柔性 OLED 主屏，不需要独立背屏；不采用绕在滚筒上的屏幕；4700mAh 是目标不是实装容量。

## R25 基线发现的漏检

R25 原 OPEN 止退爪 **PARKED** 外侧位置相对完整 A 壳体，在完全展开对接时发生每侧 **0.02112mm³** 重叠。R25 仅检查钥匙，不覆盖 A 整壳，本轮新增对抗检查。因此 R25 此项不能沿用为通过。

## R26 在本轮实际改动

- `r26_open_mechanics.py`：OPEN 止退爪改为**向内停泊 0.55mm**；新 OPEN 二阶段挡门与旧 R24 释放挡颚做 Z 分层，挡门不再越出 B 舱纵向端面；左右独立的低位接点耳与 R24 原耳通过刚性布尔融合。
- `r26_integration.py`：基于 R25 原始 OCC BRep，实际切除六个新扫掠容积，再导出新的 A/B BRep（原 R25 作为完整基线保留）。
- `r26_dynamic.py`：使用真实 R26 重新改型 BRep，在 10 个姿态与 A/B/OLED/FPC 做指定交叠检查；仅 OEM 假设 OLED。
- `r26_faults.py`：OPEN 端加入双侧挡门在关门时**阻止连续伸出路径**、左右爪未锁时先阻止开门的实体干涉；同时明确同时误开、脱爪及已经提前伸出的故障仍有危险。包含此前未检查的完整 A 壳体反例。
- `r26_tolerance.py`：216 个本轮假设 XYZ 偏差记录（±0.02 / ±0.05mm，针对新挡门/耳/停泊爪）；不替代 R25 捕获爪的 216 个失败案例，也不构成实际 GD&T。
- `r26_export.py`：10 份完整 R26 STEP 原始姿态，包含刻意有实体相交的 `GHOST` 故障图景；导出后逐件重导入和 SHA256 记录。
- `test_r26.py`：38 项有意保留未解决门槛的断言。**通过表示危险被识别或局部几何满足测试，不表示现实安全。**

## 不得省略的制造否决项

1. **OPEN/STOW 真实机械常闭尚未建成**：无独立驱动后锁扣连杆、限位弹簧、紧固座、承力试验；即使远离 A，止退爪仍可被错误扣上。任何共因释放会使局部防护失效。
2. **已经伸出的接点仍可绕过 R26 低位挡门**：挡门关闭但接点载体已伸至 0.8mm 时，实体端态未相交。此结构只防从缩回状态开始运动，不能替代主动断电与受控回收。
3. **空间：** OPEN 新挡门距离 B 原名义顶面约 0.11mm，距假设 OLED 外侧约 0.12954mm；旧 R24 导轨孔腹板仅 0.22mm。这不是有效导轨/外壳强度余量。
4. **电气：** 现有 TE 2199001-1 不能作为双电池主电源；没有 BMS 双包隔离、预充、反灌、带电裸露接点、热和 USB SI 的真实样机证据。
5. **OLED：** 无 7 英寸完整模组层叠、官方 Rmin/驻留展平寿命、COF/FPC、封边和展平力原厂签署资格；旧 R3.4 与 7.3mm 储屏腔仅是假设，最坏预算曾需 7.76mm。
