# RAZR SLIDE R30｜先读：导向座重建与 NO-GO 边界

**本轮结论：348 项研究级模型测试通过；制造、带电装配及 OLED 寿命资格全部 NO-GO。**

## 1. 产品定义（保持 R21–R29 不变）
- A/B 两个等尺寸独立功能舱：原设计约 94.25 × 73.99mm 的研究包络；B 向上滑出约 79.75mm，展开终点再做约 8.2mm 法向坐实。
- 单块约 7 英寸柔性 OLED、无独立背部外屏，A 舱尽量保留电池空间。4700mAh 为未经电芯装配/安全认证的目标，**非已有电池容量结论**。

## 2. 真实 OCC/CAD 变更
- R29 原来的接点耳、销、斜槽和 A 舱钥匙尺寸保持原参数与空间布局；**没有**凭借缩小安全距离来消除 R29 前缘约 0.030mm 的假设薄壁。
- 取 R27 尚未遭 R28/R29 反复挖槽的真实 B 壳 BRep，重新在后方布置左右固定 C 形导向座（与 B 壳布尔合体），给两个挡门增加与挡门一体的长尾轨，再执行 8 处运动让位布尔切削。
- 相对于 R27 B 壳新增实体导向材料 **1.09892766mm³**，对增强壳体切除 **0.87039325mm³**，净增加 **0.22853441mm³**；修改后 A/B 都是 OCC 有效单一实体。这仅证明建模有效，不是实体轴承座的强度合格。
- 曾尝试整体外移销槽来获得更大壁厚，局部公差通过但发生 **12 个 A 舱钥匙/壳体相关姿态穿透记录**，候选被否决，未进入正式 R30。

## 4. 没有跨过的制造硬门槛
**机械**：R29 假设前缘 0.030mm、R24 侧轨 0.22mm 薄腹板未获承力资格；36/64 联合故障仍逃逸；缺 A 钥匙可假扣合；接点 e=0.07mm 已可能移动而没有实体阻挡，真实导通行程未知；接点卡死、弹簧/销断裂后不能保证强制回缩；没有材料、拉拔、疲劳、冲击、GD&T、可靠紧固/弹簧。

**电源/USB/信号**：TE 2199001-1 仅按 Signal、最大额定 1.5A 参数评估，不能代替双电池主电源或 USB SI/EMC 证明；跨舱电源需要实体开断、保护、预充、旁路短路、实际触点无电时序/波形，USB 需选型和高速测量。

**OLED**：目标 7 英寸面板具体 OEM 型号、完整封边及 COF/FPC、允许动态曲率、平储长期形变、展平力与循环寿命、授权均缺。IEC 62715-6-42:2026 是展平力测量方法而非寿命认证。

## 5. 独立复现指令（需 cadquery、numpy 等原源码依赖环境）
在工程根目录：
```bash
./r30_inherited_tests.sh
./r30_geometry.sh
python -m unittest -v test_r30 > verification/R30_new_40.log 2>&1
python r30_ancestor_freeze.py
python r30_attest.py
python package_r30.py
```
**注意**：`r30_inherited_tests.sh` 重跑继承测试需要较长计算时间；重算 STEP 的生成时间戳可能不同，但几何形状与研究约束应复核。不要把 STEP、unittest、逻辑故障枚举当作实物认证。

更详细的否决与证明边界见 `audit/R30_硬门槛对抗审计.md` 和 `vendor/R30_机械_电气_OLED_独立硬门槛.md`。
