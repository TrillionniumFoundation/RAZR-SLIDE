# RAZR SLIDE — R33 工程包先读

**工程结论：研究级候选。严禁制造放行、带电接线或将模型宣称为认证的锁扣/连接器。**

R33 在 R32 的两个后置、非导电量规盒上实现了真正的 OCC 横向通孔，B 壳两侧同轴钻孔，并加入两只 **尚未选定目录件、没有轴向固定** 的研究保持销。CAD 抽拔路径证明：销保持安装时，左右两侧量规盒的退出路径出现真实实体阻挡；但若销脱出、断裂或未装，盒体仍可自由退出。销并非已验证的机械安全锁。几何模型不包含实体弹簧、轴向夹、轴承/紧固、限力回缩和接电先后时序。

**用户定义的产品目标维持不变：** A/B 双等外形功能舱、B 上滑后位于上半部、单块约 7 英寸柔性主屏、无背部外屏、A 优先大电池。现有 A/B 研究 BRep 尚未证明完成品同外形，4700mAh 未取得 OEM 实物认可。

文件路径：
- `r33_parts.py`：所有 CAD 参数；TE 器件以 **官方目录外接长方体** 而不是原厂 STEP 表示。
- `r33_integration.py`：从冻结的 R32 BRep 开始完成销孔布尔切除，并保留 A 原字节。
- `r33_retention.py`：穿销、无销、抽拔逃逸、轴向取出及装配偏差的实体求交。
- `r33_dynamic.py`：10 姿态 A/B/OLED/FPC（仅研究假设包络）交叠。
- `r33_catalogue.py`：TE 2199001-1 公开外包络 12 组放置方向的真实 B 壳 OCC 拒绝检查。
- `r33_expansion.py`：实际扩大 B 壳两侧目录包络槽的 **拒绝分支**，不并入最终保留研究壳。
- `r33_export.py`：7 份 STEP，其中 4 份故意是危险 GHOST；成功导出只是有效的几何记录。
- `test_r33.py`：40 项研究断言，包括正向/反向证据。测试中的已知危险是必须复现的失败证据。
- `r33_inherited.sh`：重新运行 R21–R32 的全部 433 项历史测试，不篡改旧版失败结果。
- `r33_geometry.sh`：重算并分别生成 R33 验证数据与 STEP。
- `r33_freeze.py`：原始 R32 封包与 636 个成员逐件复核。
- `r33_attest.py`：检验完整日志、哈希与制造否决结论。

**请不要用 `STEP valid`、`unittest OK` 或 `B single solid` 代替物理承力验证。**
