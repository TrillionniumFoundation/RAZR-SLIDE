# RAZR SLIDE R24 — 两端物理钥匙及跨舱安全止挡 CAD 对抗审计

**性质：离线机械工程研究。制造资格：NO-GO。** 本包不是可投产图纸，也没有 OEM 零件和实物试验。所有长度为 mm，体积为 mm³。

## 入口

- `r24_mechanics.py`：四个 A 侧实体钥匙（收纳两只、展开两只）；沿实际几何碰撞响应的理想单自由度挡颚位置求解；未嵌入软件到位许可。
- `r24_integration.py`：A 壳融合实际钥匙；在 R23 的 B 壳上实作 16 处 OCC 布尔让位切除，返回两个有效单一实体。
- `r24_dynamic.py`：10 个装配姿态、左右两站、160 个移动组件分别对 A/B/OLED/FPC 的 OCC 检查；继承 R23 载体与新侧臂一体连通验证。
- `r24_faults.py`：R22 三止挡 + R23 双颚 + R24 双侧挡颚的 8192 状态枚举，外加物理斜楔导致的近终点误放行。
- `r24_longlap.py`：试图加长挡颚延迟释放，实测与 R16/R17 侧锁销参考实体有 0.461002mm³ 碰撞；保留 **REJECTED**。
- `r24_export.py`：8 个 STEP 场景，包括两种有意的提前放行 GHOST；所有触点只是几何占位，不是 TE 真 STEP。
- `test_r24.py`：25 个 R24 测试；`./r24_checks.sh` 全量复跑继承 R21/R22/R23 加 R24（环境需 CadQuery/OCP/Shapely）。
- `audit/R24_硬门槛对抗审计.md`：放行矩阵、反例、实验证据界线、R25 方向；`vendor/R24_供应商和试验工装输入要求.md`：尚未发出的工装及原厂询证清单。
- `verification/`：原始 JSON、控制台日志、STEP SHA256；`cad/*.step`：真实导出的研究级 OCC 装配几何。

## 不变量

A/B 两功能舱外形相同（当前 94.25×73.99mm）；收纳时 B 在后层，上滑 79.75mm，Z 方向就位 8.2mm；单块约 7 英寸 OLED，**没有独立外屏**；OLED 储存在 B，A 优先大电池；4700mAh 仍是未取得 OEM 电芯许可的目标。

## 最核心否决

**R24 的物理 A 钥匙成功避开 R17 OLED 研究几何，但挡颚仍然在完全坐实前提前让开，而且 B 侧钥匙通槽与继承侧锁销孔仅剩约 0.22mm 名义腹板。** 收纳前约 1.6mm、展开 q≈6.6/8.2mm 时即可消除当前 R24 外侧载体阻挡；若 R22/R23 旧保险同时错误释放，触点可能提前伸出。延长挡颚的 R24.1 变体虽然能把解锁点推向最后几何终点，却与旧端侧锁销候选冲突，并且几乎没有公差余量。下一版必须新建 **捕获后独立二阶段机械许可**，不能再以布尔 `seated` 代替实物锁。

实测弹簧力、拉脱强度、分离时电源隔离、300,000 次疲劳与目标面板 OEM 数据均缺失。**禁止据此机械/电气制造放行。**
