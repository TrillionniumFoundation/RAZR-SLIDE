# RAZR SLIDE R23 工程包

**制造状态：NO-GO。** R23 不包含现实可生产的 A 两端机械钥匙/正向凸轮、弹簧规格、丝印 PCB、OEM 电芯/7英寸 OLED、主电源连接器或经认证 USB。

本包是可运行 R23 源码 + 全部 R22 完整基线 + 6份研究性装配 STEP + 验证报告和 SHA256，不是制造文件。

- 关键结论见 `audit/R23_硬门槛复核及否决结论.md`。
- 机械模型 `r23_gate.py` 和 `r23_integration.py`；电源短路割集 `r23_power.py`；OLED 敏感性 `r23_oled.py`；STEP `r23_export.py`。
- 测试 `python -m unittest -q test_r23.py`；完整工程复算 `./r23_checks.sh --full`（基线 R22 全量回归可能耗时较长）。
- `cad/*GHOST*`：故意制造不可接受的错误态；`*A_KEY_UNPROVEN*`：手动打开双颚，不代表 A 端实体捕获有效。
- `vendor/R23_机械电源与OLED原厂询证包.md` 尚未发送任何供应商。

**注意**：整体强行“开颚”的抽象状态意味着现实机构尚可能错误释放；R23 只有在新双颚至少一个仍正确关闭时具备几何阻挡。双颚共同误开仍有 56 个重现反例。任何声称消灭全部误开状态或已通过 300k 是不实的。
