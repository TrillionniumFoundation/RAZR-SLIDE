# RAZR SLIDE R22 — 双侧三道实体挡块、跨舱三电气路径与 OLED 原厂准入

**工程状态 2026-10-10：研究型 CAD／结构保护代理通过部分否证试验；严格 MANUFACTURING NO-GO。**

本工程从 `baselines/R21` 的真实源码、CAD、测试继续迭代，不是从效果图重绘。用户已确认的产品约束不变：A/B 两个同外尺寸完整功能舱（项目代理各约 94.25×73.99mm），B 从后/下方向上滑动成为展开后上部，纵向滑行约 79.75mm，末端前靠 8.2mm；一块约 7 英寸柔性 OLED，**无背部独立外屏**；平面收屏集中在 B；A 侧尽量腾出空间放更大电池，总目标 4700mAh **尚未从真实电芯证明**。

## 1. 改型及可复算的结论

- `r22_mechanics.py` 在 R21 的 B 舱单一实体上对 **STOW / OPEN 两个终端** 增加 3 个独立承力挡块的运动包络避让槽：左、右两只负载面挡块和第三只独立中心硬止挡。实际 OCC 布尔结果：**从 R21 的 B 壳额外切去 22.380692mm³，切后仍是一个有效连通实体**。
- 同时重用 R20 原信号载体及 B 舱背梁，增加一根跨中安全拦截杆。强制伸出但三挡块未撤回时，安全杆与 L/R/中心硬止挡分别产生 **0.3404 / 0.3404 / 0.37mm³** 实体重叠，作为 **伸出不可能的诊断冲突**；设计停车缩回状态三处为 0，三个挡块由正确坐实代理撤回的状态亦为 0。**此为模型否证，不是力学和装配合格。**
- 5 个关键姿态，修改后的 B 与 A、固定底板、叶片、OLED、FPC 的新相交 0；新增挡块和杆与这些组件及已修改 B 的非法实体相交 0，B 电池/PCB/摄像头代理额外破坏 0。统计见 `verification/R22_mechanical_results.json`。
- 320 个由 2 种终端、8 种位置、4 种原狗齿状态、5 种 A 端载荷面故障组合构成的状态代理，**312 个未满足完全端面坐实时，0 个出现无挡块而允许提前伸出的数学状态**。但三只新挡块全部错误撤回的组合确实失守（强制保留的阴性用例）；模型没有真实机械释放机构和弹簧。
- 5 个 R22 STEP 可由 CadQuery 导入，**每个 32 个有效实体代理**；第 2、第 3 个 STEP 为强制接触/挡块碰撞的否证**幽灵状态**，不可作为实际装配位置或正常干涉检验。具体文件名及 SHA256 位于 `verification/R22_STEP_manifest.json`。

**关键技术缺口：** 虽已有实际 B 壳实体切削、可接触的硬止挡体积，却**尚未建成独立装配于 A 的中心接收键、受力肩、偏心凸轮、强制缩回先于 A/B 分离的捕获式机构、双弹簧分别失效闭合、真实材料/磨损/高温/低温变形及承力分析**。目前 `qualifying_seat()` 仍是端面零间隙的计算**预言机**（0.02mm 是人为筛查阈值）。没有两侧误开仍不能让中锁被 A 以外方式顶开的物理证据，更不能声称双侧安全锁工程已通过。见 `verification/R22_fault_results.json`。

## 2. 三条独立电连接通道和保护逻辑

| 路径 | R22 设计决策（非已装配） | 放行 |
|---|---|---|
| 低速信号/唤醒 | 使用 TE 2199001-1 **仅作候选信号触点**，最大公开额定 1.5A，工作高度 0.70–1.00mm；信号寿命/偏差待厂方确认 | **NO-GO** |
| 高速 USB | 优先让主控/PHY 与 USB-C 插座均在 B 舱，以**规避跨舱高速路径**；实际 PCB、B 舱插口、ESD/EMC 未建模。若实际需要跨舱 USB，必须单独设计、测损耗和眼图 | **NO-GO** |
| A→B 主电源 | **绝不将两块电池正极直接并联**。A 端大电芯和 B 端小电芯各自 BMS，A 路独立保险、受限预充电、背靠背 MOSFET、温升/压差/焊死监测，双端各自独立带防呆的专用大电流插接系统。并非复用 TE 弹片 | **NO-GO** |

`r22_electrical.py` 对 13 个布尔输入做 **8192 个状态全枚举**，要求端点一真一假、左右实际坐实、独立中心锁存在、BMS/温度/触点额定资格和双 FET 健康条件。**预充电也不得越过电气资格检查**。实际仅 8 个输入组合允许预充电、其中 2 个允许主电源（理论状态）；违反独立断言 0，故意删除中心锁守卫的危险变种可被检测。**这些全是软件控制真值表，尤其无法实证 FET 焊死、防呆和端子实际通断。**

供应商严苛筛查：Harwin S1961-46R 14A 但厂方对比表为最少 3000 次触点寿命，距 30 万次目标差 100 倍；Mill-Max 0985 8A、100000 次，也不足 3 倍。**目前没有一个已选电源连接器符合整机目标。** 追加 **Mill-Max 0900-0** 长寿命采购询证候选：公开系列指标可达 100k–1M 次、2A 连续、初始高 3.48mm（比原 TE 1.2mm 代理高 2.28mm）；未经特定型号 300k 许可，不能原位装进旧弹片槽或并联推高电流额定。 电流灵敏度假设 3V 总线和 90% 转换效率：3W→1.111A；5W→1.852A；8W→2.963A；12W→4.444A。这是计算示例，不是实机峰值与料件设计额定。见 `verification/R22_electrical_results.json`。

## 3. OLED 厂家封装与长期静置关键否决

R21 的 OLED 仅按 **AA 有效显示宽度** 建模。B 壳与该代理最近距离只有 **0.319619mm**，仅高于假定最少 0.30mm 容差 0.019619mm；每侧封边实际多 0.15mm -> 净距约 **0.28954mm**（失败），每侧 0.20mm -> **0.23954mm**（失败）。目前没有确定的单块 7 英寸 OEM 全模组宽度/胶层/柔性尾线 STEP。

平面存屏腔体的理想关系 `2R + t + allowance <= 7.3 mm`。借用前代未经 OEM 同意的叠层 t=0.16mm、内部设计余量 >=0.30mm，理论最大 R **3.42mm**，对 R3.4 只有 0.04mm 可用裕度。公开 **维信诺完整模组 R5** 的代入值 `2*5 + 0.16=10.16mm`，相较 7.3mm 腔体不仅超 2.86mm，还差原设定 0.3mm 目标总共 3.16mm。**这不能反证实际 7 英寸 OLED 一定 Rmin=5；只说明若供应商只批准 R5，现产品封装深度需要重构，不得维持 R3.4。**

IEC 62715-6-42:2026 是卷动显示的**拉平力测量方法**，不是寿命、色偏、静置残余应变和整机批准证。必须取得目标型号在 R3.4 / 材料各层下的动态弯折、长时间收纳曲线、拉平力-温度-速度数据、残余应变、表面折痕、热湿老化和整机 30 万次耐久原厂证据。`vendor/R22_原厂数据及样机验证申请.md` 为 RFQ 和材料试验计划。

## 5. 重算命令与数据追溯

```bash
# 环境：Python3.13 + cadquery/OCP + ezdxf；所有本地参数及源文件在包内
cd RAZR_SLIDE_R22
./run_checks.sh         # 快速 R21/R22 回归及冻结结果完整性
./run_checks.sh --full  # 耗时实测：重建 B OCC 真实实体、全姿态负测并重新导出/导入 STEP
```

- `r22_mechanics.py` — 三挡块可执行 CAD；B 壳真实布尔切削，注入原左右误释放。
- `r22_verify.py` — 五态原位 OCC 干涉与实际 B 壳单体；电池/PCB/摄像头包络检查。
- `r22_export.py` / `cad/*.step` — 5 个可导入 STEP，2 个是**故障尝试假想干涉**。
- `r22_electrical.py` — 与机械资格关联的可执行电源真值表；无实际电气功能。
- `r22_oled.py` — 厂家准入检查和半径/公差敏感性。
- `verification/R22_*_results.json`、`verification/R22_STEP_manifest.json` — 保留数值、否决项、STEP SHA256，不能把回归绿灯解释为产品验收。
- `baselines/R21` — 完整的上一轮工程版以及原始 R17/R19/R20 可复算源码。
