# RAZR SLIDE R27 — 高位全行程截获片（研究 CAD）

**制造资格：NO-GO。** 本轮修正 R26 指定端态物理漏挡，却没有实现失电强制回缩或 A 端钥匙正向防假扣。不能制造真实带电电池联锁手机。

产品方向冻结：A/B 同外包络 94.25×73.99mm，B 后下舱向上滑 79.75mm，最后法向坐实 8.2mm；仅一块约 7 英寸柔性 OLED，无背部外屏，A 优先大电池，4700mAh 尚未验证。

## 本轮真实文件

- `r27_mechanics.py`：左右单一实体新 OPEN 二阶段挡门，预伸出 0.8mm 已不再绕过。
- `r27_integration.py`：将新挡门扫掠区对 R26 B 壳实际求差；新增切除体积 **0mm³**，使用旧让位，未修复安装支撑。
- `r27_dynamic.py`：10 姿态完整 A/B、假设 OLED/FPC 的指定占位互撞复核。
- `r27_faults.py`：64 种故障、仍 36 组逃逸，承认假扣与强制回缩缺失。
- `r27_tolerance.py`：108 个独立 XYZ 配置×4 项 = 432 次新接点耳/门求交。旧 R25 捕获爪失败不因此失效。
- `r27_power_faults.py`：512 状态概念双电池断电故障树；非真实电气原理图。
- `r27_export.py`：12 份 R27 装配 STEP，每份18件；`GHOST` 是已知危险/穿透，不可用来制造。
- `test_r27.py`：新增 35 项对抗断言；继承 R21–R26 191 项，共226项。
- `r27_checks.sh`：复算入口（执行时间可能较长）；`R27_SKIP_INHERITED=1 ./r27_checks.sh` 仅适用于先前基线日志已独立验证的情形。
- `audit/R27_硬门槛对抗审计.md` 与 `vendor/R27_实体样机与供应商必须提供的证据.md`：详细拒绝项和外部试验门槛。

### R28 必须攻克

缺真正复位弹簧、导向轴和安装座；已伸出的载体在关门时可能**卡死**而非强制缩回；A 不存在时假扣可能；双侧共因故障36/64未消失；主电源需独立供电连接器/BMS/隔离/预充实证；OLED 厂商模组厚度、弯曲和长时翘曲数据缺失，储屏腔的尺寸未经认可。

所有结论都是**研究参数 CAD 与失效模型**，绝非制造放行。保留完整 R26、R25、R24、R23、R22、R21 技术基线、原始测试和 STEP。
