# RAZR SLIDE R28 — 正向回缩槽＋随动销 / 拒绝制造放行

**R28 判定：参数化 CAD 研究候选；禁止制造和带电装配。**

本项目产品规格沿袭 R27：A/B 两个外形等尺寸功能舱（原参考包络 94.25×73.99 mm）；B 舱从后下层向上滑出约 79.75 mm、终点法向坐实约 8.2 mm；单块约 7 英寸柔性 OLED，非外屏，A 舱优先加大电池。**4700mAh 是目标，不是 OEM 电池已确认容量。**

## 最重要的新结构

- `r28_retraction.py` 用真实 OCC **一体挡门斜槽板**与一体接点载体**随动销**，形成默认先回缩、后落下安全挡门的两段凸轮运动。
- 关门 0.90mm，其中 0.36mm 门体保持段，剩余 0.54mm 理想斜槽驱动载体从伸出 0.8mm 到完全回缩。运动约束是刚体几何，不是已经测得的力、弹簧动作或断电证明。
- `r28_integration.py` 对继承的真实 R27 B 壳做四个 BRep 布尔让位，新增 3.25628942mm³ 实体切除，所得 B 壳仍是单一有效实体。
- `r28_faults.py`：左右 38 个理想运动抽样均无自碰撞；载体若卡在 0.8mm，挡门强行闭合时会实体干涉，不会自动安全复位。R27 的 36/64 组机械共因逃逸原样保留。
- `r28_tolerance.py`：108 个假设 XYZ 相对公差配置，324 次 OCC 求交。±0.02mm 的 54 个配置均无指定自碰撞，±0.05mm 的 54 个配置有 50 个至少一处卡滞。
- `r28_clearance.py`：名义板厚 0.085mm、斜槽 Z 向最薄余料约 0.058mm、B 壳边缘余距假设约 0.015mm；挡门向外偏移 0.05mm 时，左右两端两姿态全部与 A 壳钥匙相交。**不能据此制造**。
- `r28_presence.py`：尝试了 A 键抬起竖向占位挡销以防无钥匙假扣。它在无钥匙时挡住爪的中间路径，却需要抬高至超出 B 舱厚度名义包络 **0.71mm**。该候选**被否决，未并入 B 壳**。
- `r28_dynamic.py`：10 个离散整机姿态，无指定 A/B/OLED/FPC 名义穿透。OLED 只是假设包络，不是 OEM 完整封装。
- `r28_export.py`：6 份 STEP 重新导入并校验。带 `GHOST` 的三份是危险或已拒绝状态，不可用于制造工艺图纸。

## 快速复核

在具备 Python、CadQuery、OCP、Shapely 环境的机器上，运行：

```bash
python -m unittest -q test_r28.py
python r28_attest.py
```

如果需要重算全部 OCC 及继承基线，可运行 `./r28_checks.sh`，可能耗时较长。本次最终 268 个测试收据来自**分阶段独立复跑**，曾有单次一键长脚本超时；最终证明脚本对各阶段日志作了独立哈希和数目校验。不能将一次超时记录解释成退出码零。

完整工程证据：`verification/R28_results.json`、`audit/R28_硬门槛对抗审计.md`、`vendor/R28_真实样机_电气_OLED_供应商验收.md`、`audit/R28_SHA256_MANIFEST.json`。

**制造 NO-GO：**无 A 键假扣合尚未物理闭合、强制回缩的力及卡死释放无实测、板薄与 B 侧轨无强度资格、弹簧轴销承力座未完成、实体电源及 USB 测试缺失、OEM OLED 厚度/动态半径/展平力/长期收纳寿命缺失。
