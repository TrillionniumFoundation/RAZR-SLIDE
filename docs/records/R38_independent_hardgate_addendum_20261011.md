# RAZR SLIDE R38｜独立复算、BM28 配对座空间加严和制造资格否决

**结论：R38 研究级架构复算成立，但整机制造仍为 NO-GO。** 本补充件不改变任何 R37/R38 原始 ZIP 成员，也不声称已取得可运行的跨舱连接。

## 2. 独立重新发现的装配缺陷

- 原 R38 的 **A 舱 Hirose header 目录外包络代理与 A 壳最小距离约 0.15mm**，并无实体固定座、PCB 实装或夹持件；不是已经装到主机上的连接器。
- B 舱将 header 代理与**尚未获得 OEM 许可的保护机芯体积**做布尔切除：移除 **1.84989568mm³**，切除后的研究实体有效、仍为单体。既无实际焊盘，也无应力释放/配对保持结构。
- 原 R37 外侧接点位置若直接代换为该 BM28 header 外包络，展开坐实时与 A 舱有 **0.1128mm³** OCC 实体交叠；这个直接替换位置应维持拒绝。
- 最关键：**两舱静态 header 根本没有跨舱 FPC 实体、布线或电气连接**。因此四种正常姿态 STEP 只能作为未经上电的布局研究，不能用“静态端接架构”宣称已解决跨舱供电或 USB。

真实 OCC 敏感性筛选：

- 同位置用 DS 目录包络替换时，B 舱还需额外挖去 **0.59345276mm³**，相对原 R37 B 壳的总切除增至 **2.44334844mm³**。

## 4. 不能提前宣告闭合的系统硬门槛

**M 机械**：旧双侧互锁的 **36/64** 个危险逃逸、失效常闭、A 侧终点机械坐实、受载限力回缩、轴承座和壳体承力均未获硬件验收。新静态电连接能避免每次滑行反复配合，但尚未证明独立的滑轨终点锁。

**F 动态跨舱 FPC**：真正需要同一根服务线同时完成 B 舱 Y 向 **79.75mm** 和 Z 向 **8.2mm**，并在整个连续路径里保持允许的曲率、张力、扭转、应变释放、OLED/导轨间隙。R38 的平面 U 环不满足其所设两端锚点 Z 分离假设，只能否决那一个简单模型。**不存在可用于采购的三维 FPC 工作图或 OEM 动态疲劳验收。**

**P 双电池主电源**：Hirose 产品页的电流额定是特定接点/试验条件，不能当作未经明确 pin map、峰值电流、反灌保护、BMS、温升、开断和 PCB 旁路实测的主电源系统资格。原 3 类单点 PCB 带电旁路仍缺排除证据。

**U USB**：目录的 20Gbps 描述不能代替本项目的真实头座配合、差分对布局、全路径 TDR/VNA/眼图、串扰/EMI、可弯线宽/回流参考层和 30万次寿命。

**D OLED**：特定 7 英寸 OLED 模组的完整封装（含 COF/FPC/封边）、Rmin、长时收纳残余形变、展平力、寿命和实装拉平力仍缺。IEC 62715-6-42:2026 是卷曲显示器的展平力测量方法，不是寿命许可。

## 5. R39 唯一值得继续的路线

1. 先取得 Hirose header+receptacle 原生 STEP、配合关系、焊盘/禁布区，再给 A 舱设计实际固定座，并审查 B 舱保护机芯切除是否允许。
2. **把两个静态端点用真实多轴动态 FPC 连接起来**：以厂商层叠结构和疲劳曲率为前提，在 Y=0～79.75mm、Z 末端 8.2mm 整段扫掠、碰撞、公差与压迫力闭合。若动态线束根本不具备空间，拒绝当前拓扑，不得假称通过。
3. 电源、USB、信号分开确定每个端子的 pin map 和保护电路，先断电再机械解锁的时序与失效常闭必须实体台架；OLED 原厂数据另开硬门槛。

**独立审计给出的结论是：原 R38 工程包可复算；增大到配对座目录包络以后安装公差仍失败。制造放行 `false`。**
