# R56 原厂资料与台架行动单（READY / NOT SENT）

**状态：资料请求未发送，仍为 0/12 类真实受控资料。** 本行动单作为对 R52/R54/R55 原 RFQ 的技术增补，不替换原 RFQ，不产生供应商许可。

## 同修订版 OEM 一次性交付

请提供同修订版、包含完整 CAD 基准的 A/B 两个成品壳体、PCB/电芯/BMS/摄像头/导轨、7英寸 OLED 含 COF/FPC/封边包络，全部可修改与禁改实体图层及**签署许可**，并给出至少四个有面外分布的可独立测量三维基准对应点、材料与 GD&T。当前研究 B/A 正碰撞区域只有否决意义，不是官方许可的切削位置。

## FPC/USB 高速连接

请给出准确的线束料号、柔性 PI/铜/胶/覆盖膜/屏蔽实际厚度、导体中性层、允许动态弯曲 R、最小静态 R、疲劳/扭转/拉力/端头固定及 EMC 约束。要求全程真实铜导体 USB 连续连通，覆盖前进 79.75mm、终点法向坐实 8.2mm、完整撤回，以及九组独立换向局部试验，不允许停靠才连通、无线或缓存替代。研究用计划有 7 条路线 × 1,019 个位置 = 7,133 个 **待测计划任务**；实际量产拓扑的测试网格应由供应商批准材料和实际运动控制确定。需提供原始 OCC/FEA、应变/曲率、TDR/VNA/眼图/BER、EMI/ESD、连接电压/电流实测、循环前后与连续寿命失效数据及测量工装。

## Hirose / 主电源 / 机械安全 / OLED

Hirose BM28B0.6-24DP/2-0.35V(53) header 与 BM28B0.6-24DS/2-0.35V(53) mate：分别提供原厂 STEP、焊盘、同版装配基准、每触点载流/降额和 10 次配合限制；不要把目录 20Gbps 写成整条 USB 的通路资格。主电源必须选独立额定器件/BMS 隔离方案并测量三类 PCB 单点旁路、熔焊/短路、预充/逆灌、电弧及真实无电触点波形。双终点机械锁必须提供 36/64 危险联合释放的实体排除证明、独立止挡和受载回缩；OLED 必须有完整封装、R、长期残余形变、展平力、失效循环统计及授权。

## 接收格式

每类文件需真实发文主体、受控文号/修订、适用料号、单位与坐标基准、原始 CAD 或测试二进制、SHA256、签章和适用许可；校验软件只能检查字节一致，**不能自行认证原厂身份、材料寿命或许可**。如拒绝提供实际机芯保留空间，则必须放弃当前侵入这些空间的连续 FPC 方案，转而研究其它仍保持实时有线连通的新机械路由。
