# R39 → R40 供应商询证与实物台架准入表（不是通过证书）

**F-01 动态 FPC：** 指定真实型号、制造批次、铜箔 RA/ED、层数、铜厚/线路宽间距、绝缘、胶层、补强和完整可弯段厚度、FPC 实际外廓、端点应力释放、动态 Rmin 与中性层、3D 允许扭曲角、最小 Y/Z 行程、推荐 3D 导槽/保持方式、热疲劳、30 万次目标寿命曲线及失效标准、取样授权。要求完整 STEP/ODB++/Gerber 与可追溯版本；R39 的 1.2mm 圆形线束代理和 R2.5/R15 假设不能代替这组数据。

**M-01 机构：** 保持两等外形舱、B 纵向 79.75mm + Z 8.2mm；取得真正 A/B 成品壳、主板、电池、相机、马达及锁件工程 CAD。建立与柔性线路分离的实体承力导轨、全行程防挤/防剪切、防折痕、断线保护、两端机械捕获和失效常闭；以完整 6DOF GD&T + 负载/冲击/磨损/异物实测验证。不可借 10 个 OCC 样本宣称全程净空通过。

**C-01 固定端连接：** Hirose `BM28B0.6-24DP/2-0.35V(53)` 配对 `...24DS...` 两端完整原生 3D STEP、配合方向、焊盘、禁布区、PCB 厚度、装配/维修次数、保持/抗拔；已知系列官方额定配合次数 10，不能每次滑动重新插拔。需要验证实际 FPC 端接方案和线束定位；R38 单独 header 浮置空间不可放行。

**P-01 双电池：** 实体电池型号、两舱 BMS、极限峰值/持续功耗、保险/双向隔离/预充/反灌、熔焊与 PCB 单点短路、线束接触电阻及温升、带载断开能量/电弧、跌落磨破测试；不得从连接器目录电流推导完整主电源资格。

**U-01 USB 与高速：** 先冻结 USB 2/3/4 的真实协议速率与引脚映射，再提供 3D 线束完整走线、差分阻抗和屏蔽地参考、S 参数/TDR/眼图/BER/串扰/EMI/ESD、运动中以及老化后系统测试。

**D-01 OLED：** 精确约7英寸原厂模组版本、全封装含 COF/FPC/驱动、动态允许最小半径、静置收纳永久变形和恢复时间、展平力、触控支撑压力、温循+应力+疲劳和失效判据。IEC 62715-6-42:2026 仅用于展平力测量方法，不是寿命合格证。

**放行规则：** M/F/C/P/U/D 均需有原厂材料+装配+实物工装数据、异常注入和负责人签署；任何失败则继续 `manufacturing_go=false`。
