**制造资格：NO-GO。** R70 没有生成通过的 FPC、获得 OEM 授权、发送采购邮件或执行任何实体试验。它针对 R69 的一处程序性假阳性实施真实修复、对抗复现并准备供应商交接资料。双同外形舱、约 7 英寸单柔性 OLED、B 舱滑动 79.75mm+终点法向 8.2mm、A 优先大电池维持原约束。

## 新发现并已复现：原 R69 的 13/13 结构完整假阳性

原版 `r69_intake_preflight.py` 对 `source_sha256`、供应商信息、签署人和授权只做非空测试。构造一份 13 类均填“伪造非空字符串”、**零个真实附件**的 manifest 后，原版进程返回 **退出码 0 和 structurally_complete=13**。原版输出仍包含 `manufacturing_go=false`，不能谎称原版会真正自动放行制造，但下游若以退出码当准入依据就会出错。攻击与修复对照见 `evidence/R70_R69_forged_metadata_witness.json`。此攻击在临时环境执行，真实供应商资料 0 个被触碰。

## R70 完成的具体修复

- 固定13个类别的准确 ID 与 key，不接受重复、缺失和多余记录（不用 `assert`，Python `-O` 同样拒绝）。
- 原始文件必须位于明确的**只读证据根**内，采用 `openat` 与 `O_NOFOLLOW` 逐级读取，无目录穿越/链接跳转；以 SHA256 校验实际文件字节，禁止同一字节包冒充不同类别。
- Ed25519 验证必须由**独立可信渠道钉住的 trust store SHA256**提供公钥；由供应商在 `R70-document-detached-signature-v1` 明确定义的消息格式签署，而不是在证据清单写“签名有效”。这是可选的**工程交接协议**，不代表供应商已经接受此格式或签过任何正式文件。
- 签名覆盖身份/修订/文件 SHA/授权声明/四个有序3D非共面基准点和量测方法版本；不允许混用 `datum_set_id` 和 assembly interface revision。此结构检查**不能替代真实配准、同根材料站位追踪及 R65/R68 原有签名/时间/锚点验收**。
- 唯一可能的绿色状态是 `ENGINEERING_REVIEW_ONLY`：只表示**相应被钉住的密钥对此批字节的签名数学成立**，不能仅由密钥持有者的自述证明 OEM 身份，更不能许可修改第三方 CAD。所有路径始终 `manufacturing_go=false`；制造资格必须由 M/P/S/U/D 多专业真实台架单独批准。
- CLI 默认只读，只向 stdout 返回报告；不会写供应商箱、信任文件或采购回执。不得用自生成密钥/夹具资料当做真实 OEM 数据。

## CAD 的真实物理阻塞，未因 R70 解决

- R40 的 2.0mm×0.15mm 假设宽厚、L134、R15 G1 FPC 代理在 **193/193** 两轴姿态中与 A/B 研究壳体发生正体积交叠；B **193/193**，A **92/193**。其 OLED 代理在 4 个姿态里 **3/4** 正交叠。有限宽厚 OCC 碰撞可否决候选，却不能证明所有拓扑不可行。
- 最近 R39 单独的 101 位置锚点负面筛选未生成完整 FPC；它与 R40 完整路径研究属于两个不同封存证据链，**不合并成虚假的新通过结果**。
