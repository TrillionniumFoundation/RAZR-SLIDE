## 2. 相切圆弧、曲率、同一条材料长度

R59 的各姿态网格路线长分别 92/52/27mm，且**三条路线是独立选择、并无同一根铜线的材料坐标映射**。R60 推导出在保持这些折线段方向且以等半径圆弧相切替换原 90°角时的局部半径上界：STOW **1.5mm**、MID **1.5mm**、OPEN **0.5mm**。

R61 的 `src/r61_c1_bishop_ribbon.py` 沿同样的原 3D 折线节点构造数学上切线连续 **C1（非 C2）**的研究圆弧。刻意选取统一假设半径 **R=0.4mm**，小于三个姿态的原折线圆角上界，仅用于产生一条可计算的折线家族实例；**不得视为供应商允许的动态 FPC 最小半径**。CAD 导出的实际几何是有限线段放样的近似，非真实连续层叠材料。

按每个90°圆角替代掉 `2R` 长度、改为 `πR/2` 弧长，中心线变为：

| 姿态 | 原折线长度 | R0.4 后解析 C1 长度 | 研究分段截面起始可测试的两初始宽轴 |
|---|---:|---:|---|
| STOW | 92.000mm | **91.141593mm** | y / z |
| MID_REVERSAL | 52.000mm | **51.141593mm** | y / z |
| OPEN_SEATED | 27.000mm | **26.656637mm** | x / z |

这三条曲线长度极差为 **64.484956mm**。这不是动态测得的 FPC 伸缩应变，反而证明**不能把三条独立最短路线当作同一根固定长度排线**。任何可行方案必须额外说明材料点随运动的对应、如何在展开放置多余长度的储线机构、如何限制中性层弯曲和扭转、端部应力释放。

更强的**局限于原折线+无额外绕行的相切圆角 family**的上/下界为：在收纳最大允许 R=1.5 时长度仍 ≥ `92 − 5×(2−π/2)×1.5 = 88.780972mm`；展开即使完全不进行圆角，其总长度也 ≤ 27mm。因此这一有限家族最乐观仍有 **≥61.780972mm** 差额。**它不是所有自由三维路由、带储线环设计的不可能定理，也不是已测材料疲劳。**

## 3. 方向连续的扁平截面 OCC 对抗

以每条 C1 近似曲线的离散切线，采用旋转最小/平行运输的 Bishop 帧逐截面给出连续宽度方向。每个姿态分别试验两个正交初始宽轴，代理为未获许可的 **裸 1.2×0.2mm，含各侧0.2mm研究余量后 1.6×0.6mm**；有限分段采用实际 `CadQuery/OCC makeLoft`，与**原 A 固定壳、只变换一次的原 B 壳**作体积布尔求交。下面为每个姿态**两种已测试初始方向中碰撞段最少的一种**，不是优化全体连续初始旋转角：

| 姿态 | 研究最优起始宽轴 | 与 A 壳相交分段 | 与 B 壳相交分段 | 与 B 壳分段交集体积求和 |
|---|---|---:|---:|---:|
| STOW | y | 0 | **15** | **1.008269mm³** |
| MID_REVERSAL | y | 0 | **15** | **1.008269mm³** |
| OPEN_SEATED | x | 0 | 0 | 0 |

同一格的分段交集体积是**各个代理段分别求交求和**，不是整体融合后得到的唯一交叠体积；它只用于定位失败。OPEN 的局部零碰撞不说明电路接通，不说明连接器根部的柔性过渡，也不说明从 STOW/MID 到 OPEN 存在无干涉的**同一实体路径**。

与 R60 最大的差异是：R60 的384个刚性直棱柱相互独立，各段可以瞬时切换宽度方向；R61 加入了几何**连续运输的宽度向量**以及角点切线圆滑化，避免了把一个个“过关朝向”错误地拼成可制造排线。依然没有得到**单根真实 FPC 的跨姿态材料映射、曲率连续性C2、可伸展应变、分层/中性层、接头固定、导轨/屏幕后互锁、寿命认证**。

## 5. 五条不可绕过的实物资格

1. **M机械：** 双侧错误解锁仍有 36/64 组旧危险逃逸；限力回缩、真实承力、断簧断销、老化疲劳尚无实体证据。
2. **P电源：** 三类 PCB 单点带电旁路、双电池逆灌/预充、断接残余电压与温升/电弧均未实测。信号弹片不等于双电池主电源方案。
3. **S信号：** Hirose BM28 两端静态目录代理无原厂完整端接 STEP 与配套安装工艺，实际 FPC 端部焊盘、固定及运动应力释放不存在。
4. **U USB：** 没有一条真实全滑程不断电、不断铜线、不中断数据的跨舱实体线路；TDR/VNA/眼图/BER/屏蔽/EMI/ESD均未经台架测试。
5. **D显示：** 实际7英寸OLED封边/COF/FPC/厚度、最小动态R、长时收纳形变、展平力与疲劳寿命未取得厂家同版本批准数据。IEC 62715-6-42:2026 规定的展平力测量方法**不能替代寿命合格证**。
