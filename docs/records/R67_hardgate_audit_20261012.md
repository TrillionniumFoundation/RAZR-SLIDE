# RAZR SLIDE R67｜原始 R66 解包回归修复与 R65 可信签名入口闭环

**结论：研究资料接收桥可在独立目录执行；制造 NO-GO。M / P / S / U / D 全部保持关闭。**

## 研究源与失效复现

- R65 源：81 个 ZIP 成员、SHA256 `613debb911f7b165aba0513bbbda83a21182efc1322ad589d10286a3d5789338`，冻结原始字节未修改。
- R66 源：10 个 ZIP 成员、SHA256 `bc298fbb3ab295b35d694af82e2d279ca6b82f20279ca9ba113bb846c376dda7`，冻结原始字节未修改。
- 实际将 R66 ZIP 解包到独立目录后运行 `python -m unittest discover -s tests -v`：异常 `FileNotFoundError .../R66_supplier_admission/docs/required_evidence_classes.json`，退出码 1。这个失败是**包可搬迁性缺陷**，不是供应商证据校验失败。
- R66 仅用平铺 `release.json` 元数据、payload SHA256 和 `signature_file` 存在性，无法与 R65 的实际已签名 `signed` + `ed25519_signature_b64` 标准兼容；R66 本来即始终返回 `REJECT`，并未放行制造，但“classes_present_with_hashes=13”会造成误读。

## R67 实际代码改动

- 新建 `src/r67_signed_gateway.py`：从脚本所在包根目录载入 2 份冻结 ZIP；逐项核对外部常量 SHA256、ZIP CRC、所有成员清单 SHA256、重复成员、路径逃逸及 ZIP symlink；要求两版正式 12 类名称与产品定义精确一致，另加第 13 类同材料 FPC witness。
- 在解压**同一批经 SHA 校验的内存 ZIP 字节**后，从中提取 R65 受控 `src/*.py`，在新的隔离 Python 会话中重跑它已有的数字签名、供应商类别授权、CAD/OLED/FPC受控字段、材料站位、疲劳时间序列检查。R67 不制造新信任根，也没有复制合成测试公钥到生产信任库。
- 可选的真实签发者验证需要独立设置签发方信任库，并给出通过另一渠道核验的**文件字节 SHA256**；校验后的相同原字节传递给子进程，避免重复读易变信任库导致的 TOCTOU。仅提交自声明的密钥不能证明真实 OEM 权限。
- 没有提供信任根、空信任根、pin 不匹配、伪造内容、源 ZIP 被改、符号链接密钥，全部拒绝；所有返回分支均强制 `manufacturing_go=false`。

## 五条真实制造门槛依旧失败

1. **M 机械**：旧联合解锁 36/64 危险逃逸；两端强制捕获、失效常闭与受载有限力回缩仍未取得实物证据。
2. **P 电气**：双电池三类单点 PCB 旁路、逆灌、预充与断接余能/电弧未台架验证。TE 2199001-1 的信号 1.5A 目录用途不能作为主电源放行。
3. **S 接点**：Hirose BM28 header/mate 原厂端接、实际 PCB 焊盘与拉力释放没有受控同版资料；它们仅用于静态端接研究。
4. **U USB**：没有真实铜线跨 79.75mm 上滑 + 8.2mm 坐实时的连续导通和高速眼图、TDR、S 参数、EMI/ESD 测试。
5. **D OLED**：缺具体 7 英寸模组完整封装（COF/FPC/封边）、动态 R、储存残余形变、展平力、疲劳与触摸资格。IEC 62715-6-42:2026 是展平力测量方法，不是寿命证书。

**供应商 12 类 + FPC 单材料路线 1 类，真实文件接收数 0/13；RFQ READY—NOT SENT。** 当前不宜继续以研究壳替代原厂空间，收到可修改授权、真实签名和结构/电气/FPC叠层样品后，才能回到三维 OCC 全程扫掠及台架。R67 软件回归不改变 `manufacturing_go=false`。
