# R18.3 — 跨舱触点公差可行域（仅解析筛查）

本轮重新运行 `/mnt/data/RAZR_SLIDE_R18_2/test_r182.py` 的28项测试通过；新增独立脚本 `contact_margin_study.py` 对末端触点压缩量进行公差包络筛查。

**重要：输入均为假设，非经认证的弹簧触点性能或厂商图纸。** 假设相对位置偏差±0.25mm，所需有效压缩量为0.10～0.50mm。则名义压缩量必须同时不小于0.35mm且不大于0.25mm，**无解**。R18.2名义0.10mm，最坏最小压缩量−0.15mm。这是对这组容差/目标的设计否定，不是对所有弹簧触点方案的否定。

最低下限之外还须确认接触力曲线、额定电流与端子温升、接触抖动与电弧、高速通信信号完整性、触点污染和镀层磨损、收放与硬锁止联动。没有真实器件曲线，不能放宽0.10～0.50mm假定区间后宣称已通过。
