# R35 供应商资料及实物门槛（需求清单，非已完成证明）

**机械 M：** 索取 A/B 两端完整、修订号一致的配合界面和真实外壳 3D/GD&T；指定弹簧、销、卡簧/螺钉/防退机构、材料牌号、表面处理、紧固方式、生产装配基准。样机必须在独立双端工装验证：无 A 钥匙/假扣、单侧与双侧同时错误释放、断簧/断销/卡扣丢失、异物、跌落冲击、磨损、温湿热及可承受外载。预先定义限力回缩阈值及载体卡死后的安全状态，取得多样品原始波形与力—位移曲线。0.03mm 旧薄壁和加强轨具体与 PCB/电池重叠情况须全包络评审。

**信号 S：** TE 2199001-1 官方类别是单极 `SHIELD FINGER`，标注 Signal / 1.5A；不得假设其有任何可支持 USB 的确定差分引脚、隔离外壳或 300k 插拔资格。针对真实修订型号拿到原厂 STEP、2D 产品图、PCB land pattern、焊接工艺、工作压缩量、接点力、初触/最终脱离行程、接触电阻与循环损耗；在机械分离前实测断接先后与裸露面积。

**供电 P：** 与信号完全独立选型。定义两电池 A/B 的电芯、电压范围、持续/脉冲电流、主板负载与控制器；采用真实额定主电源互连或重构为不同舱独立供电/受控能量交换。保护必须验证逆灌、单点 PCB 短接、FET 熔焊、预充、短路/热插拔、电弧、接触温升和残余电压。不得以 TE 1.5A 单极弹片给两电池主电源制造资格。

**USB U：** 冻结端口规格、拓扑、线对及具体供应商连接器/排线、PCB 叠层、回流地与屏蔽；出具真实 TDR、S 参数、眼图/BER、串扰、EMI/ESD、运动和振动最坏姿态结果。内部定制高速链路不能自动声明 USB Type-C 连接器合规。

**OLED D：** 向目标约 7 英寸柔性 AMOLED 厂商索取修订号对应的模组完整 3D（含封边、COF、FPC、驱动、胶层）、屏幕中性面、最小动态 R 与应变、长期储屏平整度/残余形变、展平力-温度/循环矩阵、触摸与支撑压力、寿命失效判据、取样授权。IEC 62715-6-42:2026 是展平力测量方法，不能替代厂家寿命许可。

**放行判定：** 所有 M/P/S/U/D 必须从独立专业负责人取得原始台架数据和审批；仅有 CAD、AABB、PASS 测试数及 STEP 导入时，`manufacturing_go=false`。
