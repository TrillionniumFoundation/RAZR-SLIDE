# R41：独立 OEM/RFQ 及样机硬门槛（尚未提交供应商）

## F－跨舱动态线路：当前 NO-GO

**Molex Premo-Flex 15036 系列**，候选 `150360505` = 5回路，0.5mm节距，127mm长；Molex 公开的 700k @ R5mm 或 5M @ R10mm 是系列特定试验条件，与整机2轴周期不是同一力学试验，最高0.35A/回路、不能作为双电池主电源。官方资料：
https://www.molex.com/en-us/products/series-chart/15036
https://www.content.molex.com/dxresources/27c8/27c8a514-327e-46ab-ad1f-f005c3c95c8e.pdf

Molex 指向配对 **225019 FlexiSnap-15**，而旧 Hirose **BM28** 是仅10次插拔的板对板连接器，不能直接接它的柔线尾端。必须明确完整配合对（两端和运动中线束），准确 3D/PCB land pattern、定位、卡扣、组装顺序、连续形变半径、可接受扭转、动态拉力、最坏环境下循环和失效判据。

请求 FFC/FPC 供应商提供：准确部件和批次的真正叠层剖面、铜箔/镀层/胶、外宽、厚度公差、允许 R、短长度/两端应力释放、完整中性轴动力模型、300k/目标循环多样品实测、电路最大压降/温升，独立电源线与 USB 信号对必须分别指定材料/连接器。

## M－机械

明确 A/B 端3D PCBA、主板、电芯、摄像头、导轨、卡簧、螺钉、隔振、屏幕装配保护体；重新布置屏侧服务廊道和硬保护盖，不侵入 OLED/屏蔽封边。指定槽壁连续承力最小值和实际工艺 GD&T；考虑振动、卡死、销轴断裂、掉落、金属屑和断电复位；对两端分别完成机械坐实/防假扣试验。

## P－双电池供电

不得用 0.35A/回路 FFC 或 TE 2199001-1 Signal 1.5A目录额定值放行。冻结各舱 BMS 架构、最大峰值和持续电流、单向/双向隔离、反向阻断、预充电、熔丝、导线温升、三类 PCB 旁路故障处理、滑动过程负载转移和真实断接电压；带载故障台架有物理证据。

## U－USB与信号

定义 USB2、USB 5/10/20Gbps 中**具体**目标。板级/动态柔线整体测 TDR、VNA S参数、眼图/BER、接地回流、连接器屏蔽、ESD/EMI和摩擦磨损；BM28 `20Gbps` 型号目录称号不等于系统 SI合格。必须确定与目标动态线材真正匹配的端接结构。

## D－柔性 OLED

要求准确 7 英寸型号、COF/FPC/封边及保护膜整个生产外包络，动态最小 R/允许局部压痕，长期收纳残余形变及恢复时间，展平力随温度和寿命变化曲线，完整运动/触控寿命和样品授权。IEC 62715-6-42:2026 是展平力**测量方法**，不是寿命保证。

## GO/NO-GO

必须全部由责任工程人员签署 M/F/P/U/D 五门槛测试报告，设计版本和原厂部件一致；否则始终 `manufacturing_go=false`。如果现实 A/B 保护体积与线束所需自由走廊无法同时成立，应取消当前跨舱路线，在维持产品形态的前提下重排硬件/电源拓扑，而不是让软件路径穿过现有导轨、电芯或 OLED。
