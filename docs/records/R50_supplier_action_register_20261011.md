产品冻结：两个成品同外形功能舱；B 从收纳后下层沿 Y 移动 79.75mm，随后 Z 向坐实 8.2mm；单块约 7 英寸柔性 OLED，无独立背面外屏；A 舱优先较大电池。全运动过程的跨舱 USB 必须保持**真实有线物理连续性**，不接受无线/缓存或仅终点 DOCK_ONLY 替代。4700mAh 为目标，不是合格容量。

## 需要按统一 XYZ 坐标基准交付的六组受控数据

1. **OEM 整机**：A/B 实际完整壳体、PCB、BMS、电芯、相机/镜组、滑轨/锁、OLED 封边与 COF/FPC、不可侵入件和可加工空间；装配公差、热边界及授权可切目录。须提供元件版次、原始 CAD、签名与可验证来源；本轮不能擅自切穿研究 BRep。
2. **FPC 厂商**：具体产品与叠层（铜层厚/应变、中性轴）、真实宽与总厚、动态双轴 Rmin、允许扭转、支撑/应力释放、两端 6mm 以内的最小可用固定/圆角空间、三维安装姿态和连接器配合图、30 万次双向全程循环报告及失效判据。R15、W1.2、t0.2 均是筛选假设，绝不作为厂商定额。
3. **USB/连接器**：两端实际可订货料号和配合结构（Hirose BM28 如选用必须定义低频静态维修，不得用于滑动循环插拔）；PCB 焊盘、固定座、差分阻抗、回流/屏蔽、具体目标速率、实物全行程 TDR/S参数/眼图/BER/ESD/EMI 及异常中途反向保持在线记录。
4. **双电池供电**：两端 BMS、主电源峰值/持续电流、可断/不可断路径、反向阻断、预充、熔丝、PCB 三类单点旁路、带载断开电弧、余压和热升实测。TE 2199001-1 的目录 1.5A Signal 不能证明主电源资格。
5. **机械安全**：收纳和展开端独立承力捕获、真正失效常闭弹性构件、载体卡死限力回缩、断簧/断销/异物/冲击/高低温/循环/脱扣与 36/64 历史危险反例的实物关闭记录。
6. **OLED**：确切 7 英寸模组含驱动/COF/封边的完整外形、动态 R、长期平储残余形变、展平力、允许压紧张力、双轴循环寿命与失效判据。IEC 62715-6-42:2026 的展平力测量方法不是材料寿命认证。
