# RAZR SLIDE R45｜跨舱动态 U 回弯的 XYZ 同坐标审计及曲线占位复核

**最终工程资格：`manufacturing_go=false`；禁止制造、带电试装或将研究 BRep 切槽视为 OEM 许可。** R45 是 R44 冻结分支的独立增量负向验证，并不证明所有三维 FPC 路径不可实现。

## 2. 最重要的新否决：R44 的 3mm Z 仓并未与 R39 真实回弯共坐标

R43 的研究 B 舱世界位姿实际使用：`B_world = B_local + (0,s,q−8.2)`；R39 冻结参考曲线的 **U 形主圆弧处于世界 Z=6.05mm**（R45 还直接验证了多个状态下圆弧顶点的 Z）。因此：

`Z_U_in_B_local(q) = 6.05 − (q−8.2) = 14.25 − q (mm)`。

- 在收纳 `q=0` 时，回弯位于 B 局部 **14.25mm**；在展开坐实 `q=8.2` 时，B 局部 **6.05mm**。B 局部固定坐标下的必要垂直行程为 **8.2mm**。
- 由实际 OCC BRep 读出的 B 研究体 Z 包围盒约 **0–7.20mm**。按这条 R39 曲线，**458/481** 个离散状态中圆弧平面超出 B 名义 Z 包围盒；全部 **481/481** 状态都不处于 R44 假设的 **0.75–3.75mm** 服务仓。上述计数对 R44 三个恒长方案均成立。
- **任何固定于 B、只高 3mm 的仓**都不可能在该冻结运动规则下容纳一个垂直移动跨度 8.2mm 的同一主回弯平面。只计算零厚度圆弧至少需 8.2mm 高；仅按本轮假设厚度 0.20mm、每侧 0.20mm 余量计，则占位高 **8.8mm**。这不是 FPC 厂商资格要求，也没有考虑两端引出弯曲、导向护罩和应力释放。
- 因此 R44 那些使用 Z=0.75–3.75mm 的 `3115.419mm³`、`9.918%` 等切除结果，仍可作为**特定假设高度带上的体积预算对比**，但**不能解释为真实 R39 U 形回弯已腾出的同坐标三维通道**。

原始 JSON：`results/R45_z_coregistration.json`；参考图：`plots/R45_Z_frame_mismatch.png`。

## 4. 重新分析可以跟随 B 舱移动的回弯 Z 假说（仍然全部拒绝）

为避免“R39 A 固定回弯失败＝一切 3D FPC 不可能”的不合理推论，R45 另做**纯粹条件性**的高度插值：

`Z_arc_world(q,α) = α×6.05 + (1−α)×[3.5+q−8.2]`。

- `α=1`：原 R39 的 A 固定回弯；B 局部 Z 超廓，多数状态不在 B 壳内。
- `α=0`：回弯随 B 移动；在收纳时世界 Z=-4.7mm，超出 A 研究 BRep 的下方界限 -3.4mm。
- 按 A 世界 Z 边界 -3.4..7.2、B 局部 Z 边界 0..7.2 的**单轴粗包络**，理论上只有约 `0.12093≤α≤0.34419` 可以两侧同时不越界。取 `α=0.25` 时粗高度包络成立，但实际 OCC 对该回弯实体的 **10/10 个代表姿态**均检测到与 B 舱研究实体的正体积相交。

另外 α 改变了 R39 原三维中心线及端点运动，**尚未重新求解固定总弧长**，也不具备任一端应力释放、动态扭转和寿命许可。Z 粗包络符合不意味着无材料碰撞，更不代表改道成功。完整 3×10=30 组探针：`results/R45_3D_arc_probe.json`；四份 3D 姿态 GHOST STEP。

## 5. 与跨舱连通性相关的架构条件（不擅自选择）

- `CONTINUOUS_FPC`：理论可连续物理传输，但实际 3D FPC 尚无合法空间/厂家叠层、应变、连通/功率/高速 SI 资格。
- `DOCK_ONLY_WITH_B_STANDALONE`：A/B 在运动时断开，B 侧必须本地独立供电；**物理 USB /跨舱实时数据会中断**。尚未取得产品方接受中断的明确授权。
- `DOCK_ONLY_WITH_RADIO_DATA`：无线桥不能冒称物理 USB 不断连，也不能作为主电源；没有 RF 芯片、功耗、延迟/吞吐、共存验证。

仅为量级试算：15W 持续负载、3.7V、85% DC 转换效率、持续 5 秒时，B 电芯理想输入电流约 **4.769A**、消耗约 **6.624mAh**，与电芯循环寿命、低温/老化/峰值放电及 4700mAh 目标**无关**。若 5Gbps 的跨舱应用数据被中断 5 秒且完全缓存，原始积压至少 **3125MB（十进制）**；缓存不能维持真实 USB 总线实时传输。`results/R45_architecture_decision.json` 保存所有假设及断言。
