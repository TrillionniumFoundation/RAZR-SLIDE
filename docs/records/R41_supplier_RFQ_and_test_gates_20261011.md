# R41 动态跨舱 FFC、连接器、OLED、机械和电气询证需求（非认证）

**发给 Molex/柔性线路制造商：** 请核对 15036 150360405 (102mm,5回路) 与 150360505 (127mm,5回路) 的完整 3D 外包络（真实宽度/厚度/端部 stiffener）、接点图、可夹持区域、适用的 FlexiSnap-15 `225019` 配对型号和 PCB 焊盘；确认 700k@R5/5M@R10 是否适用于准确 SKU、实际双轴 79.75mm 移动+8.2mm Z 坐实/扭转、30万次、目标温度、湿度、夹持与失效判据，并提供铜材、层叠和中性轴数据。请给出真实弯折试样与驱动工装、插损/阻抗/EMI/ESD/USB SI 资料。**没有完整硬件资质不能设计主电源。**

**给机壳/PCB/OEM：** 请提供等外形 A/B 完整外壳、实际 PCB、相机、电芯、电池绝缘、导轨/止挡与弹簧、OLED 安装和保护体积的准确 3D/GD&T。明确允许改动的空间及热/材料/载荷预算，设计从舱内固定座到滚动 FFC 回弯的连续带护盖槽；首阶段禁止削薄 0.030mm 的旧前缘和未经验证的 0.22mm 侧轨。

**给电源设计团队：** 两舱电池供电图和负载峰值、独立供电还是受控跨舱供电、BMS/保险/反向阻断/预充/放电、跨主板错误桥接的单点故障、故障接点残余电压/弧光温升等必须有真实示波器与台架记录。单 FFC 回路 0.35A 不能承担未定义的主电源。

**给 USB/SI：** 先指定 USB2/高速接口目标及引脚拓扑、FFC 回流路径/差分对阻抗、连接器实际端接，跑移动全程 TDR/VNA S 参数/眼图/BER/EMI/ESD、温漂、反复弯折后 SI。不得以 BM28 或 FlexiSnap 产品目录速率冒充整链路认证。

**给 OLED：** 请提供唯一指定约7英寸面板的完整 3D 封装（COF/FPC/封边、总厚度和保护层）、实际动态 R、长期收纳残余形变/展平力、压伤/应变/触摸性能和30万次目标寿命数据及项目使用许可。IEC 62715-6-42:2026 是展平力方法，不是寿命合格证。

**放行规则：** 完整机械 M、FFC F、接点 C、电源 P、USB U、OLED D 全部供应商资料与实物台架独立通过前，`manufacturing_go=false`。
