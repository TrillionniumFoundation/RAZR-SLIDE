# RAZR SLIDE R40｜完整宽厚 FPC 两轴运动实体扫掠与硬门槛否决审计

**最终制造判定：`manufacturing_go=false` / NO-GO。**

R40 完成了可复算的三维 G1（切线连续）跨舱 FPC **研究代理**、193 个运动状态下的完整实体 OCC 求交、曲率/长度扫参、宽厚敏感性、B 端迁移代理，以及独立继承回归。所有候选材料尺寸为假设，**没有制作真实 FPC，亦未取得厂商封装数据、试样或电气台架证据**。正碰撞可以否决该候选；不碰撞不能证明可制造或疲劳寿命。

## 1. 不变的产品形态及可用基线

- A/B 为目标相同**成品外观尺寸**的两个独立功能舱；没有证据证明当前研究实体 BRep 全部方向已经同尺寸。
- B 由收纳时的后/下层沿长轴向上滑 **79.75mm**，随后法向坐实 **8.2mm**；单块约 7 英寸柔性 OLED，无独立外屏；A 舱优先较大电池。4700mAh 仍为目标，不能视作现成电芯容量。
- 从 `RAZR_SLIDE_R39_verified_engineering_package_20261011.zip` 原始 1,150 个归档成员开始；其完整 ZIP SHA256 为 `5190d553f35a9a06de2f217b926d9477471a90a1bc99d2aabcb506821d07996e`。外部来源实际读取、CRC 通过，原始 1,150 个文件在 R40 目录中**逐字节一致**，记录见 `audit/R40_R39_immutable.json`。
- A/B 采用 R38/R39 研究 `cad/R38_A_R37_BYTE_IDENTICAL.brep` 和 `cad/R38_B_PROVISIONAL_STATIC_HEADER_CLEARANCE.brep`，其中 B 已含未取得 OEM 批准的研究性挖槽；**不是**完整 Motorola PCB、电芯或正式结构安全体积。
- 两端 BM28 是静态端接**目录代理**，目前无 OEM PCB/端接固定证据。R40 研究 B 端的虚拟回环位置需要将原 B x≈32.7mm 内迁 **30mm**，但未实际修改 PCB/B 壳安装基准。

## 2. R39 → R40 数学改型：消除折角，保持两端夹持切线

R39 舱内 R15 由 XY 半圆与倾斜 Z 向直线尾臂相接，接头切线不连续。R40 取 A 端固定 `(32.7,70,6.05)`、虚拟 B 端 `(32.7−2R,15+s,4.8+q−8.2)`：

1. A 端沿 +Y 直线至曲率起点。
2. XY 平面半圆半径 R15，从 +Y 方向切线连续转向 −Y。
3. B 尾臂采用 `z(t)=z_A+(z_B−z_A)(3t²−2t³)`，两端一阶导数为零，因此圆弧末尾到尾臂、B 夹持点的切线连续（G1）。**它不构成 G2 曲率连续，也未求解真实弹性线平衡、导体应变及夹持力。**
4. 在每个运动位置数值反解折返点 Y，使理想解析长度 `L=(Y_turn−Y_A)+πR+∫√((Y_turn−Y_B)²+(ΔZ·(6t−6t²))²)dt` 为同一个 L。

完整运动为 **161 个纵向位置（q=0）＋32 个法向位置（s=79.75mm）= 193 状态**。计算以假设 **0.15mm 厚** FPC 和概念级 **R15** 为筛选条件，不能把 100× 厚度规则当成特定供应商的寿命承诺。实际弯曲半径必须以厂家目标层叠、中性面、铜箔和寿命试验确定。

| 几何方案 | 193 状态最小全路径曲率半径 | 状态未达到假设 R15 |
|---|---:|---:|
| R15 / L≈108.086mm | 4.902mm | 70 |
| R15 / L=124mm | 11.068mm | 24 |
| R15 / L=128mm | 12.973mm | 12 |
| R15 / L≈131.962437mm | 15.000mm | 0 |
| **R15 / L=134mm（本轮 OCC 主案）** | **15.000mm** | **0** |

数值下界约 **131.962437mm** 是**当前特定 G1 参数化族**满足假设 R15 的长度下界，**不是**真实全局最短 FPC、最低应变或电气设计最优解。R40 L134 的解析长度在 193 状态漂移在浮点舍入内，真实导出的是 65 个截面之间的**分段直纹 loft**，不能宣称材料长度和中性面在物理形变中严格守恒。

## 3. 核心 OCC 结果：有限宽厚、193/193 状态均穿壳

取用于装配否决的**非厂商尺寸**：假设宽 **2.0mm**、厚 **0.15mm**。沿 G1 路径放置矩形截面，64 段直纹 loft 得到实际 OCC 单一有效三维实体，并在每个状态与 A 壳（世界坐标）、B 壳（反变换至 B 自身坐标）做真正的实体体积求交：

| 完整 193 状态 | 检查结果 |
|---|---:|
| 全部状态实体有效 | 193 / 193 |
| 与 A **或** B 壳正体积相交 | **193 / 193** |
| 与 B 壳正体积相交 | **193 / 193** |
| 与 A 壳正体积相交 | **92 / 193** |
| A 壳最大交叠 | **9.961889mm³** |
| B 壳最大交叠 | **31.844319mm³** |
| L134 理想路径全程曲率下界 | **R15**（筛选值） |

四个阶段 `STOW / MID / PREDOCK / OPEN` 使用有效完整 loft，包含收纳、坐实前、完全展开 3 份可重导入的有限宽厚代理 STEP。**这不是真实 FPC STEP 或完整手机装配 STEP。** 全部 193 状态的逐项 A/B 交叠体积、解析长度和曲率记录在 `verification/R40_all_193_finite_volume_motion.json`，对应三维实体几何见 `cad/R40/`。

对 R17 继承的**研究 OLED 占位体**再做四个姿态的完整 ribbon OCC：收纳/中程/预坐实 **3/4 存在正体积交叠**；该 OLED 不是目标原厂全封边/COF/FPC 封装，零交叠的 OPEN 不代表 OLED 安全。

## 4. 宽厚、公差与端接迁移敏感性（仍是模型假设）

- 四个姿态分别取 0.5×0.10、1.0×0.10、2.0×0.15、2.6×0.75mm 四档截面，**16/16 个有限实体方案与 A/B 壳发生正体积相交**。其中最后一档在标称 2.0×0.15mm 尺寸外每面额外留 **0.30mm 假设保护距离**，不是已由 OEM 授权的制造间隙。
- R15 需要虚拟 B 端由 x=32.7 内迁至 x=2.7。选取 25 条宽 2mm、厚 0.15mm 的**直线端接迁移占位棱柱**（y=5/10/15/20/25，z=2.5/3.5/4.8/6/7），**18/25 条与 B 壳发生实体交叠**。未交叠的 7 条并非实际可用走线，尚未检验 PCB、焊盘、支架、挠曲曲率及连接器安装。
- 原先 R39 对单侧边条带 3.33454mm 的上限已经不足以容纳假设的 R7.5/R15 侧向 180° U 弯直径；R40 没有声称否定所有可能的多轴动态排线拓扑。
- 由于**名义状态已经全部不合格**，本轮没有继续用数字 ±0.05mm 公差扫描来掩饰结构不可装入，也没有削切未经 OEM 许可的 A/B 壳体去强行制造“零穿透”假结果。

## 5. 真正还缺的物理、电气和结构资格

1. **M（机械）**：R37 等前轮 64 个联合故障中仍有 **36 组危险逃逸**，两侧实体硬坐实、断销/松脱失效常闭、受载有限力回缩、卡滞与污染/冲击/磨损测试未闭合。改用静态 BM28＋动态 FPC 不自动消除机械安全要求。
2. **P（电源）**：三类单点 PCB 旁路会使暴露触点带电的故障模型仍在；未冻结跨舱主电源、BMS、电芯不同荷电状态隔离、反灌、预充、熔丝/关断 FET、接触电阻/热升/断接电弧的真实器件和台架。**TE 2199001-1 是信号弹片，1.5A 目录上限并非双电池主电源认证。**
3. **S/U（信号与 USB）**：Hirose BM28 静态端接 24 位候选仍仅是目录包络，缺完整原厂 3D 配对件、PCB 焊盘/支架/固定、动态排线全叠层、USB 目标速率与 TDR/VNA S 参数/眼图/BER/串扰/EMI 验收。
4. **D（OLED）**：没有真实 7 英寸 OLED 模组的全部封装宽度、封边/COF/FPC、动态最小 R、长期收纳残余形变与展平力/疲劳数据。IEC 62715-6-42:2026 是**展平力测量方法**，不是动态寿命证书。
5. **E（整机）**：两块成品外壳确实同外形、原厂两舱主板/摄像头/电芯完整保护体积、4700mAh 目标及支撑板空间仍未证实。R38 研究壳体已作过未授权挖槽，不能擅自再削切来“收敛” FPC。

## 6. 测试与复核的真实边界

- 使用隔离 cell 从外部 R37 ZIP 全新运行 **R21–R37 661 项**；从封存的 R39 工作树新运行 **R38 36 项、R39 37 项、R40 47 项**，总计 **781/781 项研究测试通过**、对应实际退出码均为 0。所有日志和校验见 `verification/R40_fresh_regression_results.json`；通过的负向断言是**正确捕获危险设计**，绝不是 781 项正向安全证明。
- R39 原 1,150 个成员逐文件 SHA256 一致。完整 STEP 均导出/重导入有效，但每次复算会因 STEP 序列化头部等产生文件哈希变化；源代码、姿态、实体体积和碰撞判断才是主要复算对象。
- 本轮 **不包含真实样机、受载弹簧/铜线力学、夹持边界、连续弹性体 FEA、铜箔材料应变、循环寿命、线束供应商签字或电气测量**。

## 7. R41 唯一应优先投资的架构工作

**停止在未经 OEM 授权的研究机芯实体上盲目增加凹槽。** 先取得真实 A/B PCB、电芯、导轨、摄像头和目标 OLED 完整保护 BRep，以及指定供应商的 FPC 宽厚/铜层/动态寿命及夹持规范，再进行联合可行性求解：静态连接器安装座、有限宽厚 3D 连续线束、实际导向壳、完整扫掠体、应力释放与所有状态的容差安全距离必须同时成立。若需要为 R15 回环腾出 15–30mm 横向空间，应出具对 SoC、电池及总厚度的明确体积/功能代价，再选择是否调整模块划分。

如果 OEM 空间不足，应正式停止 R38 静态端接＋连续 FPC 路线，比较**各舱独立电源＋隔离短距信号连接**等其他拓扑；这也是**未经验证的备选架构**，不能擅自认定安全或合规。

**最终结论：`manufacturing_go=false`。**
