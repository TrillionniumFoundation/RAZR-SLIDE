# R39→R40 真实跨舱线束与连接器供应商询证/实物试验单

**本文件是询证/试验条件，不是原厂答复或实测报告。制造放行继续 NO-GO。**

## 设计不变条件
A/B 成品同外形，单约7英寸可弯 AMOLED、B 在两舱间上滑79.75mm再法向坐实8.2mm；无线外屏，A 优先电池。产品名义宽 73.99mm、长94.25mm是当前研究基线，不是已装入 OEM 电子件的确认值。目标30万动作循环需要厂家联合定义合理寿命/失效判据。

## 需要供应商以**具体 PN/修订/批次**提供的 CAD／材料／样机

1. **跨舱柔线**：铜箔类型与晶粒取向、实际总叠层厚度和宽度、全部导体层结构、覆盖膜/粘合层、中性面位置、每段允许动态 R、允许扭转与反向弯折、冷热循环与弯折后连续性/绝缘、额定动态张力、导向与保护套的真实 STEP。必须提供跨舱两轴完整 3D 装配及样机，并声明 30万次是否有历史数据。
2. **电气**：A/B 侧实际 Hirose BM28 header+mate 的原生 STEP、准确配对 PN、板端/柔端焊盘图、板厚/线宽、屏蔽和保持设计、装配方向、允许力、应力释放；明确是否适用于移动寿命，现有连接器仅作固定端接研究。
3. **双电池电源独立线路**：额定持续/峰值电流、线束电阻与热升、双端 BMS、反灌阻断、隔离 FET、预充、熔丝和硬件短路路径；不得默认信号弹片或 24 位连接器能够分担所有电源通道。
4. **USB 数据线路**：真实目标 USB 速率、线束阻抗、差分长度匹配、铜屏蔽/接地与弯曲状态 SI 模型；提供最坏姿态 TDR/S 参数与眼图/误码率/EMI 验收方案。
5. **OLED**：原厂实际完整封装 CAD（含封边、驱动IC、COF/FPC）、允许动态曲率、长时间收纳残余形变、展平力、循环/局部压力失效判据，说明若和跨舱柔线邻近的最小净距与防擦条件。
