## 2. 曲率数学边界：每个姿态的自由弧长必要区间

**严格限定本研究假设：**一整条材料长度总计 `L_total=70mm`（不是 OEM 料号）、真正暴露弧长 `L_free(s,q)∈[0,70]` 可由假设的 cassette 连续变化；材料是无铰链、无折角、曲率 `κ≤1/15mm` 的 C¹,¹ 中心线；没有实际端部夹持切向、厚度/应变/张力/摩擦、线速上限或铜层疲劳数据。

原端点相对长度：`d(s,q)=sqrt[(s−55)²+(q−9.45)²]mm`，先 `s:0→79.75` 且 `q=0`，最后 `s=79.75` 时 `q:0→8.2`。在 `s=26.5272498694mm` 首次进入 `d<30mm` 的区域，持续到全坐实；因 `L_total=70mm` 不足以在最紧 `s=55mm` 选择长圆弧分支，若自由弧长连续，首次切入后只能选择比较圆弧的**短支**：

`d(s,q) ≤ L_free(s,q) ≤ 30 asin[d(s,q)/30]`（在 R15 比较圆弧成立的这一路径区段，且弧长小于 `2πR`）。

这个条件来自曲率上界的 **Schwarz/Schur 比较不等式**，是**必要条件而非充分条件**；具体弧线是否能绕过 A/B/OLED，仍必须用真实厚度和厂商数据做完整 CAD。基础文献：John M. Sullivan, *Curves of Finite Total Curvature*, Theorem 5.1, <https://arxiv.org/abs/math/0606007>；H. A. Schwarz 曲率限制弧长排除定理的经典论述见 <https://jasoncantarella.com/downloads/Collection%201967%20Chern.pdf>。

按上述规则生成 **503 个互不重复的参考工位**（401 纵向常规格点+首次 `d=2R` 临界点+连续极小点 `s=55`+100 个新增法向坐实点）；见 `results/R75_503_pose_interval_schedule.csv`。R39 和 R41 以前的负面 OCC 证据是单独来源，本轮没有声称 503 姿态都完成了新的三维 OCC 带体布尔求交。

## 3. R75 新发现：中程速率下界严格高于首末平均

假设储线器的暴露线长对运动进度 `t=s+q` 具有全程速率比上界 `|dL_free/dt|≤k`（只是待验的运动控制能力要求，不是电机配置）。任意姿态 i<j 的数学必要区间 `[low_i,upper_i]` 要求

`k ≥ max(0, low_i−upper_j, low_j−upper_i) / (t_j−t_i)`。

R74 对收纳→s55 的端到端计算只给出 **0.8398588444mm/mm** 的平均收线量下界。R75 对 503 个参考点的所有成对区间进行对抗枚举，得到更严格且具有**具体两工位见证**的速率下界：

| 工位 | 区间限制（单位 mm） |
|---|---|
| 收纳 `(s=0,q=0)` | 暴露自由线长不得小于 `55.8059360642` |
| 滑动 `(s=42.66625,q=0)` | 暴露自由线长不得大于 `16.3327874627` |
| 运动间距 | `42.66625mm` |
| **速率比必需下界** | `(55.8059360642−16.3327874627)/42.66625 = 0.9251609551mm/mm` |

任何**连续**可行模型都必须至少满足这两个具体工位，因此 **0.92516 是确切的必要下界见证**；它不是“连续全程已精确证明最优”的承诺。采用 `k=0.9251609551+1e−9`，可以从所有离散 `upper` 构造一条通过 **503/503 个必要区间**的 Lipschitz 自由线长参考表，见结果 CSV。该表不证明中间任意姿态的曲率、材料长度站位或实体空间合格，更不是储线盒的机械控制程序。

## 4. R75 新发现：非自适应固定放线指令的相对端点误差极限

在最紧 `s=55mm`，名义端距只有 `d=9.45mm`，短支自由弧长仅能在 **[9.450000,9.6136996215]mm**。假设同一个固定放线指令需要兼容端距在 `[d−E,d+E]` 区间所有实际偏差，且不能读取/补偿实际端距；它必须同时满足：

`L_free ≥ d+E`（可能最长端距），以及 `L_free ≤ 30 asin[(d−E)/30]`（可能最短端距）。

两者相等的临界相对端点**欧氏距离误差幅值**约 `E*=0.0797309136mm`。在 **E=0.08mm** 时，这两个必要区间没有交集；在 **E=0.05mm** 时仍存在仅约 `0.0610mm` 的数学指令窗口。这不是加工中心轴系的真实误差数据，也不是所有自适应 cassette 的禁止条件；受控张力、摩擦反馈或实时端距补偿可以改变该固定指令假设，但必须通过真正机电动态验证。完整应力敏感性见 `results/R75_fixed_command_relative_error_sensitivity.csv`。

以能自适应暴露线长的理想盒体为另一**未实现**假设，midpoint 的储线最低值为 `70−9.6136996215=60.3863003785mm`；在独立误差 `E=0.05mm` 的保守模型中，实际需要存储不少于约 `60.438967mm`。R74 还给出收纳→s55 净收线至少 `46.192236mm`，这些是下界而非实装构造。

## 5. 材料体积只给下界，不等于储线腔合格

如果另外**假设** FPC 宽 `1.2mm`、全厚 `0.15mm`、不重叠占体积，则仅在最紧姿态被储存的实体材料体积下界约 `60.3863×1.2×0.15=10.869534mm³`。这没有计入任何折返曲率、空隙、导槽、弹簧、应力释放、连接器、FPC 实际分层、玻璃盖板或 OEM 禁布区。对 1/2/4/8/12 层仅给理想投影面积和叠厚的必要下界，见 `results/R75_min_material_storage_footprint.csv`；任何面积下界不能作为真实盒体所需体积的上限或可装配证明。
