# RAZR SLIDE R54｜双轴动态 FPC 数据准入、独立 CAD 基准配准与换向验收计划

**最终制造结论：NO-GO（`manufacturing_go=false`）。** 本轮修的是下一阶段的数据可追溯性与试验覆盖工具，不是完成实体 FPC、USB、电源、机械锁或 OLED 的制造资格。

## 一、继承可核验工程事实

- 产品定义未改：两个成品外形同尺寸的独立功能舱；B 在收纳时位于后/下层，沿 Y 上滑 **79.75mm**，终点沿 Z 坐实 **8.2mm**；单块约 7 英寸柔性 OLED，无独立外屏，A 舱优先更大电池。**4700mAh 只是目标**；完整 OEM 外壳、PCB、电芯 CAD 以及两舱等成品外形尚未验证。
- 冻结父包 `R53_original_immutable.zip` SHA256 `5c2dc051e6cfc19301eb34cccc82c0c2d9707a55bdb2032da6c957ddd8f3b95e`；原包 **27** 个文件的 CRC、26 个清单成员 SHA256 全部重新检查，任何文件不作修改。R53 父链报告包含 R50 `86f226f9bce3a3f0659737327c7cc32415eed3b9be3f96f35a746ac32844dfd6`，R51 `3b31d2f3c3ae869a35953dd7d183e1ade05f5aa0c3c1ca1ae7ac5295a098dbb5`、R52 `ba0731232b3edaf67cc40a6bf5e29707660ec96c6692db00d74e1e377ff68dcc`；本轮独立检查了 R50/R52 源包 SHA/CRC 与 R52 内嵌 R51 的哈希，但增量 R54 **仅**打包 R53 27 成员基线，不将其伪称为独立重跑所有历史全量几何。
- 当前可复核的研究线束是 R50/R52/R53 同一冻结分支的 **7 个有限宽厚路线族×9 个姿态**，共 **220** 条正碰撞分段见证，B 壳正碰撞 **63/63**，A 壳 **49/63**。坐标登记不是可制造挖槽图，不与 R40 的另一条 193 状态 G1 曲线分支混算。
- **本轮实际供应商受控证据：0/12 类。** 未收到原厂 A/B/BMS/电池/USB/OLED/FPC 的实际受控 3D、正式线路堆叠、签署可改区域或实物测试。Hirose 官网为指定 BM28 料号列出 STEP 接口，连接主机请求时返回 HTTP 403 HTML；不能在报告中称下载到了 STEP。

## 二、新增 R54 配准工具（不是原厂身份验证）

`src/r54_native_datum_screen.py` 不再只接受报告者自带的 4×4 矩阵及点位的自洽性，另行以基准点重拟合 SO(3) 刚性旋转及平移，选具有最大三角面积的 3 个标记点作为校准，其余至少一个点全部留出验证：

- 验证基准点独立编号、三维数值范围、左右坐标间刚体距离不变量、至少 5mm **假设研究级**坐标跨度和不退化三角形。
- 对比给定变换、重新拟合变换、留出点残差、配准内点残差、成对点距离偏差及旋转差。合格阈值 **0.02mm 仅为保守软件筛选值，不是 OEM 公差 GD&T**。
- 拒绝坐标镜像、单位偷换、非刚性缩放、重复标识、点位篡改、负向轴错置等对抗输入。即使所有数值满足，也总是返回 `manufacturer_origin_authenticated=false`、`OEM_license_to_modify=false`、`manufacturing_go=false`。
- **局限**：数值自洽的合成 STEP/合成测量点仍可能通过，这不能自动证明档案确实来自 Motorola/Hirose；基准点也必须由 OEM 同修订版实物和原 CAD 独立交叉测量。

`src/r54_native_screen_cli.py` 可对以后收到的受控 `registrations` JSON 做数值筛查，但并**不**读取或更新 OEM 机芯，也不能自行授予认证。

## 三、新增 79.75+8.2mm 双轴有限运动采样计划

`results/R54_motion_sequence_20261011.json`：

| 阶段 | 数量 | 运动逻辑 |
|---|---:|---|
| 滑出+最终 Z 坐实 | **481** | 321 个 Y（0→79.75mm）+ 160 个 Z（0→8.2mm，Y 固定 79.75） |
| Z 撤回+Y 收回 | **480** | 先 160 个 Z 反向状态，后 320 个 Y 反向状态 |
| 1/4、1/2、3/4 滑程换向局部试验 | **15** | 每处 5 个前进/退回/再前进微行程姿态，仅独立局部试验 |

B 的随动研究坐标 `B_world = B_local + (0, s, q−8.2)mm`，A 舱固定。脚本拒绝中段提前 Z 坐实、缺失中途采样、错误方向、后向行程符号错和缺失三处换向试验。

**关键边界：这只是有限采样的验收输入序列，不是已执行 961 个姿态的 OCC 实体碰撞测试，更不是连续时间扫掠、接触寿命、真实电铜连通或局部应力预测。** 无实际 OEM 带材模型可应用此序列。还须取得用户需求工况速度、加速度、扭转、实测温度、插针焊脚/应力释放，然后才能扩展为动力学和 30 万次疲劳台架。

## 四、可执行收据

- 从冻结 R53 ZIP 临时解包后真实重跑原版 **30/30** 项；新 R54 研究级测试 **41/41** 项，退出码 0，合计 **71/71 个本轮实际运行断言**。
- `R54_RUN_REPRODUCE.py` 在临时隔离目录重算上述测试，并把三个 R54 JSON 结果再生，与封包前版本逐字节对比；返回退出码 0。测试“通过”的含义包括**正确拒绝危险的合成数据**，绝不是 71 项硬件合格。
- 原父包 SHA256、成员 CRC、成员级哈希及新包 manifest 全部锁定。源代码/测试不覆盖任何 R53/旧 FPC 文件。

## 五、原厂资料和真实试验的不能延期的要求

1. **E/OEM**：同一修订版本 A/B 完整外壳、板、电池、摄像头、OLED 封装、保持结构原始 STEP；经独立实测的 4+ 不退化基准点、变换和 GD&T；所有可改服务仓以签署图层/文档确认，**不得**把研究碰撞盒直接送机加工。
2. **M**：双终点真正实体坐实、失效常闭和有限力回缩；解决继承 **36/64** 联合释放反例和受载强度/污染/冲击。
3. **P**：BMS 主电源独立供电拓扑、热升、逆灌、预充、熔焊 FET、三种单点 PCB 旁路故障；信号弹片额定 1.5A 不能直接证明主电源。
4. **S/U**：真实指定料号 Hirose BM28 的 header/mate STEP、焊盘、插拔次数和内部静态安装；动态 FPC 含回流/屏蔽和实际差分阻抗，**全滑程及反向中 USB 必须保持真实铜导体连续**。要求 TDR、VNA S 参数、眼图/BER、EMI/ESD 和循环后重复验证；不可用 DOCK_ONLY/无线/缓存顶替。
5. **D/OLED**：指定 7 英寸面板含 COF/FPC/胶框完整封装、动态最小 R、长期收纳残余变形、展平力和 30 万次寿命/失效判据。IEC 62715-6-42:2026 只规定展平力测量方法。

## 六、R55 正确进入条件

**先拿到真实受控数据和授权，再建可装配 FPC CAD。** R54 提供将来验收的数值配准与离散运动基准，但没有修改实际工程件、没有消除 R50–R53 的研究壳干涉。除非原厂批准并给出厚度/保持/电芯真实空间，否则继续优先重新评估跨舱连接拓扑，不得凭模型假定切削机芯。

**最终判定：`manufacturing_go=false`。**
