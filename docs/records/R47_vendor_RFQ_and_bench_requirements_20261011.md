# R47 原厂资料询证及 USB 连续链路样机需求（待发送草案）

项目：两等外形功能舱、单约 7 英寸柔性 OLED、B 上滑 79.75mm 后法向坐实 8.2mm，USB 在运动全程必须有连续的实体铜导体连接。以下为准备给 OEM、FPC 厂、连接器厂、测试实验室的询证草案。**未发送、未收到答复、未完成任何硬件试验。**

## 给整机/显示 OEM

请提供统一 XYZ（定义 `B_world=B_local+(0,s,q−8.2)`）的完成版 A/B 外壳、主板、摄像头、两颗电芯/BMS、滑轨/硬止挡/机械锁、OLED 及 COF/FPC 的装配 CAD（原生 STEP/Parasolid、版本、哈希），定义机械可切/禁止切区域、材料最薄壁与 GD&T、公差检验基准。书面确认两舱成品同外形及 A 优先电池空间的可实现性。交付 7 英寸 OLED 全封装宽度、动态 R、长储存残余形变、展平力、循环寿命、失效判据和样品授权；IEC 62715-6-42 的方法不能代替该模组寿命实证。

## 给动态 FPC 厂

请提供能够覆盖 Y=79.75mm 与 Z=8.2mm 连续双轴动作的准确线束料号、W×t、铜/介质/保护膜层叠、RA 铜与中性轴、两面/宽向动态弯曲与扭转许可、最小 R、端点直线应力释放/固定方式、真实 STEP/制造数据、每层铜阻抗与损耗、设计公差及 30 万次项目目标在高低温/反复反向/污染/急停下的原始循环数据。需附经签名的样本编号、设备时钟、导通/阻抗波形及失效定义。未取得前不许可把 R15 作为原厂允许运动半径。

## 给 USB / 静态端接厂

确认目标 USB 协议、真实物理比特率及差分对数量、参考地/屏蔽、端点配合件 CAD、land pattern 与安装保持结构。整机在连续滑动、中途停止、反转、Z 终点微动、加速疲劳后必须用 TDR、VNA S 参数、眼图/BER、重枚举/掉线计数和 EMI/ESD 测试证实**不中断物理 USB**。Hirose BM28 仅可考虑静态低插拔端接；端点触点切换或无线不可取代 USB。

## 给电源/BMS 与安全机构供应商

对于可选两端停靠辅助供电，提供独立电源连接器料号、额定电流/接触温升、主板最坏瞬变、两颗 BMS、预充、双向隔离、熔丝、残余电能放电与故障工装。重点验证三个单点 PCB 旁路、熔焊保护、反灌、触点提前带电/开断电弧。在两端真实机械捕获及断电/回缩顺序有原始时序波形前，不允许暴露的带电触点。
