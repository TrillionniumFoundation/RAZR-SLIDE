# R7 升降托板机构：对抗筛查包（非通过版 CAD）

## R7 当前完成内容
1. 从 R6.1 ZIP 解包出原始 Python、CAD 和验证记录并复核数值。
2. 从真实 R6.1 源码计算26条托板节距、0.37 mm升程、OLED宽度及机身两侧剩余空间。
3. 按假设构造凸轮运动行程的敏感性表和曲线，用平滑升程曲线最大局部斜率筛除原 0.35 mm 短行程。
4. 对侧边随动件包络做名义净距筛查，明确各个假设。

## 核心结论
- R6.1 升程 0.37 mm，凸轮水平升程区仅0.35 mm。三次 smoothstep 曲线的最大绝对导数为 1.5h/L，对应局部切线角约57.8°；不是经力学求解的压力角。
- 若以最大局部切线角 <=15°为 *初步筛查目标*，需要至少2.071 mm的凸轮升程区；其本身并不保证滚子半径、曲率、加速度和寿命合格。
- R6.1 名义显示宽67.321mm，机身总宽73.99mm，单侧3.335mm；示范分配壁厚0.65、滑轨1.4、裕量0.3后，只有0.985mm，放不下假设1.2mm宽的滚轮。假设非厂商规格，不能泛化为所有机构都不可能。
- 最接近工程上合理的 R7 候选是共用长升程凸轮轨道、侧缘支撑以及分舱末端锁止；**本轮未完成可加工的凸轮/轴承/支柱/锁止CAD**，没有对此宣称通过。

## 须补齐方可放行
- 真实侧轨、轴承、凸轮和钢带的2D制造图、滚轮圆角与接触应力；至少将完整26组件（含支柱）扫掠进同一三维模型。
- 偏载、磨损、过约束、公差堆叠、挠度/冲击安全锁止、寿命实验。
- OEM主板、电池、相机和动态FPC的有版本来源CAD；Hirose FH34SRJ现货连接器仅作为候选（官方0.5mm节距、1.0mm高，支持0.3mm厚FPC），不是已验证整机MIPI走线方案。
- 屏幕供应商许可的中性层动态回弯半径、光学胶蠕变与拉平力试验。
