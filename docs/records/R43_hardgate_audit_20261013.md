- 完整父包：`RAZR_SLIDE_R42_FPC_full_verified_20261013.zip`，SHA256 **`4daf4f6cf63ffe3c4222c71726f66da4b99ae121410322954b41362fcee1f513`**。父包 **56** 个成员，独立 CRC 检查通过。R42 父包又包含 R41、R40、R39、R38 及更早版溯源。所有父包只读，原 A/B 壳、机芯、OLED 研究保护 BRep 未被切除。
- R42 已在 121 个数学位置证明两段固定长度中心线解存在，但 **9/9 个**真实 OCC 研究姿态均侵犯受保护空间；本 R43 只是对其双 U 半速中继方案做更广的位置否决与实体反例。数学长度守恒、模型测试成功或 STEP 可以导入均不是寿命/制造通过。

## 2. R43 新增路线搜索（必要条件，而非三维完整净空证书）

使用 R42 两段独立 FPC、半速移动 C 节点、研究参数 **R16.5mm、宽 1.2mm、厚 0.15mm**，在每个测试配置中将两条 FPC、A/B 研究端点和 C 节点**同步 X/Z 刚性平移**，而不是擅改 FPC 层叠或切削机芯。扫描范围：

- `ΔX=-36,-33,…,+3mm` 共 **14** 档；`ΔZ=-4.5,-4.0,…,+1.5mm` 共 **13** 档；总计 **182 布局**。
- 每布局检查 `STOW、MID、PREDOCK、DOCK_HALF、OPEN_SEATED` 共 **五姿态**，每姿态两条 FPC；沿中心线采点、排除两端各 3mm 的非芯线端头区，使用 OpenCascade 实体点内判别 `BRepClass3d_SolidClassifier`。
- 原包络 X±36.995mm，研究 Z 范围 `[-8.2,7.68]mm`；所有 182 布局中心线名义包络未越 X/Z 界。**这一项只表示落在尺寸窗内，绝不等于不穿机芯或可装配。**

| 必要条件检查 | 本轮真实结果 |
|---|---:|
| 共同平移布局数 | **182** |
| 采样中心线可同时避开 A/B 受保护实体的布局 | **0** |
| 同时避开 A/B + OLED 及旧显示 FPC 研究体 | **0** |
| C 中继节点在五姿态均不位于 A 壳保护实体的布局 | **0** |
| 仅 X/Z 包络未越界的布局 | **182** |

**解释边界：**中心线进入保护实体构成当前特定线路布局的明确失败见证；零样本命中也只能进入下一轮 OCC 体积检查，不能自动合格。对 X/Z 位移以外的连续变形、不同端点、更换拓扑、无中继独立线路、不同 R/宽度和 OEM 实物壳体，本筛查**不构成无解证明**。

## 3. 两种代表布局的 OCC 真正带状扫掠

从筛查保留两组**负例**：`LOWEST_SAMPLED_COLLISION` (`ΔX=-3mm, ΔZ=+1mm`，采样总碰撞较低)；`OLED_CENTERLINE_ESCAPE` (`ΔX=-36mm, ΔZ=-3.5mm`，中心线 OLED 采样零命中)。各取 STOW、PREDOCK、OPEN_SEATED 三个姿态，分别建立宽 **1.2mm** 厚 **0.15mm** 的有效单体 OCC 带状 FPC 与中继尺寸代理。A/B 及 OLED、原显示 FPC 研究实体**没有切削**。表为**两条 FPC 对对应受保护体积求交之和**，单位 mm³：

| 方案 | 工位 | A 壳 | B 壳 | OLED 代理 | 两条 FPC 互相重叠 |
|---|---|---:|---:|---:|---:|
| 较低中心线碰撞 | STOW | 20.5630 | 1.4179 | 0.0968 | 2.1972 |
| 较低中心线碰撞 | PREDOCK | 8.9550 | 1.1822 | 0.2881 | 3.4097 |
| 较低中心线碰撞 | OPEN_SEATED | 3.8611 | 14.7945 | 0 | 7.0497 |
| OLED 中心线未命中 | STOW | 1.7932 | 28.0312 | **0.2209** | 2.1972 |
| OLED 中心线未命中 | PREDOCK | 1.7550 | 12.5907 | **0.2116** | 3.4097 |
| OLED 中心线未命中 | OPEN_SEATED | 14.9570 | 17.7404 | 0 | 7.0497 |

**6/6 个 OCC 姿态存在 A 或 B 原保护实体穿透**；两条线也在六姿态均自占用，不存在独立的安全中继板/导向保持结构。额外发现 OLED 中心线零命中仍被宽厚实体体积扫掠识别出 OLED 穿透，正是不可将点级筛查冒充实体资格的反例。四份失败 `R43_GHOST_*.step` 已重新导入有效实体；STEP 有效仅表示研究负例可读，不得发给厂家作为可制造装配。

## 4. 侧边横截面平面 U 的必要尺寸下界（限定范围）

沿用 R41/OLED 研究包络，单侧可用 X 宽 **36.995−33.660=3.335mm**，Z 高 **7.68−(−8.20)=15.88mm**，横截面对角线 **16.226418mm**。

若线路需要在这一个 XZ 横截面内形成完整的**平面 180° 半圆 U，且其直径两端都必须落在截面内**，则端点相距 `2R`。对条件性研究半径 `R=16.5mm`，直径 **33mm > 16.226418mm**，差 **16.773582mm**。在 X 宽完全不变时，理论 Z 高至少还需增加 **16.951049mm**；反之 Z 高不变时，单侧 X 宽至少还需增加 **25.592938mm**。这些是简单外包络下界，未含保护胶、应力释放、公差、PCB 或 OLED 禁布区。

这只否定“直径横跨同一个 XZ 截面”的平面 U；**不能外推到沿 Y 方向、扭转、滚筒、叠层分仓或其它三维储线方式**。R16.5mm 也绝非 FPC 厂商许可动态最小 R 或 300k 次合格寿命。
