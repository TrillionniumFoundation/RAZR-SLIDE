# RAZR SLIDE R39 → R40｜真实材料与样机询证矩阵

**该文件是必须获取的输入和试验计划，不是供应商出具的合格报告。**

## 动态 FPC（优先）
请具体厂商/料号提供：实际铜层数量、材料/厚度与剖面、中性层位置、覆盖膜/胶粘剂、最小**动态**弯曲半径（以寿命和温度指定，不混用静态折弯半径）、弯曲方向、允许应变、扭转规则、最小端头直段及夹持半径、整件 3D CAD、跨舱 79.75mm 滑程及终点 8.2mm 法向就位所需服务环长度/防磨损导槽；300,000 次目标循环下的阻值漂移、开裂、剥离、绝缘和抗拉脱失效判据。若不能提供相关材料许可，几何 R2.5/R7.5/R15 均不能作为合格设计。

## 机械与整机空间
获取两舱完成装配外壳、B 主板和 SoC/电池保护体积、A 电池、电池软包膨胀、OLED 实际层叠 3D、外侧滑轨/铰链/两端机械坐实钥匙、所有 FPC 支撑/压板/摩擦材料/止挡。建立实测公差 GD&T 链、带真实弹簧/紧固的承力路径与疲劳、污染、振动、跌落验收。任何旋转/平储导槽不能切断主机芯或承力通道。

## 跨舱主电源
独立定义双电池电源系统架构和原理图。必须有高/低 SOC 交叉供电、预充、反向隔离、熔焊、单点 PCB 桥接、掉电后残余电压、接点先断电后机械分离、温升、短路电弧和同/异步动作试验。TE 2199001-1 的 Signal 额定电流1.5A及BM28目录额定值，都不自动构成跨舱双电池功率许可。

## USB / 信号
冻结协议和速率、拓扑、真实 Hirose header/receptacle PCB/FPC 焊盘、回流路径、阻抗与阻抗变化预算；做 TDR、VNA S 参数、眼图、BER、串扰/EMI/ESD、温循/全滑程疲劳后的 SI 复验。不得因24位或目录带宽就声称系统高可靠。

## OLED
原厂约7英寸真实型号、完整封装宽和保护边（含COF/FPC/封边/胶材）、平储通道、屏幕动态允许R、层叠残余变形、拉平力随循环与温度变化、触摸性能及项目样品/图纸商业授权。IEC 62715-6-42:2026 仅为展平力测试方法，不能证明动态疲劳寿命。
