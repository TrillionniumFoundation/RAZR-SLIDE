# RAZR SLIDE 全资料安全审阅与工程分支选择

**选择 R50 的全长有限截面验证框架作为修复集成基座，单独引入 R44_FPC_20261013 的后背回环作为待验证候选；R79 保留为数学约束辅证。没有任何一支具备制造资格，`manufacturing_go=false`。**

选择依据是实际端点、实体截面、障碍体覆盖和来源可复核性，而不是编号、时间或测试数量。这里的“选中”表示最适合接入真实缺失工程工作的源码基础，绝不是选中了能制造的手机。

## 1. 全资料覆盖与读审边界

原资料已按 728 项精确身份和原始字节盘点。安全比较读取了全部 **157 份独立 Markdown**，其中包括同编号分叉审计、独立复核、供应商/RFQ/可信来源要求；解析了全部 **205 份独立 JSON** 并检查资格字段；提取了 **29 份早期 PDF** 的文本。两份 R4 PDF 为同一 SHA 的栅格文档，文本为空，已将全部六页渲染并逐页查看，没有按“无文本”略过。

原 ZIP 共 **121 份／117 种不同 SHA**；归档审计检查了原包及嵌套 ZIP 的 CRC，均未发现 CRC 错误。R50 和 R52 各有三份字节相同的 ZIP 副本，不能把三份副本计作三次独立工程验收。其他同编号、不同哈希包均保留。包头、README、嵌套父包和成员清单覆盖另有归档审计记录。

逐文件名称、SHA、审阅方法、JSON 资格字段和关键分支来源详见本目录 `BRANCH_SELECTION_SAFETY_20261013.sources.json`。它明确区分完整文本/字段审阅、原始字节审计与实际源码重新执行。87 张 PNG、25 个 HTML、18 个 CSV、3 个 GIF、2 个独立 STEP 和其它原资产的字节归档，不能被写成每个源程序、每个 CAD 场景、每个连续运动区间都重新验收。实物机械、电气、USB 和 OLED 验收并没有因资料扫描而出现。

## 4. 选中后必须修的实际缺陷

R50 的 `solid_cells()` 要求每个 loft 格有效、单体且体积为正；但 `solid_intersection()` 只检查交集 `isValid()`，没有显式拒绝负有符号交叠或不合理体积上界。历史聚合断言强制旧路线 B 相交为正，足以保留它们的否决；**不能直接将这套函数用于新候选“零交叠即通过”**。新实现应逐格验证交集有符号体积与 `min(格体积,障碍体积)` 上界，保留局部内点/实体见证交叉复核，区分 compound 重叠体积和真实布尔 union，不隐去算法异常。

本轮已在新的 `engineering/cad-review-20261013/occ_signed_volume.py` 实现有符号体积验证，10 项独立对抗检查通过，包括负值、非有限值、超过 cell/body 上界、真实包含/不相交/相交实体与多格非 union 的拒绝规则。原 R50 不改写。部分原 R50 姿态的当前重新计算保存在 `R50_selected_checked_run.log`，不将部分新计算冒称完整 63 姿态或历史 138 项全回归。

验证已接入另建的 `engineering/r50-repair-20261013/src/r50_full_span_finite_ribbon.py`，任何原始负交叠体积都拒绝，不取绝对值、不夹成零。它属于选中框架的真实源码修复；没有改写封存 R50，也没有赋予新的实体材料资格。

R44 后背 U 则须先解决两个真实端接，不允许只把悬空锚点标成“已连接”。原板端到回环的直径 0.30mm 直线代理在三姿态均穿入所属研究保护体：A **0.611831mm³**，B **2.060871mm³**。改换折线路径、端点、出线角或实际后盖仍须单独求解，不能从这个反例推出全局无解。

材料方向同样必须进入选中框架：任意数学平行运输截面不等于真实 FPC 的宽向/厚向易轴。当前新增 CAD 副审计已发现 R44 的 XY U 在其原截面方向下是宽向硬轴弯曲；把截面转到厚向易轴后又出现 OLED 正交叠反例。该副审计保存原失败并以新的源码和收据交付，不覆盖历史 R44 或历史 R45。数字 Frenet 修复不会让悬空端点变成实装 PCB，也不会取得厂家两轴弯曲许可。

完整新增副审计 `engineering/cad-review-20261013/R45_CAD_motion_audit.json` 已完成 **121 姿态×23 个研究障碍体**，修订几何帧的裸带仍为 0 个体积交叠姿态；四个主障碍的全采样最短距离分别为 A 7.875mm、B 0.951035727mm、OLED 0.395mm、旧显示 FPC 7.560588601mm。这是更完整的离散研究证据，仍不是完整连续材料扫掠或端接通过。坐实 B 端宽轴倾角从旧模型 **27.965742551°** 降到新数学帧 **0.035088109°**，但真实夹持方向和容许材料扭转未知。改为厚向易轴后，STOW OLED 正交叠 **2.003046417mm³**，并超研究 Z 包络 **0.35mm**；完全坐实仍超 Z **0.352640614mm**。这就是不能因裸带零交叠选它为合格线束的具体反例。

R58 另有值得永久保留的实际程序反例：B 研究体重复变换曾产生假零交叠，修正为原 B 单次世界变换后，镜像 STOW 的交叠为 **24.94164306mm³**，原零值已撤回。R61 的 Bishop 截面运输可用于改进数学姿态处理，但其独立逐姿态路径长度为 **91.141593／51.141593／26.656637mm**，使用未批准 R0.4 圆角；R62 又证明 A 端漂移 0.200mm、B-local 漂移 0.650mm。它不能代表同一根固定长度、真实夹持材料在三姿态中的运动。应取方法与否决测试，不能把较新零交叠片段换成完整线束通过。

这两项是实际可修的模型/验证问题；处理后仍须面对真实 OEM 空间和材料数据，不再以增加软件门禁或重复相同负例代替工程推进。

## 5. 所有分支共同缺少的安全资格

已从源码独立重新枚举原机械 **64 状态／36 逃逸**、电气 **512 状态／487 带电**及 **三类单点 PCB 旁路**；新鲜 R37 OCC 结果与历史匹配。机械最小逃逸割集是左右两侧挡门/载体耳组合的四种二故障对；电源三种单点为 A 直通 pad、B 直通 pad、共同 live bus 到 pad。计数属于概念故障树，不是实机失效率。

|---|---|
| 双侧捕获、防误解锁、失效常闭 | 实体 STOW/OPEN 捕获、真实弹簧/硬止挡、安装和承力、断簧/断销/双侧共因试验均缺 |
| 有限力回缩 | 实测最大阻力、最小可用力、最大施力、最弱材料/保持阈值与 jam 安全状态缺失；碰撞不等于回缩 |

| 信号与 USB 独立动态路径 | 全部端接、铜层/回流/屏蔽、规定速率、全运动 TDR/VNA/眼图/BER/ESD/EMI 与断线原始记录缺失 |
| 两电池独立保护／受控交换 | 真电芯/BMS/负载、反灌、预充、限流/熔丝、PCB 三旁路及实测残压/能量缺失 |

R46–R50 原资料明确冻结**滑动、停车、反向与就位期间物理 USB 连续**；本轮沿用该功能条件，端点停靠、无线、缓存或重枚举不作为合格替代。信号、USB、供电分开建模，仍须检查共享地、屏蔽、机壳、擦破和单板旁路的跨路径共因。

本次工程继续点因此是：以 R50 的完整路径验证接口接入明确未合格的 R44 候选，补齐有符号体积和真实材料轴、端接/应力释放、完整障碍体；保留 R58/R61 和 R79 的确有用途反例与数学约束。一旦下一项需要 OEM 原生空间、具体 FPC/OLED 数据或实物力/电气/寿命测量，登记上述缺失证据为硬阻塞，停止无新依据的门禁迭代。**全部真实 M/P/S/U/D 资格完成前，整机始终 `manufacturing_go=false`。**
